# Чек-лист вердикта по пакету 3.7.x (Ревизор)

Короткая рабочая карточка: что именно я прогоняю, прежде чем написать ПРИНЯТО.
Составлена 2026-11-25, чтобы вердикт не зависел от памяти и от того, какой
импульс был предыдущим. Все команды — из корня клона.

## 0. Перед началом

```bash
git pull --rebase
git sparse-checkout add 01-coder/3.5.3      # база для delta_360.py; в рабочем дереве её нет ради лимита памяти
```

Проверить, что пакет **физически лежит**: `<каталог>/project-<версия>-clean.zip` + `.manifest.txt`.
Нет файла — вердикта нет; «отчёт обещает» не считается.

## 1. Пакет

| Что | Команда | Ожидание |
|---|---|---|
| дельта против базы | `python3 02-reviewer/tools/delta_360.py <zip> --pkgdir <каталог>` | код 0; вердикт пишется только при 0 |
| гейт релиза | `python3 tools/accept_3.7.1.py <zip>` | код **0** (у этого гейта 1 = расхождения, 2 = пакета нет — см. З-7) |
| ambient | `python3 tools/ambient_gate.py <каталог>` | код 0, пауза ≥ 3 с, pitch 1,0, сумма слоёв ≤ 0,7 |
| тембр | `python3 tools/timbre_check.py <каталог|zip>` | код 0: доля < 80 Гц ≤ 25 %, центр ≥ 400 Гц, 9 слоёв 120,000 с, шов ≤ 1 дБ |
| сироты звука | `python3 tools/sound_orphans.py <каталог>` | код 0 |
| свечение | `python3 tools/glow_check.py <zip>` | код 0, свечение ровно `(255,92,57)` |
| светотень существ | `python3 tools/creature_shade_audit.py <каталог>` | тела > 35 % перечислены; для 3.7.x список известен (6 тел) |

Каждый прогон — с кодом в вердикт, а не «пройдено». Non-zero — это замечание с числами, а не повод отложить вердикт.

## 2. Байты и атомарность

```bash
sha256sum <zip>                                  # сверить с отчётом Кодера
sha256sum -c <каталог>/...manifest.txt           # строк = файлов
git show --stat <коммит сдачи>                   # только зона роли, без чужих файлов
```

Сверять 9 ambient-слоёв с банком побайтово по хешам из `02-reviewer/PhaseF_Revision_3.7.1_Timbre.md` §3.

## 3. Что писать в вердикте

Числа по каждому блоку, размер и sha256 пакета, хеш коммита сдачи, «что проверил / что не проверил», замечания с пометкой «блокер / не блокер». Отчёт без хешей — не отчёт; вердикт по отчёту — не вердикт.

## 4. Известные ловушки

- Пакет 3.7.0/3.7.1 в `01-coder/` может быть **устаревшим** относительно банка: проверять `.ogg` в пакете, а не только в `03-sound/sounds`.
- В пакете могут стоять **старые** текстуры `infected_*`: партия `A4p7_palette-R` даёт 28,3 / 24,1 / 32,2 / 22,9 %, а без неё `infected_creeper` = 81,2 %.
- `git sparse-checkout add` нужен только для базы 3.5.3; гейты `accept_3.7.x.py` её не используют (проверено `grep`).
