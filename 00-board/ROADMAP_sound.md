## Твоя задача СЕЙЧАС — T-3149 · Ревизия банка: единообразие и «мёртвые» слоты

**Статус:** ASSIGNED → **IN_PROGRESS** (сразу, без ожидания команды) · **Зона:** `03-sound/sounds/` · **Приоритет:** 1

**Почему эта задача.** Приёмка швов (T-3133) закончилась, нормализации
сданы. Дальше в Roadmap 3.7.3 — **полировка звука**. Твоя часть: привести
банк к единообразию, **не меняя уже принятое**.

**Что сделать:**

1. **Единый формат.** Пройди по всем `.ogg` банка: битрейт, частота
   дискретизации, число каналов, кодек. Таблица «файл → параметры».
   **Норма банка** (из `sound_bank_policy.md`): единый кодек, единая частота,
   стерео/моно — по семейству, 160/96 kbps для фоновых/точечных.
   Расхождения — перечислить.
2. **«Мёртвые» слоты.** Проверь, все ли файлы банка **используются**: каждый
   `.ogg` должен быть достижим из `sounds.json` (прямо или через
   `sound_orphans.py`). Неиспользуемые — кандидаты в архив. **Ничего не
   удалять** — только список с обоснованием.
3. **Петли с тишиной.** В `heartbeat_loop` — 283 мс тишины в хвосте (твой
   отчёт T-3133). Для каждой петли с заметной тишиной в хвосте оцени:
   это **воспринимаемая пауза** или **артефакт обрезки**? Рекомендация по
   каждой: оставить / перерисовать хвост / заменить.
4. **Единый запас.** Ты ввёл запас 0,20–0,44 дБ для 7 файлов (T-3140).
   Проверь **остальные**: есть ли пики выше −1,00 dBFS или, наоборот, ниже
   −3 dBFS (слишком тихие)? Дай **список на доливку** — те, где громкость
   заметно ниже соседей по группе. **Пока не трогай** — сначала список.
5. **Отчёт** `00-board/reports/sound_bank_uniformity.md`: таблицы по пунктам
   1–4 + сводка «сколько в норме, сколько требует внимания».

**Критерий приёмки:** таблица параметров всех `.ogg`; список неиспользуемых
с обоснованием; вердикт по петлям с тишиной; список на доливку; **банк не
изменён** (это аудит, не правка).

Заказчик в игре: **«щепотка раздражения после прослушивания на постоянной
основе, пока ты рядом с ульем»**. Типичный признак — **низкочастотная подложка**.

Это **замер**, не перерисовка. Твоя работа — измерить и дать вывод с числами.

### Что измерить

Инструментом `tools/sound_metrics.py` по **13 ambient-файлам**:

- `amb/hive_ambient_01..03.ogg`
- `amb/hive_ambient_close_01..02.ogg`
- `amb/hive_pulse_01..03.ogg`
- `amb/hive_ambient_tonal_stinger.ogg`
- `hive/amb_surface.ogg`, `amb_deep.ogg`, `amb_core.ogg`, `amb_threshold.ogg`

По каждому:

| Метрика | Зачем |
|---|---|
| **доля энергии < 80 Гц** | **главное число** — это и есть «раздражение» |
| RMS, peak, crest | общая энергия и пики |
| спектральный центр | где сосредоточена энергия |

**Порог ориентира: доля < 80 Гц > 25 %** — значит подложка низкочастотная и
это и есть раздражение.

### Что уже измерено (проверь и дополни)

Первичные замеры Архитектора — если сойдутся, используй свои:

| Файл | доля < 80 Гц | доля < 120 Гц |
|---|---:|---:|
| `hive_ambient_01..03` | 80,0 / 81,5 / 82,8 % | 83,7 / 85,4 / 87,0 % |
| `hive_ambient_close_01..02` | 78,5 / 76,5 % | 83,1 / 81,1 % |
| `hive_pulse_01..03` | всего 8,0 / 8,2 % | — |
| `amb_surface` | — | 77,1 % энергии в 1–5 кГц |
| `amb_deep` | — | 72,3 % энергии в 20–60 Гц |

**Вывод по этим числам:** постоянная кровать (`hive_ambient_*`, ~80 % энергии
ниже 80 Гц) — это и есть «раздражение». **Пульс к источнику раздражения не
относится** (всего 8 %) — «периодический гул» имеет другую причину, её чинит
Кодер (расстройство слоёв и отсутствие паузы между пульсами, см. задачу Кодера).

**Тембр стингера** (`hive_ambient_tonal_stinger.ogg`, 10 с): RMS 0,1071,
пик 0,521, доминанты **41,2 и 110,2 Гц**, энергия 20–60 Гц — **63,4 %**.
Это тот самый слышимый «гул».

### Вывод, который нужен от тебя

`00-board/reports/sound_ambient_metrics.md`:

1. Таблица: файл → RMS → peak → crest → спектральный центр → доля < 80 Гц.
2. **Раздел «Вывод»**: годно ли как есть или нужна перерисовка.
3. Если доля < 80 Гц велика (условно > 25 %) — это и есть «раздражение»;
   **тогда перерисовка становится задачей следующей волны, и в этом окне её
   не делать**. Просто зафиксируй это и переходи к K8-S.

**Не перерисовывай ambient в этом окне** — это решение следующей волны.
