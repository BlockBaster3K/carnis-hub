## 1. Что произошло при попытке

```
GET  /repos/BlockBaster3K/carnis-hub/keys   → 403 Resource not accessible by integration
POST /repos/BlockBaster3K/carnis-hub/keys   → 403 Resource not accessible by integration
```

При этом обычные права есть:

| Проверка | Результат |
|---|---|
| `GET /user` | `BlockBaster3K` — 200 OK |
| `GET /repos/.../carnis-hub` | `push=true, admin=true, maintain=true` — 200 OK |
| `GET /repos/.../actions/secrets` | **403** |
| `GET`/`POST /repos/.../keys` | **403** |

**Причина:** это GitHub App installation token, а не пользовательский PAT.
В заголовках `X-OAuth-Scopes` пуст, `X-Accepted-Github-Permissions` есть —
то есть токен выдан интеграции с ограниченным набором разрешений.
`admin=true` в объекте репозитория отражает права владельца, а не scope
установки приложения. Эндпоинт deploy keys требует `administration: write`,
которого у установки нет. Это **не** проблема токена и не лечится
перевыпуском — нужен либо PAT с `admin:public_key`, либо доступ в веб-интерфейс.
