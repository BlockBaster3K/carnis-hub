**Дата:** 2026-11-26 · **Автор:** Интегратор · **Задача:** I10–I14 (волна 52)

## Коротко

Пакета 3.8.0 ещё нет (`01-coder/3.8.0/` не создан), поэтому гейт
`tools/accept_3.8.0.py` **готовится заранее** — по правилу «ноль простоя»,
чтобы в момент сборки не было простоя на моей стороне.

## Что уже сделано (`bc9e539`)

`tools/accept_3.8.0.py` — база от 3.7.3: все правила 3.7.3 продолжают
действовать и на 3.8.0 (crest, пик/запас, банк == пакет, свечение Р-3,
реестр, дельта к предыдущей версии, манифест). Дефолтные пути переведены
на 3.8.0, эталон дельты — **3.7.3**.

**Блок 16 (новый, по волне 52).** Проверяет новые существа. Ключевое
решение: состав берётся **из реестра Художника, а не из текста доски**.

- Доска (T-3191) говорила «17 новых существ».
- Ревизор пересчитал по факту: **33** существа, 99 файлов, дублей 0.
- Значит заявленному числу доверять нельзя, и гейт не сравнивает с
  «17» — он перечисляет состав раздела 3.8.0 реестра и требует полный
  комплект на каждое существо.

На каждое существо проверяется:

| Проверка | Зачем |
|---|---|
| `geo` разбирается как JSON, есть `bones` | битая геометрия = моб не грузится |
| `texture_width/height` в geo == реальный размер PNG | если объявлено 128×128, а нарисовано 64×64, UV уедут и моб станет разноцветной кашей — **глазами это не видно** |
| текстура существует и ≥ 7 цветов | норма палитры проекта |
| `glowmask` существует и по правилу Р-3 | ровно 2 цвета: `(0,0,0,0)` + `(255,92,57,255)` |

Всё fail-closed: любое отсутствие — `fail`, не `warn`.

## Проверено на реальной сдаче Художника

Собрал временный пакет из его zip `Carnis_3.8.0_infected_vanilla_mobs*.zip`:

```
новые существа: в реестре 33, полный комплект 33, с изъянами 0
fail: 0 | warn: 0
```

Негативы (руками):

| Негатив | Ожидание | Факт |
|---|---|---|
| удалён `infected_slime_glowmask.png` | fail | ✓ |
| в geo объявлено 256×64 вместо 64×64 | fail | ✓ |
| нет раздела 3.8.0 в реестре | warn, не «ок» | ✓ |

Замечание по существу: у части новых мобов **1–6 костей** и
`geo` фактически повторяет ванильную геометрию. Блок 16 это **не валит** —
он проверяет целостность, а не художественную ценность. Требование
«≥ 12 костей и анимации» — это H-блок Художника (T-3189); Ревизор уже
вынес его отдельной находкой. Моё дело — чтобы гейт не пропустил битый
комплект, а не оценивать модели.
