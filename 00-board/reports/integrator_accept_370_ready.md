## 1. Зачем понадобился новый скрипт

`tools/accept_3.6.0.py` для 3.7.0 **не подходит**: в нём жёстко зашита версия
`3.6.0` и проверки K4/K5/K6-S — пункты, закрытые в 3.6.0. У 3.7.0 другой состав:

| Пункт 3.7.0 | Чем проверить |
|---|---|
| A4-p7 — палитра существ | `tools/glow_check.py` (написан мной, `ef04189`) |
| K8-S — 0 сиротских `.ogg` | `tools/sound_orphans.py` (написан мной, `e14cd13`) |
| Д1–Д7 и принятое не тронуто | сверка 14 файлов с 3.6.0-R |
| целостность, версия, overlay, JSON | те же проверки, что и в 3.6.0 |

Новый скрипт **не дублирует** логику чекеров, а вызывает их как подпроцессы —
чтобы не разъехались два разных прочтения одного ТЗ.

## 2. Что проверяет (7 блоков)

1. **Манифест** — `sha256sum -c`, число строк против числа проверенных.
2. **JSON** — все файлы пакета разбираются.
3. **Версия 3.7.0** — `mod_version`, `mods.toml version`, `displayVersion`,
   имя каталога (суффикс `-R` отбрасывается, как в CI).
4. **Overlay** — `03-sound/... -> пакет/... | sha256`; сверяются и файлы,
   и заявленный хеш.
5. **A4-p7** — вызывает `glow_check.py`, требует код 0.
6. **K8-S** — вызывает `sound_orphans.py`, требует код 0.
7. **Д1–Д7** — 14 файлов побайтово равны 3.6.0-R (Д6-блоки, Д7-флора,
   `cerebral_nexus.geo.json`, 4 модели K5).

Коды: **0** ПРИНЯТО · **1** ЕСТЬ РАСХОЖДЕНИЯ · **2** пакета нет.
Без пакета печатает, чего именно ждёт, и не падает трейсбеком.

## 4. Три бага, найденных при отладке (честно)

| Баг | Как проявился | Исправление |
|---|---|---|
| Неверные пути принятых файлов | `✗ нет файла: geo/block/cerebral_nexus.geo.json`, `textures/block/incubating.png`, `thermal_shock.png` | реальные пути: `geo/entity/`, `textures/mob_effect/` — взяты из 3.6.0-R |
| Неверный разбор `overlay.txt` | `✗ overlay: 0 из 2` на верном пакете | формат `src -> dst \| sha256`: я не отрезал хвост с хешем от пути назначения |
| Нет Pillow в `sys.executable` | `glow_check → код 1` вместо кода 2 | автопоиск интерпретатора с Pillow (`/tmp/vv/bin/python`) |

Все три были **ошибками моего скрипта**, а не дефектами сдачи. Если бы не
отладка на живом пакете, приёмка 3.7.0 забраковала бы корректную сдачу по
overlay и по «ненайденным» файлам.

## 5. Что осталось непроверенным

- **Pillow в системе отсутствует.** Скрипт ищет `/tmp/vv/bin/python`; если venv
  не создан (а песочница его уже теряла между сессиями), `glow_check` не
  запустится и приёмка скажет «нет Pillow». Нужно `python3 -m pip install Pillow`
  либо восстановить venv. **Это единственная внешняя зависимость приёмки.**
- **Синтетические пакеты, а не сдача Художника.** Реальный `Carnis_3.7.0_A4p7_palette.zip`
  ещё не появлялся; при первом появлении прогнать сразу.
- **`sha256sum -c` требует coreutils** в PATH — в песочнице есть, на CI тоже.
- Настоящий ID прогона CI для 3.7.0 будет известен только после сборки.
