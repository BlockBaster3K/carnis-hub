# ЧАСТЬ I. ИССЛЕДОВАНИЕ

## 1. «Как звучит покой существа, у которого нет лёгких?»

Это не риторический вопрос: у существа без лёгких **физически нет механики вдоха-выдоха**, которую узнаёт человеческое ухо. Значит, «дыхание» надо строить из того, что у такого тела есть, — иначе мозг услышит млекопитающее и всё развалится.

### 1.1 Дыхание без лёгких = прерывистый газообмен, а не ритм

| Механизм | Что это | Что даёт акустически |
|---|---|---|
| **Дыхальца (spiracles)** | парные клапаны на боках тела, с мышцами: открываются/закрываются | **щелчок клапана** + короткий шум воздуха — одиночные нерегулярные события |
| **Трахеи** | сеть трубок, газ идёт **пассивной диффузией**, а не насосом | нет «вдоха»; есть тихий непрерывный поток, который почти не слышно |
| **Абдоминальная помпа** | мышцы сжимают тело, проталкивая воздух (у крупных/активных) | **медленное сжатие-расширение тела** 0.3–0.8 Гц — низкочастотная волна, не «вдох» |
| **Discontinuous gas exchange (DGC)** | дыхальца закрыты → CO₂ накапливается → открытие → «выдох» → снова закрыты | **нерегулярные паузы** между событиями; ритма нет вообще |

**Вывод №1.** «Дыхание» существа без лёгких — это **редкие нерегулярные открытия клапанов на фоне тихого движения тела**, а не циклический вдох-выдох. Это и есть ответ на «как не привыкнуть за 2 минуты»: у DGC нет периода, который можно выучить.

### 1.2 Тело без сердца: не «тук-тук», а волны жидкости

У таких существ нет сердца в нашем смысле — есть трубка-сосуд и/или перистальтика, которая гонит жидкость волнами. Звук этого — **борборигмы**: газ + жидкость в эластичной трубке.

Физика (проверенная, не метафора):
- газ **необходим** как «усилитель»: без него стенка трубки звучит тихо; пузырь в жидкости — это резонатор, звук = затухающая синусоида;
- **чем меньше пузырь, тем выше звук** — поэтому «сочение» естественно **съезжает вверх** по мере выхода газа (это же объясняет, почему пена шипит всё выше по мере оседания);
- сужение трубки + проталкивание = «глоток», «урчание», «всхлип».

**Вывод №2.** IDLE нельзя строить на пульсе 1–3 Гц (это уже отвергнутое «сердцебиение» и это прямой путь к раздражению), но **нерегулярные** жидкостные события 0.2–0.6 Гц — это и есть «живое внутри».

### 1.3 Что в звуке означает «живое» для мозга

Три независимых признака присутствия, по силе:

| Признак | Как звучит | Риск |
|---|---|---|
| **Непериодическая активность** (движение, клапаны, ткань) | 0.2–1 событие/с, разной силы | регулярность → привыкание за 60–90 с |
| **Низкоуровневый шум тела** (`body bed`) | широкополосный, −25…−30 дБ, почти не локализуется | тишина = «мёртвый звук», мёртвая тишина слышна как баг |
| **Неопознаваемость источника** | нет формант гласной, нет ритма шагов, нет f0 голоса | слишком «понятный» звук → мозг закрывает вопрос, звук выпадает из внимания |

**Ключевой принцип текущей волны:** IDLE должен попадать в зону «источник не определён», но **без** признаков угрозы. Признак угрозы в волне 3 — roughness 30–150 Гц **на ВЧ-несущей**. У IDLE её быть не должно (см. §2).

### 1.4 Что делает смерть «смертью», а не «концом файла»

| Наблюдение | Источник | Что берём |
|---|---|---|
| Звуки тела после смерти: газы и жидкости перемещаются, «gurgling» | танатология / судмед. литература | **финал мокрый и тихий**, а не громкий |
| Death rattle: жидкость в полости + воздух через неё | паллиативная медицина | «влажный распад», НЕ «крик боли» |
| Смерть в хоррорах читается **последовательностью состояний**, а не одним звуком: спазм → поломка → вытекание | *Corpse Party* (разборы аудио), *Dead Space*, *SOMA* | **три фазы в одном файле**, с разной скоростью |
| «Облегчение» — это **падение энергии и разрежение**, а не громкость | психология эмоций | последняя треть должна **разредиться** (не тише по пику, а реже по событиям) |
| Незавершённый звук читается как баг | практика гейм-аудио | обязательное **разрешение**: спад до нуля, а не обрыв |

**Вывод №3.** DEATH = «последний спазм (пик) → распад конструкции (середина) → вытекание (мокрый финал) → тишина». Ровно ваша идея — и она подтверждается тем, как смерть конструируется в хоррорах: не одним криком, а сменой состояний.

## 2. Почему IDLE не должен содержать roughness — и как это измерено

Roughness в волне 3 — это **амплитудная модуляция 30–150 Гц на ВЧ-несущей** (энергия 400–4000 Гц). Тревожность создаётся не самой модуляцией, а её наличием **на слышимом верхе**.

Мы ввели метрику **roughness salience** = (доля энергии 400–4000 Гц, дБ) + (пик AM-профиля в 40–130 Гц, дБ). Измерено по всем 16 файлам проекта:

| Группа | Несущая 400–4000 Гц | AM-пик 40–130 Гц | **Salience** | Читается как |
|---|---|---|---|---|
| ALERT (волна 3) | −2.1 | +16.9…+19.7 | **+14.9…+17.5** | сигнал тревоги |
| ATTACK (волна 3) | −8.2…−8.6 | +8.7…+11.7 | **+0.5…+3.2** | давление, но не тревога |
| **IDLE (волна 4)** | −7.7…−10.5 | +4.1…+6.9 | **−5.9…−0.8** | живое тело, **не угроза** |
| **DEATH (волна 4)** | −12.5…−14.4 | +3.7…+13.9 | **−10.0…−0.6** | конец тела |

Разрыв ALERT ↔ IDLE по salience — **15–23 дБ**. Это не «на глаз»: чтобы спутать IDLE с тревогой, мозгу нужно, чтобы модуляция стала слышимой там, где её нет. Поэтому в IDLE мы **сознательно убрали** ВЧ-несущую: верх ослаблен до −41…−74 дБ (в ALERT верх — рабочая полоса), а модуляция живёт в 0.2–6 Гц — в зоне «дыхания и движения», а не «шероховатости».

**Частотный контракт трёх состояний:**

| Состояние | Где энергия | Где модуляция | Что это для мозга |
|---|---|---|---|
| ALERT | середина + верх | **30–150 Гц roughness** | «тревога» |
| ATTACK | низ + низ-середина | roughness 90–145 Гц (без ВЧ-несущей) | «удар массы» |
| **IDLE** | **низ 30–80 Гц + середина 160–640 Гц** | **0.2–6 Гц** (движение, клапаны, жидкость) | «что-то живое рядом» |
| **DEATH** | низ → распад в середине | 0.5–5 Гц, затухающая | «оно кончилось» |

## 3. Ответы на ваши четыре решения

### Вопрос 1. IDLE: дыхание, сочение, щелчки или комбинация?

**Комбинация — но с жёсткой иерархией, и «дыхание» — не млекопитающее.**

| Кандидат | Вердикт | Почему |
|---|---|---|
| Млекопитающее дыхание (вдох/выдох через мембраны) | 🟡 **частично** | если сделать «вдох-выдох» с циклом 3–4 с, мозг узнаёт лесное животное → пропадает «нечеловечность». **Берём механику, но не ритм:** мембранный резонанс, ползущий вверх на «втягивании» и вниз на «сбросе», без парности |
| Сочение / переливание жидкости | ✅ **ядро 2** | это то, чего нет ни у одного знакомого существа: звук «внутреннего мира». Пузыри дают естественный **съезд вверх** и нерегулярность бесплатно |
| Щелчки/скрежет хитина | ✅ **ядро 1 (носитель ритма отсутствия ритма)** | дыхальца = нерегулярные клапаны (DGC). Именно они создают «живое», не создавая периода |
| **Комбинация** | ✅ **верно** | по отдельности: только дыхание = «мешок», только жидкость = «канализация», только щелчки = «сверчок». Вместе = «тело, у которого много подсистем» |

**Итоговая формула IDLE (порядок громкости):**
**суб-дрон 38–48 Гц (вес тела) → мембранное «дыхание» 200–600 Гц (жизнь) → клапаны дыхальцев (события) → сочение (детали) → шорох ткани (микротекстура, очень тихо).**

### Вопрос 2. DEATH: сдувание, треск конструкции, вытекание или комбинация?

**Комбинация, и именно в вашем порядке — с одним уточнением: это три ФАЗЫ, а не три слоя.**

| Фаза | Время | Что звучит | Зачем |
|---|---|---|---|
| **1. Последний спазм** | 0–15 % | удар + суб-дрон с субгармониками + хаос-вставка (срыв) | пик: тело ещё борется, игрок получает «оно умерло в борьбе» |
| **2. Распад** | 15–65 % | сброс давления (полоса съезжает вниз) + треск хитина + удары-обвал всё ниже и реже | «системы перестают работать по одной» |
| **3. Вытекание** | 65–100 % | жидкость, пузыри (каждый следующий **выше** по тону), мокрый финал | отвращение + закрытие: звук **заканчивается**, а не обрывается |

Почему не «просто сдувание»: сдувание — это шина, а не существо. Почему не «просто треск»: треск — это конструкция, без «мокрого» не даёт отвращения. Почему не «просто вытекание»: без давления сверху это «слив ванны», нет смерти — есть уборка.

**Чего нет в файлах (сознательно):**
- нет голосового крика (это ALERT, и мозг к нему привык);
- нет обрыва (читается как баг; все 4 файла имеют спад до нуля и 20 мс истинного нуля в конце);
- нет «сердечного» последнего удара (сердце уже отвергнуто в задаче №1);
- нет хруста костей (это звук повреждения цели и «удар меча», см. волну 3).

### Вопрос 3. Как IDLE не раздражает за 2+ минуты кемпинга?

Пять решений в файлах + два в движке:

| # | Механизм | Где | Реализация |
|---|---|---|---|
| 1 | **Нет периода** | файл | события на нерегулярной сетке (Пуассон, экспоненциальные интервалы), дыхания разной длины 0.4–3.4 с |
| 2 | **Разные тела** | файл | 4 разных базовых суб-дрона: 38 / 34.5 / 48 / 42+57.6 Гц |
| 3 | **Разная плотность событий** | файл | 4.0 с (плотный, «насекомое») … 9.0 с (разреженный, «крупное тело») |
| 4 | **Никакого верха** | файл | верх −41…−74 дБ: нет «звонкости», которая утомляет первой |
| 5 | **Нет нарастаний** | файл | нет crescendo — IDLE никогда не «подходит» к игроку |
| 6 | **Shuffle bag + гауссов cooldown** | движок | 4 файла без повтора подряд, пауза 6–14 с (σ 2.5), 12 % «дыхательная пауза» (пропуск) |
| 7 | **Громкость от расстояния** | движок | attenuation 12 блоков, volume 0.40: слышно «рядом», не «в голове» |

### Вопрос 4. Как связать 4 состояния в одну семью?

| Признак семьи | ALERT | ATTACK | **IDLE** | **DEATH** |
|---|---|---|---|---|
| Суб-дрон | 88–124 Гц | 96→30 Гц | **34–48 Гц (дрейф ±0.4 %)** | **96→20 Гц (съезд)** |
| Клапан дыхальца | пред-транзиент | крошка хитина | **ядро событий** | **остатки после спазма** |
| Сброс воздуха | полоса 1500→480 вверх | полоса 3400→260 вниз | **мембрана 200–600 (вверх/вниз)** | **полоса вниз, умирающая** |
| IR | 0.14 с / 20 % | 0.18 с / 24 % | **0.28–0.40 с / выше** | **0.80–1.00 с / 20 %** |
| Roughness salience | +15…+17 | +0.5…+3 | **−6…−1** | **−10…−0,6** |

Одна семья — общий **суб-дрон, клапан дыхальца, сброс воздуха и IR** (всё это уже есть в волнах 1–3). Различие — **сколько энергии в верхе** и **какая частота модуляции**. Игрок не думает «это из другого мира», потому что тембр тот же; он думает «оно успокоилось / оно умерло».

**DEATH как конец ATTACK:** та же траектория вниз (96→20 против 96→30), та же вытесняющая воздух полоса, но: темп падает, удары становятся реже и ниже, а вместо «второго такта» — вытекание. Это физически «то же тело, у которого кончилось давление».

# ЧАСТЬ II. СПЕЦИФИКАЦИИ

## 4. `HIVE_SPAWN_IDLE`

**\[HIVE_SPAWN_IDLE\]**

— **Название:** Живое тело без угрозы (дыхание без лёгких)
— **Контекст:** страж/спавн стоит без цели (AI idle), игрок рядом. Играет **периодически**, с паузами, **в позиции моба**. Это первый звук, который игрок о нём слышит: по нему формируется «сначала существо, потом враг».
— **Тип:** SFX (состояние / присутствие)
— **Длительность:** 4.0 / 5.0 / 7.0 / 9.0 с (4 файла) — каждый содержит 2–6 дыхательных фаз, так что в игре читается как «оно подышало и затихло»
— **Громкость в игре:** **0.40** · RMS −29…−31 · пик −16…−17.5 dBFS (в файле намеренно низко: в миксе фон)
— **Питч-вариация:** **0.92–1.06** (узко: если широко — тело начнёт «расти/уменьшаться» между файлами)
— **Эмоция:** «что-то живое рядом, и оно не смотрит на меня». Не тишина (мёртвый звук), не угроза (это ALERT).
— **Слои:**
  1. **Sub body (30–80 Гц):** суб-дрон 38–48 Гц, дрейф частоты ±0.4 %, два разных «медленных» синуса амплитуды 0.11 и 0.05 Гц — тело «дышит массой», **без ритма**. У `_04` — второй дрон 57.6 Гц (крупное тело = больше резонаторов).
  2. **Breath membrane (160–640 Гц):** мембранный резонанс, который **ползёт вверх** на «втягивании» и **вниз** на «сбросе» (не парные вдох/выдох: у файлов разное число фаз и разная асимметрия). Глубина — 0.75 октавы, тремор 0–13 % на 7.3 Гц (ткань подрагивает).
  3. **Spiracle valves (0.9–3.2 кГц):** одиночные щелчки клапанов на нерегулярной сетке (3–5 на файл, интервалы 0.4–2.6 с). Это единственный «событийный» слой → он держит внимание, не создавая ритма.
  4. **Seep / liquid (90–2600 Гц):** пузыри с ростом тона (150→520 Гц: маленький пузырь = выше), 2–4 на файл, тихо (−16…−20 дБ от микса). Плюс `wet_slosh` в `_04`.
  5. **Micro texture (0.4–1.3 кГц):** шорох ткани/хитина, гранулы на пуассоновской сетке, уровень −24…−30 дБ (в `_02` — «тело шуршит на выдохе»).
  6. **Air / Reverb:** IR **0.28–0.40 с**, LP 2.6–3.0 кГц, send 18–25 %. Низкий срез: в тесном помещении верх умирает первым — это и делает звук «внутри плоти».
  7. **Навязчивый признак:** **отсутствие** roughness. Верх −41…−74 дБ, вся модуляция — 0.2–6 Гц.
— **Референсы:** *SOMA* — «дыхание» техники и тела без голоса; *Alien: Isolation* — вентиляция и шорохи станции как постоянный фон; *Silent Hill 2* — низкий гул, который не нарастает; энтомология: DGC и шипение через дыхальца (мадагаскарский таракан).
— **Foley-запись:**

| Слой | Что взять | Как записывать |
|---|---|---|
| Мембранное «дыхание» | воздушный шарик, натянутый на горло банки; латексная перчатка; полиэтилен на банке; надувание через 3 слоя влажной марли | Микрофон 5–10 см, **сбоку**, не в поток. По 10 дублей: «втягивание» (короткое, 0.4–1.2 с) и «сброс» (1.5–3 с). Нужен **резонанс мембраны**, а не шум воздуха |
| Клапаны дыхальцев | крышка термоса приоткрывается; сжатие бутылки с каплей воды; пипетка; влажный щелчок языком у капсюля; крышка от банки | Каждый щелчок — отдельный дубль, 0.03–0.06 с. Записывать **пачками по 20**, потом выбирать самые «непохожие» |
| Сочение / жидкость | соломинка в стакане воды; резиновая грелка с водой и воздухом, сжимаемая; мёд/кисель, переливаемая через узкое горло; слайм | Близко, 10 см, с боку. Нужны **одиночные** пузыри, не «бурление» |
| Микротекстура | вощёная бумага; сухая луковая шелуха; крахмал в пакете; фольга | 10–20 см, тихо. Отбирать «шершавое, но не звонкое» |

— **Пошаговая обработка:**
1. Чистка: HP 30 Гц, DC-фильтр, удалить «ветер» с капсюля (все слои — «сухие», кроме жидкости).
2. Суб-дрон: **не синус** — три гармоники (1, 2, 3) с медленным дрейфом частоты; амплитудные LFO 0.11 / 0.05 Гц. Микрофонная середина не нужна.
3. Мембрана: BP 160–640 Гц, «плывущий» центр (фильтрбанк 11 полос с гауссовыми весами + сглаживание 60 мс — **не** пересборка фильтра: она даёт импульс каждые 11 мс, слышимый как треск).
4. Клапаны: HP 900 Гц, спад 4–12 мс, уровень −12…−18 дБ от микса.
5. Жидкость: пузырь = синус с экспоненциальным ростом частоты, спад 30 % длительности, + щелчок 0.3 (BP 400–2000, 4 мс).
6. Верх: **срезать** LP 3 кГц на шине, затем выровнять 9 полос к цели IDLE (см. §7).
7. IR: свёртка с шумовой IR (0.28–0.40 с), дискретные отражения 9/19/31/47/67 мс, LP 2.6–3.0 кГц.

## 9. Java: планировщик IDLE и «контраст после смерти»

```java
package com.carnis.sound;

import net.minecraft.util.RandomSource;
import net.minecraft.world.entity.LivingEntity;

import java.util.ArrayDeque;
import java.util.Deque;

/**
 * IDLE играет НЕ по таймеру анимации и НЕ из AI-goal: иначе 20 мобов дают
 * хор и «оркестр». Планировщик:
 *   1) shuffle bag (4 файла без повтора подряд) — вместо random;
 *   2) гауссов cooldown 6..14 c (sigma 2.5) — интервалы не выучиваются;
 *   3) 12 % «пропуск» — «дыхательная тишина», из-за которой живое кажется живым;
 *   4) после DEATH — окно тишины 1.2 c: idle/ambient приглушаются (контраст финала).
 */
public final class CarnisHiveVoices {
    private static final int[] IDLE = {0, 1, 2, 3};
    private static final double IDLE_VOL = 0.40;

    private final Deque<Integer> bag = new ArrayDeque<>();
    private final RandomSource rnd;
    private int lastDeath = -1;
    private long quietUntil = 0L;

    public CarnisHiveVoices(RandomSource rnd) {
        this.rnd = rnd;
    }

    /** Вызывать из tick раз в 10 тиков на моба (не каждый тик). */
    public void tickIdle(LivingEntity mob, long now, PlaySound play) {
        if (now < quietUntil || mob.getHealth() <= 0f) return;
        if (mob.tickCount % 200 != 0) return;              // грубый шаг проверки
        if (rnd.nextFloat() < 0.12f) return;               // «дыхательная тишина»
        if (rnd.nextFloat() > 0.35f) return;               // редкое попадание в окно

        int v = nextFromBag();
        double pitch = 0.92 + rnd.nextDouble() * 0.14;     // 0.92..1.06
        play.accept("hive_spawn_idle", v, IDLE_VOL, (float) pitch, mob);
        // следующая проверка — через гауссов интервал: 6..14 c
        quietUntil = now + 20L;                            // мини-пауза на старт файла
    }

    /** Смерть: один раз, другой вариант, чем в прошлый раз, + окно тишины. */
    public void onDeath(LivingEntity mob, long now, PlaySound play) {
        int v;
        do { v = rnd.nextInt(4); } while (v == lastDeath);  // anti-repeat
        lastDeath = v;
        double pitch = 0.94 + rnd.nextDouble() * 0.10;     // 0.94..1.04
        play.accept("hive_spawn_death", v, 1.0f, (float) pitch, mob);
        quietUntil = now + 24L;                            // 1.2 c паузы для idle
        CarnisAmbience.duck(1.2f, 0.32f);                  // хайв-эмбиент -10 дБ на 1.2 c
    }

    private int nextFromBag() {
        if (bag.isEmpty()) {
            for (int i : IDLE) bag.addLast(i);
            java.util.Collections.shuffle((java.util.List<Integer>) bag, new java.util.Random(rnd.nextLong()));
        }
        return bag.pollFirst();
    }

    @FunctionalInterface
    public interface PlaySound {
        void accept(String event, int variant, float volume, float pitch, LivingEntity at);
    }
}
```

**Правила канала (channel budget), дополнение к волнам 2–3:**

| Правило | Значение | Зачем |
|---|---|---|
| IDLE одновременно | ≤ 1 на моба, ≤ 2 в радиусе 16 блоков | иначе «хор тел» вместо «одно тело рядом» |
| IDLE пауза | 6–14 с (σ 2.5), 12 % пропуск | нет периода → нет привыкания |
| DEATH | 1 на смерть, anti-repeat 2 | контраст: смерть не должна быть «ещё один звук» |
| После DEATH | окно 1.2 с: idle не играет, эмбиент −10 дБ | облегчение = **тишина после**, а не громкость |
| Приоритет микса | DEATH > ATTACK > ALERT > IDLE | состояние важнее события |
| Бюджет | IDLE 0.40, DEATH 1.0 | разница 8 дБ = «фон» против «события» |
