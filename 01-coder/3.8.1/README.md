# Carnis: Adaptive Hivemind

*The Living Swarm Update* — мод для Minecraft 1.20.1 (Forge).

Живой улей заражает мир органикой: четыре стадии паразитизма, растущая сеть
ткани, макроскопические органы. Игрок находит Пульсирующее Сердце и его сеть,
сталкивается с Мясным Амальгамом и выживает против Роя с бронёй
Нейро-Резонатора, Био-Очистителем, Пневматическим Инокулятором и Кодексом
Карнис.

## Зависимости

Мод **работает без необязательных зависимостей** — достаточно Forge и GeckoLib.

| мод | нужно | сторона |
|---|---|---|
| Minecraft | 1.20.1 | клиент + сервер |
| Forge | 47.1.0+ | клиент + сервер |
| **GeckoLib** | **4.4.4+**, обязателен | клиент + сервер |
| Curios | необязателен для запуска; нужен обеим сторонам для слотов head/back | клиент + сервер |
| Patchouli | необязателен (книга рецептов) | клиент |
| SmartBrainLib (SBL) | необязателен (поведение мобов) | клиент + сервер |
| Lodestone | необязателен (оформление интерфейса) | клиент |
| Sound Physics Remastered | необязателен (объёмный звук) | клиент |

Без GeckoLib мод **не запустится** — это жёсткая зависимость. Curios и
остальные библиотеки необязательны для запуска Carnis. Curios необходим и на
клиенте, и на сервере только если нужны Curios-слоты; без него мод запускается,
но эти слоты недоступны.

Java 17.

исходниках нет, код мода распространяется под MIT — то есть сейчас GPL-код
в производную работу не попадает. Но Sound Physics — это **замена
саунд-движка**, поэтому он никогда не должен становиться обязательной
зависимостью: только soft dependency.

## Установка

1. Установить Forge 47.1.0+ для Minecraft 1.20.1.
2. Положить `carnis-<версия>.jar` в папку `mods`.
3. Положить `geckolib-forge-1.20.1-4.4.4+.jar` в `mods` — **и на клиенте, и
   на сервере**.
4. Необязательные моды — по желанию, на обеих сторонах, если они нужны
   обеим.

Подробный разбор требований: `00-board/reports/install_requirements.md` в
репозитории проекта.
