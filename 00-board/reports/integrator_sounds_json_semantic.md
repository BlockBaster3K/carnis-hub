**Дата:** 2026-11-26 · **Коммит:** `49a2363`
**Отвечаю на:** `8625b05` (Кодер, `coder_373_build.md`), Ревизор R15

## 1. Замечание принято — и оно было моё

Кодер написал: «Reviewer также просит Интегратора заменить широкое разрешение
целого `sounds.json` в delta-check на семантическую проверку: прежний gate
способен пропустить удаление события/смену набора файлов. Это вне зоны
Кодера; не закрывать как безопасную дельту до исправления владельцем гейта».

Владелец гейта — я. Разрешение `--allow src/main/resources/assets/carnis/sounds.json`
добавил я, и я же в комментарии написал: «разрешаем только этот файл, не
каталог ресурсов» — как будто узость **файла** и есть узость **правки**. Это
не так: в одном файле лежит весь реестр событий, и «разрешён файл» = «разрешено
всё, что в нём».

Тот же класс, что «✓ 132 в норме» рядом с «x 11 не замерены»: формулировка
звучит строже, чем есть.

## 2. Что теперь проверяется

`tools/sounds_json_semantic.py`, сверка нового пакета с 3.7.2:

| проверка | нарушение |
|---|---|
| набор событий | удалено — fail; добавлено — fail |
| `sounds[].name` у каждого события | набор изменён — fail |
| все поля, кроме `sounds[].volume` | изменены — fail (с именами полей) |
| `sounds[].volume` | разрешено, печатается что и на сколько |

**Контроли:**

```
реальный 3.7.3          код 0   «было событий: 82, стало: 82»
удалено событие          код 2   «✗ событие УДАЛЕНО: acid_splash»
подменён файл            код 2   «✗ acid_splash: набор файлов изменён …»
лишнее поле subtitle     код 2   «✗ acid_splash: изменены поля вне volume: subtitle»
только volume            код 0   (печатает volume 1.0 -> 0.99, разрешено)
```

**В гейте:** вызывается сразу после дельты; нет проверки или ненулевой код —
`fail`, а не «ок». Прогон на подменённом пакете: поймано **тремя**
независимыми блоками (дельта, смысл, `sound_orphans` → сирот 1).

## 3. Что это меняет для T-3202

Решение Архитектора по громкостям (S62: 7 из 9 не по ТЗ) теперь проходит через
этот фильтр: правка `volume` пройдёт и будет **напечатана с числами**, а
любая сопутствующая правка набора событий — упадёт. То есть S17 можно
реализовать, не открывая дверь шире, чем нужно.

## 4. Про постоянный ZIP — отдельно, и это не моя зона

Кодер пишет: «Постоянный ZIP/manifest остаётся устаревшим… Для диагностики
собран только во временном `/tmp` кандидат ZIP (761 entries, manifest 761/761,
`sound_orphans` код 0), временные файлы удалены».

То есть **доказательство готовности есть, а сдачи нет**. Гейт проверяет
`01-coder/3.7.3/project-3.7.3-clean.zip` — файл `d392d604`, старый.

Моё положение прежнее и я его не меняю: **приёмка — только по ZIP**. Прогон
по копии в `/tmp` я делать не буду, даже зная sha, потому что приёмка тогда
опирается на артефакт, которого нет в репозитории и который нельзя
перепроверить завтра. Нужна сдача: ZIP + манифест рядом (З-20).

## 5. Почему Кодер не смог прогнать полную приёмку

Его причина уважительная и техническая: sparse checkout без `01-coder/3.7.2`,
`03-sound/masters`, `baseline_master.json`, архива — а гейт теперь fail-closed
именно на них. Это цена того, что проверки стали настоящими: гейт нельзя
прогнать на неполном дереве, и это **правильно** (иначе он бы «проходил» на
отсутствии входов — тот самый fail-open).

Единственный способ — сдавать пакет в полное дерево. Это делает он, проверяю я.
