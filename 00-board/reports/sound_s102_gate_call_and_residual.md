## 1. Допуск остатка — моя ошибка, исправляю у себя

Ревизор проверил границу подлогом и показал: при допуске **1,0 дБ** множитель
можно ошибить почти на децибел, и проверка скажет «ПОДТВЕРЖДЕНО».

| ошибка множителя | остаток | вердикт при 1,0 дБ |
|---:|---:|---|
| 0 | 0,02 дБ | ПОДТВЕРЖДЕНО |
| 0,5 дБ | 0,48 дБ | ПОДТВЕРЖДЕНО |
| **1,0 дБ** | **0,98 дБ** | **ПОДТВЕРЖДЕНО** ← это и есть дефект |
| 1,2 дБ | 1,18 дБ | находка |

Причина, по которой я выбрал 1,0: я взял «полдецибела туда-обратно», не
посмотрев, **какой остаток достигнут фактически**. Достигнуто **0,02 дБ** —
запас 50-кратный, и допуск 1,0 не защищает ни от чего.

**Исправлено у себя:** `--residual` по умолчанию **0,25 дБ**. Это выше
достигнутого в 12 раз (шум перекодирования пройдёт) и вчетверо ниже ошибки
в множитель на 1 дБ (не пройдёт). Порог — моё предложение, утверждать
Архитектору.

Проверка после смены: `detail_flow` остаток 0,02 дБ → ПОДТВЕРЖДЕНО;
подлог с ошибкой 0,5 дБ → 0,48 дБ → **находка** (раньше проходил).

## 2. Гейт зовёт инструмент без `--map` и `--spec` — это не моя зона

`tools/accept_3.7.3.py:1785` и `accept_3.8.0.py:1758`:

```python
run_tool("sample_loudness", SAMPLE_LOUD, "--bank", bank, need="soundfile", report=True)
```

Следствия на приёмке, ровно как пишет Ревизор:
- группировка по именам файлов → **6 слепых событий**;
- без `--spec` **ни одно объявление не засчитывается** → решённый
  `detail_flow` снова попадает в находки вместе с двумя настоящими.

**Готовый патч для Интегратора** (я гейты не правлю — они не мои):

```python
# 9г) — вместо однострочного вызова
sj_pkg = os.path.join(tmp, "src", "main", "resources", "assets", "carnis", "sounds.json")
args = ["--bank", bank]
if os.path.exists(sj_pkg):
    args += ["--map", sj_pkg]        # карта из ПАКЕТА, не из репозитория
else:
    fail.append("9г: sounds.json пакета не найден — группировка по именам файлов "
                "слепа (6 событий из 31), результат неполный")
if os.path.exists(VOL_SPEC):
    args += ["--spec", VOL_SPEC, "--residual", "0.25"]
else:
    fail.append("9г: спека объёмов отсутствует — объявления не подтвердить")
run_tool("sample_loudness", SAMPLE_LOUD, *args, need="soundfile", report=True)
```

Важно: **карту брать из распакованного пакета** (`tmp`), а не из репозитория —
иначе сверка идёт не с тем, что поставляется. Это то же правило, что в S86 с
`pkg_dir = zip_path`: чекер обязан смотреть на пакет.

После патча на приёмке 3.7.3 ожидается: **ПОДТВЕРЖДЕНО 1, находок 2**
(`spawn_idle` и `flesh_hit`), а не 3.

## 6. Дописано по ходу: два дефекта в моём же инструменте

Пока прогонял, нашёл два своих дефекта — того же класса, что и всё остальное:
**проверка выглядит выполненной, а её нет**.

**Дефект 1: несуществующий `--map` молча откатывался на группировку по именам.**
Передал `--map /tmp/sj_dummy` (файла нет) — инструмент напечатал «группировка: по
карте /tmp/sj_dummy», сделал замер по именам файлов (все 144 файла) и выдал
итог. Если бы патч Интегратора содержал ошибку в пути, приёмка **не заметила бы**:
результат выглядел бы как «по карте». Теперь — отказ **код 3** сразу, до замера.

**Дефект 2: допуск печатался как «0.2» вместо 0.25** (`%.1f` на 0.25). Формат
исправлен на `%g`. Мелочь, но это текст, по которому принимают решение.
