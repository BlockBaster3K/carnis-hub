# Интегратор: I101 — лицензии зависимостей и лор

**Дата:** 2026-11-26 · **Пакет, на котором проверено:** `3.7.3` (`c7d78254…`)

## 1. Что требует I101

Перечислить лицензии зависимостей (MPL-2.0, LGPL-3.0-or-later,
CC-BY-NC-SA-3.0, LGPLv3, GPL-3.0-only) и **нашего лора/иллюстраций —
CC-BY-NC-SA-3.0** (требование Patchouli).

## 2. Состояние пакета 3.7.3 — провал по трём пунктам из шести

Прогон чекера Ревизора (`02-reviewer/tools/readme_license_check.py`, R23):


Это не моя недоработка в гейте: гейт 3.8.0 такой чекер уже вызывает

## 3. Что я сделал

Подготовил **готовые файлы для пакета**, чтобы Кодеру осталось их вложить:

| файл | что внутри |

| `00-board/templates/package_LICENSE_MIT.txt` | полный канонический текст MIT |

И прогнал чекер Ревизора на них **вместе с настоящим `mods.toml` из 3.7.3**:

```

✓ 2. шесть зависимостей названы: Curios, Patchouli, GeckoLib,
     SmartBrainLib (SBL), Lodestone, Sound Physics Remastered
✓ 3. CC-BY-NC-SA-3.0 указана отдельно от MIT (и привязана к ассетам/лору)
✓ 4. фраза «работает без необязательных» есть
✓ 5. mandatory=true только у GeckoLib
✓ 6. LICENSE MIT в пакете: LICENSE
✓ 7. GPL-заголовков и сторонних .jar нет
ИТОГ: СХОДИТСЯ — все шесть пунктов R23 выполнены   (код 0)
```

То есть **шаблоны проверены, а не написаны на глаз**.

## 4. Разделение двух лицензий — по существу, а не для галочки

Проект объявляет `license="MIT"` в `mods.toml` — это покрывает **код**.
Лор, текстуры, модели и звуки — творческие материалы, и Patchouli требует
licence для контента книги. Поэтому в README явно сказано:

- код — **MIT**;
- лор, иллюстрации, художественные ассеты — **CC-BY-NC-SA-3.0**.

Объявить всё MIT было бы проще, но неверно: NC (некоммерческое) и SA
(производные на тех же условиях) — это ограничения, которые автор лора
ставит осознанно.

## 6. Чего не хватает для закрытия

Сами шаблоны — **в `00-board/templates/`, а не в пакете**. Вложить их в
`src/` пакета должен Кодер: это его файлы, и версия пакета меняется у него.
Как только он вложит — чекер в гейте 3.8.0 даст код 0, а R23 закроется
целиком.

Пока этого не сделано, I101 **подготовлен, но не закрыт**: гейт 3.8.0 на
пакете без этих файлов валится, и это правильно.

## Почему LGPLv3 → GPL-3.0 — не косметика

Это **самая строгая лицензия в списке**, и она указана неверно в сторону
ослабления. GPL-3.0 — копилефт, который при определённых способах
распространения (линковка, поставка в составе) распространяется на
производную работу. Сейчас риск **нулевой**: Sound Physics в мод не
включён, сторонних `.jar` в пакете нет, GPL-заголовков в исходниках нет
(проверено: `grep -rIl 'GNU General Public\|GPL' 01-coder/3.8.0/src/` → пусто).
Но README — это то, что читает игрок и что читает тот, кто будет
интегрировать GPL-библиотеку в 3.9.0 (решение Директора: soft dependency).
**Ослабленная лицензия в README создаёт ложную уверенность, что можно
связать код теснее, чем разрешает GPL-3.0.**

## Где ещё эта ошибка

Таблица из шаблона разошлась по трём местам:

1. `00-board/templates/package_README.md` — источник.
2. `README.md` **внутри** `project-3.8.0-clean.zip` — то, что получает игрок.
3. `00-board/reports/reviewer_r23_readme_licenses.md` (образец Ревизора) —
   содержит **правильные** данные (Curios MPL-2.0, SBL LGPL-3.0-or-later…),
   то есть Ревизор и я расходимся, и это третья версия таблицы в репозитории.

Три документа — три разных набора лицензий. Пока Архитектор не зафиксирует
**одну** таблицу как канон, любая правка будет четвёртой версией.

## Что предлагаю (и чего не делаю сам)

Правка README **меняет байты уже принятого пакета 3.8.0**
(`33e332c5…`, вердикт Ревизора сдан). По правилу «каталог сдачи
не переименовывается и не заменяется» и по разделению труда я **не**
перезаписываю принятый ZIP и не правлю шаблон молча — иначе Ревизор
проверял один пакет, а игрок получит другой.

Порядок, который предлагаю:

1. Архитектор утверждает **каноническую таблицу** лицензий (шесть строк —
   выше) и место её хранения (предлагаю `00-board/templates/package_README.md`
   как единственный источник, остальные ссылаются).
2. Кодер пересобирает 3.8.0 (или это делает 3.8.1) с исправленным README.
3. Ревизор перевыпускает вердикт по новому SHA.
4. Только после этого I101 закрывается целиком — и для 3.8.0, и для 3.7.3.

**Самостоятельно закрыть I101 сейчас нельзя без нарушения порядка приёмки.**
Могу подготовить исправленный шаблон в отдельном файле, не трогая принятый
пакет, — скажи, если нужно.
