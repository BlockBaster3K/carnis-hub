## 0. ДИАГНОЗ: почему текущий звук читается как «противный, некрасивый»

Разбор старого звука дал три конкретные причины (все три — типовые ошибки органического хоррора в игровом аудио):

| # | Что было | Почему это «противно» | Что делаем |
|---|---|---|---|
| 1 | **Непрерывный узкий резонанс в 500–1500 Гц** (гул «в нос») | Ухо имеет максимум чувствительности 2–4 кГц, а полоса 500–1500 Гц при постоянном присутствии читается как «заложенное ухо / гудение трансформатора». Именно она даёт ощущение физического дискомфорта, а не страха | Полосы **широкие (Q 0.9–1.6) и дрейфующие**; центр «пустой» — 1–3 кГц; вся жизнь — в низе и в 4–12 кГц |
| 2 | **Ритмические микрособытия** (бульки/капли на почти фиксированном интервале) | Мозг мгновенно вычленяет пульс → «сердцебиение» → раздражение + потеря тревоги (тревога = непредсказуемость) | Мокрые события **редкие** (1 на 9–17 с), с плавной атакой, без «капельного» транзиента, и **никогда не в такт** |
| 3 | **Биения суб-тонов в 0.8–3 Гц** | Два близких низких тона дают амплитудное биение — это буквально «пульс» на уровне физики | Расстройка суб-тонов снижена до **0.4 Гц** (дыхание объёма, не пульс); добавлена анти-пульс микромодуляция ±1.5% |

**Плюс отсутствовала «красота».** Хоррор работает на контрасте: чтобы было жутко, должно быть *красиво и неправильно*. Старый звук был только «неправильно». Новый построен вокруг слоя **«поющие жилы»** — редкие далёкие интонационные партиалы (не мелодия, не аккорд), которые дают масштаб и чужую красоту.

**Итоговая формула нового звука Улья:**
> низкое давление полости (тело) + широкое дыхание массы (жизнь) + редкие мокрые микрособытия (плоть) + далёкие поющие жилы (красота) + шёлковый воздух (пространство).
> Никакого ритма. Никакого гудения в середине. Ни одного опознаваемого события в подложке.

## 1. ОБЩИЕ ПАРАМЕТРЫ (для всех трёх звуков)

| Параметр | Значение | Почему |
|---|---|---|
| Формат | OGG Vorbis (libvorbis, q4) | единственный читаемый Minecraft формат |
| Частота | 44100 Hz | стандарт ванили; 48k допустим, но не нужен |
| Каналы | **MONO** | без mono нет 3D-аттенюации в OpenAL (звук «прилипнет» к игроку) |
| True Peak | ≤ −3 dBTP (петли), ≤ −1 dBTP (one-shot) | наложение нескольких источников не даёт клиппинга |
| Громкость | AMBIENT −26 LUFS · CLOSE −24 LUFS · PULSE −20 LUFS | задаётся `volume` в sounds.json, финальный уровень — слайдером игрока |
| Длина | петли 120 с · PULSE 13.4 с | 120 с — минимальная длина, при которой повтор не детектируется (см. §5) |
| Стык петли | ≤ 2 мс по амплитуде | круговое сглаживание 10 мс, см. §4.6 |
| Целевой тембр (9 полос, дБ отн. суммы) | `[-11, -5.5, -6, -10, -13, -18.5, -22.5, -26.5, -34]` | «тёмный, но живой»: масса внизу, шёлк сверху, центр пустой |

# 2. СПЕЦИФИКАЦИИ

## 2.1 `HIVE_AMBIENT` — «Дыхание биомассы» (основной фон рядом с hive-блоками)

**\[HIVE_AMBIENT\]**

— **Название:** Дыхание биомассы
— **Контекст:** игрок в 8–32 блоках от блоков/структур Улья, Улей не агрирован. Подложка всей заражённой зоны; никогда не «выключается» — только сменяется по уровню заражения. Играет как `TickableSoundInstance` (не через `playSound` каждый тик).
— **Тип:** Ambience
— **Длительность:** **120 с** (бесшовная петля, `stream: true`)
— **Громкость в игре:** 0.34 (`volume`), целевые −26 LUFS
— **Питч-вариация:** 1.0 (петля; НЕ менять питч — иначе «плывёт» стык)
— **Эмоция:** давление, «мир вокруг живой и огромный»; настороженность без отвращения. Это фон, который хочется оставить включённым.
— **Слои (методология Шага 1):**
  1. **Low body (25–190 Гц):** давление полости. Суб-тон 41 Гц (+обертон 82 Гц для читаемости на ноутбуках) с биением 0.4 Гц + широкое шумовое «тело» 55–190 Гц, центр дрейфует ±10% с периодом 20–40 с. Пропорция: ~45% энергии.
  2. **Mid texture (190–900 Гц):** «дыхание массы» — широкополосный шум с формантами на ~420 / 880 / 1500 Гц, каждая шириной 0.85–0.7 октавы (НЕ пики!), центры дрейфуют на ±0.14 окт. + «натяжение мембраны» 260 / 490 / 1090 Гц (тише, ±0.12 окт.). Пропорция: ~30%.
  3. **High detail (1.5–12 кГц):** (а) **поющие жилы** — 12–18 редких событий за 120 с: 4–9 с каждое, 2–3 ингармонических партиала, лёгкое глиссандо ±0.6%, экспоненциальное затухание 1.6–3.2 с; тона из ряда D-минор-пентатоники (329/392/440/494/587/659 Гц) — «красиво, но не по-человечески»; (б) мокрые микрособытия 1 на 9–17 с, 0.22–0.65 с, широкополосные, с плавной атакой (без «капли»).
  4. **Air / Reverb (6–16 кГц + пространство):** «шёлковый воздух» 4.2–13 кГц с медленной эволюцией ±0.16 окт. + свёртка с IR **каверны**: RT60 ≈ 5.5 с (decay 1.85 с при 44.1k), LP 2.9 кГц, send 48%.
— **Референсы:** *Dead Space* «Creepy Ambi Patch» (рандомизация без узнаваемого паттерна); *SOMA* — IR живого комплекса; *Silent Hill 2* — «красивое, но неверное» (без мелодии); *Alien: Isolation* — станция «под нагрузкой» (сухой лёд как идея постоянного структурного шума).
— **Foley:** см. §3.1 — полный список предметов и записи.
— **Варианты:** **3 файла** (`_01 balanced`, `_02 choral` — больше жил, «зовущий», `_03 wet` — больше плоти, «влажный»). Различия — реальные (разные веса слоёв), а не питч. Плюс направление B: `hive_ambient_tonal_01` (консонансный дрон D2) — см. §6.
— **Priority:** **High**

**Тех:** `AMBIENT` · att 0 (non-positional, звучит «вокруг») · stream true · loop · bank 3 · crossfade между уровнями 3 с · subtitle отсутствует.

## 2.2 `HIVE_AMBIENT_CLOSE` — «Внутри тела» (усиление внутри hive-структуры)

**\[HIVE_AMBIENT_CLOSE\]**

— **Название:** Внутри тела
— **Контекст:** игрок **внутри** структуры Улья (в помещении из hive-блоков, в «полости»): 0–8 блоков от блоков со всех сторон, либо в зоне с флагом `INSIDE_HIVE`. Заменяет `HIVE_AMBIENT` с кроссфейдом 4 с.
— **Тип:** Ambience
— **Длительность:** **120 с** (бесшовная петля)
— **Громкость в игре:** 0.42 · целевые −24 LUFS
— **Питч-вариация:** 1.0
— **Эмоция:** клаустрофобия, интимность чужого тела: «я внутри него, и оно это знает». Тревожнее, но не громче.
— **Слои:**
  1. **Low body (25–190 Гц):** то же давление, но **ближе и суше** — меньше реверба, чуть больше 90–190 Гц (грудная клетка рядом). Добавлен очень тихий «грудной» резонанс 118 Гц (широкий, Q≈1.2) — «я слышу его грудную клетку».
  2. **Mid texture (190–1100 Гц):** дыхание массы с центром выше (520 Гц вместо 420) и шире: близость = больше середины, но по-прежнему без пиков. Мембрана громче (0.75 против 0.45).
  3. **High detail (1.5–14 кГц):** мокрые события **чаще** (1 на 5–10 с) и **ярче** (полосы 0.5–3.2 кГц вместо 0.32–2.4 кГц); жилы — тише и «задушены» (0.5 от обычного) — красота уступает близости.
  4. **Air / Reverb:** IR **меньше**: RT60 ≈ 3.0 с, LP 3.8 кГц, send 30% — «тесно, стены рядом». Плюс постоянный очень тихий «пульс конструкции» −24 дБ (не сердцебиение! — нерегулярный, 0.15–0.35 Гц).
— **Референсы:** *SOMA* — «room size system» (тесные отсеки звучат суше, но «дороже»); *Dead Space* — мембранные двери Ishimura; *Amnesia* — Brute «в трубе» (звук из полости).
— **Варианты:** **2–3 файла** (`_01 balanced`, `_02 wet`). Для бесконечного пребывания внутри — 3.
— **Priority:** **High**

**Тех:** `AMBIENT` · att 0 · stream true · loop · bank 2–3 · кроссфейд с `HIVE_AMBIENT` 4 с (взаимоисключающие, одновременно не играют).

## 2.3 `HIVE_PULSE` — «Вздох Улья» (редкое одиночное событие)

**\[HIVE_PULSE\]**

— **Название:** Вздох Улья
— **Контекст:** редкий одиночный акцент в заражённой зоне (интервал 45–150 с, гауссово распределение): Улей «вдыхает» — как будто огромная масса набирает воздух и выдыхает. НЕ сердцебиение, НЕ «бульк»: это единственный момент, когда фон «проявляет себя». Играет на позиции ближайшего узла Улья (позиционно!).
— **Тип:** Ambience (акцент) / SFX
— **Длительность:** **13.4 с** (вдох 3.4 с → горло 2.3 с → выдох 3.5 с → хвост 4.2 с)
— **Громкость в игре:** 0.55 · целевые −20 LUFS
— **Питч-вариация:** 0.94–1.06 (здесь можно — не петля)
— **Эмоция:** внезапное осознание масштаба: «оно дышит, и оно большое». Не испуг — холод.
— **Слои:**
  1. **Low body (25–100 Гц):** мягкий суб-толчок давления на пике вдоха (39 Гц, гаусс 0.7 с) + низ выдоха, уходящий вниз к концу (LP-дрейф).
  2. **Mid texture (200–1400 Гц):** вдох — полоса «уезжает» вверх (200→600 Гц, +0.45 окт.); горло — узкая вокализация 168 Гц с изгибом вниз **без рыка** (это стон, не агрессия) + шумовая мембрана 520/1100 Гц.
  3. **High detail (1.4–8 кГц):** «открытие» верха к концу вдоха (множитель 0.3→1.0) — воздух входит в полость; на выдохе верхняя полоса темнеет (1.4→0.7 кГц за 4 с).
  4. **Air / Reverb:** два пространства одновременно: IR «полость» RT60 5.0 с (выдох, send 55%) + IR «горло» RT60 1.8 с (вдох, send 28%) — эффект «звук идёт изнутри наружу».
— **Референсы:** *Bloodborne* — Vicar Amelia (страдание, а не злоба); *Amnesia* — Waterluker (дыхание через воду); *Silent Hill* — «мир вздохнул».
— **Foley:** см. §3.3.
— **Варианты:** **3–4 файла** + питч 0.94–1.06 → 12+ воспринимаемых варианта. `_01` «вдох-выдох» (базовый), `_02` «задержка» (вдох → пауза 1.2 с → выдох, самый тревожный), `_03` «обрыв» (выдох не завершается — обрывается в тишину).
— **Priority:** **High** (это главный «признак жизни» Улья; без него зона мертва)

**Тех:** `AMBIENT` (или `HOSTILE` если рядом Улей) · att 16 (позиционно!) · stream false · bank 3–4 · cooldown 45–150 с (гаусс).

## 3. FOLEY: ЧТО ВЗЯТЬ В РУКИ И КАК ЗАПИСАТЬ

> Всё ниже — то, что нужно записать для замены процедурных слоёв реальными записями. Каждый пункт = конкретный слой из §2.

### 3.1 Для `HIVE_AMBIENT` (слой → источник → как записывать)

| Слой | Что взять в руки | Как записывать |
|---|---|---|
| **Low body** | (1) собственная грудная клетка — контактный микрофон на грудине или **стетоскоп**; (2) большая картонная коробка/бочка, в которую говорят через трубку; (3) вентиляционная решётка/труба отопления (структурный гул) | Микрофон в 5–10 см от коробки, говорить/дышать **низким** голосом без слов; труба: приложить микрофон к металлу, не к воздуху — нужен структурный шум. Записать 3–5 минут непрерывно, потом вырезать лучшие 20–40 с. |
| **Mid texture (дыхание)** | собственное дыхание через **мокрую ткань** (полотенце, намоченное и отжатое); **гофрированный шланг** (60–80 см) с ладонью на конце; пустая пластиковая бутыль 5 л | Дыхание — вплотную к микрофону, но через ткань (это убирает «щелчок губ» и даёт влажность). Шланг: дышать в него, ладонью приоткрывать/закрывать конец → широкое «дыхание массы». Записать по 8 дублей разной интенсивности. |
| **Mid texture (мембрана)** | натянутая кожа (барабан/пергамент) или **резиновый лист**; кожаная куртка, натянутая на спинку стула | Натягивать и медленно отпускать рукой (не бить!). Записывать близко (10 см), с разной скоростью. Это «creak»-события. |
| **High detail (жилы)** | **не записывать**: это синтез/обработка. Но исходники: (1) край тарелки/подвесной металл + смычок; (2) натянутая струна (гитарная 1-я) на деревянной доске, смычок + контактный микрофон; (3) бокал, обведённый мокрым пальцем | Записать по 10–15 минут: смычок медленно, с разным давлением и позицией. Потом в DAW: срез 0.4–0.6 с атаки, растянуть, питч-сдвиг ±5%, экспоненциальное затухание. |
| **High detail (мокрые события)** | мокрая губка, сжатая в кулаке; мокрая замша/кожа, оттянутая от стола; гель из тюбика | Записывать **медленно** (атака 20–60 мс) — нам нужен не «кап», а «плоть тянется». Микрофон 8–15 см, без ветрозащиты близко к источнику. |
| **Air** | пустая комната/коридор с шумом вентиляции; шум «шёлковый» — шуршание шёлка/нейлона у микрофона | Записывать в реальном помещении, потом использовать как «воздух» −28…−34 дБ. Шёлк — 30 см от микрофона, очень медленные движения. |

### 3.2 Для `HIVE_AMBIENT_CLOSE`

Всё то же + **дополнительно**:
- **«Грудная клетка рядом»**: контактный микрофон на грудной клетке человека, 2 минуты спокойного дыхания — использовать как основу 90–190 Гц.
- **Мембранные «потягивания» ближе**: та же кожа, но микрофон 3–5 см, добавить щелчки слюны (записать отдельно, вклеивать редко).
- **«Пульс конструкции»**: капля в металлическую раковину (редко!), скрип трубы при нагреве — превратить в нерегулярные события 0.15–0.35 Гц (не метроном!).

### 3.3 Для `HIVE_PULSE`

- **Вдох:** собственный вдох, но **медленнее обычного** (3.4 с) через бумажную трубку/свёрнутый лист — даёт «втягивание воздуха в объём».
- **Горло:** голос на 168 Гц («ммм» с открытым горлом), записанный через металлическую раковину/трубу — метод Brute (Tapio Liukkonen, *Amnesia*). Обязательно: **без агрессии**, это стон.
- **Выдох:** длинный (3.5 с) выдох через мокрую ткань, всё тише и темнее к концу.
- **Пик давления:** кулак в мокрую глину, но **очень** близко к микрофону (получим саб) — использовать только 40–100 Гц.

### 3.4 Микрофонная гигиена (что реально влияет)

1. **Никакой обработки на записи**: 48/96 кГц, 24 бит, без компрессора, без ревера, без лимитера. Всё — в DAW.
2. **Пики −12…−6 dBFS** (не в ноль: нужен запас для питч-шифта вниз).
3. **Тишина помещения важнее микрофона**: замерьте шумовой пол; для слоёв «воздух» он должен быть ≤ −60 dBFS, иначе шум всплывёт при подъёме верха.
4. **Моно, всегда моно.** Любой стерео-файл убьёт позиционирование в Minecraft.
5. **Дубли, а не один дубль**: по 6–10 на каждый источник, разной интенсивности — из них собираются банки вариаций.

## 4. ПОШАГОВАЯ ОБРАБОТКА (что делать с записями в DAW)

### 4.1 Слои и их «рабочие» полосы (единая таблица)

| Слой | Рабочая полоса | Обработка | Уровень (отн. микса) |
|---|---|---|---|
| Low body (суб) | 25–60 Гц (+обертон 80–120) | HP 22 Гц 12 дБ/окт → сатурация tanh 1.5× (только этот слой) | −6 дБ |
| Low body (тело) | 55–190 Гц | LP 240 Гц, дрейф центра ±10%, ±20 с | −14 дБ |
| Дыхание | 190–900 Гц | BP широкий Q≈1.0 (НЕ узкий), 3 форманты, дрейф ±0.14 окт | −11 дБ |
| Мембрана | 210–1300 Гц | BP широкий, ±0.12 окт дрейф, редкие creak-события | −13 дБ |
| Жилы | 300 Гц–8 кГц | HP 200 Гц, срез атаки, затухание 1.6–3.2 с, 12–18 событий/120 с | −13 дБ |
| Мокрые события | 320–3200 Гц | атака ≥20 мс, HP 300 Гц, 1 событие/9–17 с | −15 дБ |
| Воздух | 4.2–13 кГц | HP 2.5 кГц 24 дБ/окт (!), дрейф центра | −13 дБ |

### 4.2 Порядок обработки (обязательный)

1. **Чистка**: убрать щелчки/дыхание микрофона (iZotope RX / spectral repair), DC-offset, HP 22 Гц.
2. **Форманты, а не пики**: любые резонансы делать **широкими** (Q ≤ 1.6) и **дрейфующими** (LFO 0.03–0.1 Гц). Если хочется «узко» — это ошибка: узкая полоса = гудение.
3. **Медленная эволюция**: амплитуда каждого слоя меняется на ±2–3 дБ с периодами 20–40 с. Периоды — «неудобные» (7.3 / 10.7 / 13.3 / 17.1 с), чтобы НОК был огромным и пульсации не складывались в ритм.
4. **Один реверб на зону**: `afir` (или Altiverb) с одной IR на все слои → «одно помещение». IR пишем сами: хлопок/стартовый пистолет в подземном паркинге, цистерне, лестничном пролёте (RT60 3.0 с — «внутри», 5.5 с — «каверна»).
5. **Сатурация только на низ** (tanh, drive 1.5), верх не трогать: агрессия без «грязи».
6. **Анти-пульс**: очень медленная нерегулярная модуляция ±1.5% (0.027 и 0.041 Гц) — маскирует остаточную периодичность.
7. **Мастер-баланс полос** (9 полос) до целевой кривой — это работа с *реальными данными*: поднимать полосу, где нет контента, нельзя (получим «полосы» на спектрограмме).
8. **Проверка «сердцебиения»**: огибающая → спектр модуляции; в 0.8–3 Гц не должно быть пика > 4 дБ над локальной базой.
9. **Сшивка петли**: круговое сглаживание стыка 10 мс (см. `seam_fix.py`), контроль: скачок < 2 мс.

### 4.3 Чего НЕ делать (антипаттерны, которые и создали «противный» звук)

- ❌ Узкие резонансы в 500–1500 Гц «для атмосферы» → гудение в голове.
- ❌ Капли/бульки на фиксированном интервале → «часы» из плоти.
- ❌ Два близких суб-тона → биения 1–3 Гц = сердцебиение.
- ❌ Стерео-файл → звук прилипает к игроку, 3D нет.
- ❌ Нормализация «в 0 dBFS» → при наложении двух источников клип.
- ❌ Один файл без вариаций → repetition fatigue за 3–5 минут.
- ❌ «Страшная» библиотека (riser/stinger) в подложке → мгновенно «мультяшно».

## 5. СКОЛЬКО ВАРИАНТОВ НУЖНО (unconscious repetition)

| Звук | Файлов в банке | Питч в sounds.json | Воспринимаемых вариантов | Обоснование |
|---|---|---|---|---|
| `HIVE_AMBIENT` | **3** (+1 tonal) | 1.0 (петли не питчить) | 3 (+3 tonal) | 120 с × 3 = 6 мин непрерывного звучания без повтора; при смене по `corruption` — 9 мин. Питч для петель запрещён (стык поедет) |
| `HIVE_AMBIENT_CLOSE` | **2–3** | 1.0 | 2–3 | игрок проводит внутри структуры меньше времени; 2 достаточно, 3 — комфортно |
| `HIVE_PULSE` | **3–4** | 0.94 / 0.97 / 1.03 / 1.06 | 12–16 | питч здесь допустим (не петля) → 4 файла дают 16 комбинаций; при cooldown 45–150 с повтора не будет слышно за сессию |

**Правила, чтобы подсознательный повтор работал:**
1. Интервал между срабатываниями — **гауссов** (mean 45–150 с, σ = 0.35·mean, обрезка 0.4–2.2·mean), не таймер.
2. **Anti-repeat guard**: не играть один и тот же файл дважды подряд; хранить последние 3 ID.
3. **10–20% времени — «absence»**: PULSE не играет вообще (мир молчит дольше, чем ждёшь) — самый сильный приём.
4. **Паттерн-брейк**: каждые 3–5 повторов — один «неправильный» вариант (`_03 обрыв`).
5. Кроссфейд между уровнями заражения — **3–4 с**, не переключение.

## 6. О ГЕНЕРАТОРЕ (направление A / B)

**A — «воздушное» (`airy`, по умолчанию).** Широкое дыхание + редкие поющие жилы + шёлковый верх. Тревога через масштаб и непредсказуемость. Рекомендую как основное.

**B — «тональное» (`tonal`).** Добавлен консонансный дрон D2 (квинта + октава + малая терция) и редкие тихие «искры» (D-минор-пентатоника, −26 дБ). Более «красиво и печально», ближе к *Silent Hill* / *TLOU*. Риск: тональность может «прилипнуть» и надоесть за час.

Слушайте оба и скажите, куда двигаемся — дальше докручу выбранное (или смешаю: 80% A + 20% B).

## 7. FFMPEG: СБОРКА И ЭКСПОРТ

### 7.1 Экспорт готового микса (WAV → OGG, mono, 44.1, точная громкость)

```bash
# 1) измеряем громкость мастера
ffmpeg -hide_banner -nostats -i hive_ambient_01.wav \
  -af loudnorm=I=-26:TP=-3:LRA=50:print_format=json -f null - 2>&1 | tail -20

# 2) статичное усиление + лимитер + mono/44.1/Vorbis q4
#    (gain_dB = target_LUFS − measured_LUFS; НЕ используем loudnorm в один проход —
#     он «качает» громкость и убивает ровность петли)
ffmpeg -y -i hive_ambient_01.wav \
  -af "volume=-3.88dB,alimiter=limit=0.7079:attack=12:release=120:level=0,aresample=44100" \
  -ac 1 -ar 44100 -c:a libvorbis -q:a 4 \
  assets/carnis/sounds/amb/hive_ambient_01.ogg

# 3) контроль: каналы/частота/кодек/пик/громкость
ffprobe -hide_banner assets/carnis/sounds/amb/hive_ambient_01.ogg
ffmpeg -hide_banner -nostats -i assets/carnis/sounds/amb/hive_ambient_01.ogg \
  -af ebur128=peak=true -f null - 2>&1 | tail -12
```

### 7.2 Сборка из foley-слоёв (реальные записи)

```bash
# слои: low.wav (суб+тело), breath.wav, membrane.wav, veins.wav, wet.wav, air.wav
# IR: cave.wav (5.5 с), cavity.wav (3.0 с)
# 1) свёртка с одной IR на зону (одинаковое помещение для всех слоёв)
ffmpeg -y -i breath.wav  -i cave.wav -filter_complex "[0][1]afir=dry=0.5:wet=0.5" breath_r.wav
ffmpeg -y -i membrane.wav -i cave.wav -filter_complex "[0][1]afir=dry=0.7:wet=0.3" membrane_r.wav

# 2) сведение слоёв с весами (без клиппинга: amix normalize=0 + последующий лимитер)
ffmpeg -y -i low.wav -i breath_r.wav -i membrane_r.wav -i veins.wav -i wet.wav -i air.wav \
 -filter_complex "\
 [0]volume=1.00[l];[1]volume=0.55[b];[2]volume=0.45[m];\
 [3]volume=1.15[v];[4]volume=0.85[w];[5]volume=0.80[a];\
 [l][b][m][v][w][a]amix=inputs=6:normalize=0:duration=longest[mix];\
 [mix]highpass=f=22,alimiter=limit=0.7:attack=12:release=120[out]" \
 -map "[out]" -ac 1 -ar 48000 mix_master.wav

# 3) петля: сшивка стыка (10 мс круговое сглаживание) — см. tools/seam_fix.py
python3 tools/seam_fix.py mix_master.wav

# 4) экспорт (см. 7.1) + проверка модуляционного спектра
```

### 9.2 Логика (три правила)

1. **Bed — не событие, а состояние.** `TickableSoundInstance` с `volume()`, зависящим от уровня заражения; при входе/выходе из структуры — смена инстанса с кроссфейдом 4 с (старый гасится по 0.25/тик, новый поднимается).
2. **PULSE — только по гауссову таймеру**, cooldown 45–150 с, с 15% шансом «absence» (ничего) и 10% шансом сыграть два подряд с интервалом 2–4 с (эффект «оно заговорило»).
3. **Позиция PULSE — честная**: `level.playSound(null, pos, ...)` на ближайшем узле; если узлов нет — не играть вовсе (иначе звук «из воздуха» ломает доверие к миру).
