## Важное наблюдение про 2 строковые записи

Из 145 записей **2 записаны строкой**, а не объектом:

```json
"pulsing_heart_beat": {"sounds": ["carnis:block/heart_pulse"]}
"pustule_burst":      {"sounds": ["carnis:block/pustule_burst"]}
```

**Это ровно те два файла, которые я в T-3163 ошибочно объявил мёртвыми** —
разбирал только объектную форму. Обе формы теперь учтены, сирот 0.

Это же место, где ошибся бы любой наивный парсер. Отмечаю явно, чтобы проверка
не потерялась при следующей правке `sounds.json`.

## 51 событие с единственным вариантом

срабатывании звук прозвучит тот же самый — без вариативности.

Не дефект (критерий S10 этого не требует), но **наблюдение для дизайна**:
