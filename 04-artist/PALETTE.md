## 4. Порог плотности светотени (`04-artist/tools/shade_density.py`)
- Макс. доля одной непрозрачной краски: **≤ 35.0%**
- Мин. число непрозрачных цветов: **≥ 7**

## 5. Рецепт перекраски под порог ≤ 35 %
1. **Выбор палитры**:
   - Для существ и органики в палитре проекта: брать все 7 цветов `BASELINE_PALETTE` (`(84,40,54)` … `(209,144,130)`).
   - Для блоков/щупалец с привязкой к family (как A3R1 / T-3115): посчитать средний RGB непрозрачных пикселей `(mr, mg, mb)` и построить 7-ступенчатую рампу со смещениями `[-30, -20, -10, 0, +10, +20, +30]` по R и `0.7×` по G/B.
2. **Распределение пикселей (квантильное разбиение)**:
   - Посчитать непрерывный индекс `score = lum(RGB) + шум(x, y) + вертикальный_градиент(y)` для каждого непрозрачного пикселя (`α > 0`).
   - Отсортировать непрозрачные пиксели по `score` и разбить на 7 равных квантилей (`idx * 7 // N`).
   - Это гарантирует ровно 7 цветов и долю самой частой краски **~14.3%–15.5%** (запас > 2× до порога 35%).
3. **Инварианты**: альфа строго `{0, 255}`, маска `α > 0` сохраняется побитово (`0/0`), обязательная проверка `04-artist/tools/shade_density.py` → код `0`.
