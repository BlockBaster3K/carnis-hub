## Решение Р-10 (ambient)

«Либо длины равны, либо играет только один слой» — второй вариант нельзя засчитывать по наличию `if (insideStructure)`: close-слой играет **одновременно** с кроватью. Поэтому если в коде есть `closeSound`, длины обязаны совпадать, включая пару «кровать ↔ close»; если close-слой убран из кода — одновременности нет и п.4 не применяется.
