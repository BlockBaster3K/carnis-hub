## 2. 16 неиспользуемых файлов — подтверждены (пункт 2)

**Не «потеряны при сборке».** Все 16 лежат в подкаталоге `archive/` банка
(`archive/hive/*_w1516`), то есть **вне** пути, откуда собирается пакет.
Проверка в пакете 3.7.3:

```
.ogg файлов в пакете: 144    ← ровно канон, без archive/
файлов из archive/ в пакете: 0
```

То есть это **архивные версии**, а не рабочие файлы. Отдельный вопрос «удалять
ли `archive/` из банка» — не мой: это задел и история правок.

| событие | пакет | репозиторий |
