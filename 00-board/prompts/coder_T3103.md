## Шаг 1. Снять sparse-checkout (обязательно, иначе банка нет на диске)

```bash
cd /home/user/hub5

```

**Почему это первый шаг:** рабочая копия исключает `*.ogg`, `*.png`, `*.zip`,
`*.jar`. Из-за этого каталог `03-sound/sounds/` физически отсутствует, и
скрипт сборки рапортовал «нет в банке» на все 9 ambient-слоёв. Это была
причина, а не ошибка сборки.

## Шаг 2. Внести партию `-R` и A3R1 в пакет

```bash
cd /home/user/hub5
python3 - <<'EOF'
import zipfile, os
PKG = "01-coder/3.7.0"
for arch in ["04-artist/deliverables/Carnis_3.7.0_A4p7_palette-R.zip",
             "04-artist/deliverables/Carnis_3.7.0_A3R1_tendrils_recolor.zip"]:
    z = zipfile.ZipFile(arch)
    for n in z.namelist():
        if n.endswith("/"):
            continue
        dst = os.path.join(PKG, n)
        os.makedirs(os.path.dirname(dst), exist_ok=True)
        open(dst, "wb").write(z.read(n))
    print("внесено:", os.path.basename(arch))
EOF
```

**Только партия `-R`.** Старая `Carnis_3.7.0_A4p7_palette.zip` содержит
`infected_creeper` с долей краски 81,2 % — это З-1, который чинили.
Принята `-R`: 28,3 %, Ревизор подтвердил.
