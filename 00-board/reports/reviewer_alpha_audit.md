## 2. Почему это не дефект: стандарт проекта требует именно так

`00-board/reports/artist_z5_and_creatures.md` §20 говорит прямо:

> «Полупрозрачные края `{210, 220}` были бинаризованы в `255` **осознанно**: единый стандарт проекта (ТЗ 3.7.0 §2.3, A4-p7, A3R1) требует **альфу только 0 или 255** … Бинарная маска `α > 0` при этом сохранена побитово (пропало 0, добавилось 0).»

Мои замеры это подтверждают: у всех трёх файлов маска `α > 0` **побитово равна** 3.6.0-R, то есть силуэт не потерян ни на пиксель. `incubation_overlay.png` в сдаче Художника (`Carnis_3.7.2_T3122_creatures_z5.zip`) уже с альфой `[0, 255]` — значит это не «побочный эффект заготовки», как я написал в первой редакции, а та же осознанная бинаризация.

**Следствия, которые я снимаю:**

- **З-12** (`pustule_cluster`) — не дефект. Свою рекомендацию «не принимать файл до восстановления альфы» **отзываю**; вариант **B** Интегратора в этой части не нужен.
- **З-13** (`incubation_overlay`) — не дефект. Убираю требование «в релиз 3.7.2 не пускать».
- **З-14** (`infected_skeleton_glowmask` в 3.7.1) — не дефект и не «мой пропуск»: `glow_check` правильно пропустил его, потому что маска цела, а бинаризация — требование стандарта.
- Решение Архитектора **T-3142** (перекраску трёх файлов принять, снять их из `KEEP_IDENTICAL`, сверять побайтово с архивом Художника) остаётся в силе **без изменений** — править его не нужно.

## 3. Что действительно остаётся: у стандарта «альфа 0/255» есть границы (З-15)

Если применить правило «только 0 или 255» ко всему дереву текстур, оно ломает 28 файлов — и вот это уже настоящая мина для 3.7.3:

| Каталог | Файлов с градиентной альфой | Почему так и должно быть |
|---|---:|---|
| `item/` | 19 | предметы и иконки сглаживаются полупрозрачной кромкой |
| `block/` | 5 (`pulsing_heart` 4096 px с градиентом 150–155, его маска, 3 маски свечения) | у блоков альфа маски = сила свечения |
| `particle/` | 2 (`biomass_spark` 145/220, `purifier_flame` 210) | частицы обязаны быть полупрозрачными |
| `misc/vein_overlay.png` | 1 (**16 787 px**, градиент 95–230) | это оверлей, альфа и есть сила эффекта |
| `hallucination/phantom_eyes.png` | 1 (48) | мягкое свечение |

**Вывод:** правило 0/255 действует только на **`textures/entity/**`** (19 файлов) и на перекраски `creeping_tendrils_*` (A3R1). Ко всему дереву его применять нельзя: `misc/vein_overlay` из 16 787 градиентных пикселей и `pulses_heart` из 4 096 превратились бы в жёсткие пятна.

## 4. Что предлагаю поставить в гейт (зона Интегратора)

```bash
# 1) геометрия — для всех текстур, дешёвая и всегда обязательная:
python3 02-reviewer/tools/alpha_audit.py <пакет> \
    --baseline 01-coder/3.6.0-R/project-3.6.0-R-clean.zip          # код 0 ожидается

# 2) стандарт 0/255 — только там, где он объявлен:
python3 02-reviewer/tools/alpha_audit.py <пакет> \
    --baseline 01-coder/3.6.0-R/project-3.6.0-R-clean.zip \
    --require-binary --only entity/                                # код 0 ожидается
```

`--require-binary` **без** `--only` сегодня даёт 28 нарушений — все они ложные по смыслу §3, поэтому флаг нельзя включать глобально. Это ограничение записано в шапке инструмента.
