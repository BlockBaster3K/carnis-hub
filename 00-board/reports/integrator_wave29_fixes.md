### 1.5. `tools/sound_metrics.py` — переписан

OGG читается **не через libsndfile**. Порядок поиска декодера: `ffmpeg` из `PATH` →
переменная `FFMPEG` → пакет `imageio-ffmpeg`. Если декодировать нечем — скрипт честно
разбирает контейнер Ogg/Vorbis и падает с кодом 1, не выдавая вымышленных метрик.
Метрики: RMS, peak, crest, спектральный центр, доли энергии < 80 Гц и < 120 Гц, хвост;
окно 4 096, шаг 2 048. Банк по умолчанию — `<repo>/03-sound/sounds`.

## 3. Что осталось непроверенным

- **`sound_metrics.py` зависит от внешнего декодера.** Полные метрики посчитаны только
  с ffmpeg. В чистом Python декодера Vorbis нет: без ffmpeg/`imageio-ffmpeg` скрипт
  падает с кодом 1 (это спроектированное поведение, а не сбой). Корректность самих
  чисел подтверждена сверкой с ранее заявленными Звукарями значениями, но независимого
  второго декодера для перекрёстной сверки не применялось.
- **SSH-канал недоступен.** В песочнице нет ключа (`~/.ssh/id_ed25519` отсутствует),
  `git@github.com:22` и `ssh.github.com:443` отвечают, но аутентифицироваться нечем.
  Пуш идёт токеном из окружения через credential-helper — токена нет ни в
  `.git/config`, ни в argv, ни в reflog, ни в файлах репозитория. Клон чист: `origin` —
  `https://github.com/BlockBaster3K/carnis-hub.git`.
- **Отзыв старого PAT не выполнен** — требует ручного действия заказчика в UI GitHub;
  через API недоступен.
- **Игровой тест Д6 не выполнялся.** Приёмка текстуры — по метрике и хешам; художественная
  приёмка в игре не заявляется.
- **Перенос PNG в сборку `3.5.3-R`** — за Кодером; до этого Д6 в JAR не закрыт.
- **CI по этим коммитам не запускался** — `00-board/**` и `tools/**` не входят
  в триггеры workflow. Это ожидаемо, а не сбой.
