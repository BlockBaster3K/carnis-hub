# Ревизор · T-3184: что будет с файлами при удалении 11 недостижимых событий

**Дата:** 2026-11-26 · **Пакет:** 3.7.3 `d392d604…` · **Зачем:** Кодер остановился на выборе «подвязать или удалить», потому что удаление события легко превращает его файлы в сироты и валит `sound_orphans`. Вот точная картина по `sounds.json` пакета — счёт по ссылкам, а не по догадкам.

## Что из этого следует

1. **`FLESH_AMALGAM_AMBIENT` — самый дешёвый случай:** ресурс уже звучит через `hive.amalgam_breath`. Удалять надо только дублирующую регистрацию события; ни один файл не пострадает, `sound_orphans` не изменится.
2. **Остальные 10 событий** — любое удаление обязано быть «событие + ключ в `sounds.json` + файлы» одним пакетом, иначе мой `sound_orphans` (и гейт) упадут на сиротах. Это правильное поведение: молча оставлять `.ogg` без события нельзя.
3. **Наиболее осмысленны к подвязке** (а не удалению), по данным Кодера: `AMALGAM_SMASH` (обычный melee Flesh Amalgam), `CREEPER_RUPTURE` (взрыв заражённого крипера), `HIVE_SPREAD` (успешное разрастание), `SYNAPSE_SHOCK` (переход synapse node в активное состояние) — у каждого есть очевидная точка вызова и нет конфликта с уже звучащими событиями.
4. **Пять `hive.detail_*`** — без решения Звука по ambient-слоям не трогать: они one-shot детали, и вставлять их «куда-нибудь» значит менять звуковой дизайн. Пока решение не принято, честнее оставить их в списке известных недостижимых, чем прятать.

**Проверка после правки:** `python3 tools/sound_orphans.py <пакет>` → **код 0** (сейчас 3), и `python3 tools/accept_3.7.3.py <пакет>` → **код 0** (сейчас 1). Других блокеров в пакете нет — это подтверждено полным прогоном чек-листа.
