## 2. Замечание по методике (моё, себе на будущее)

Первым проходом я сгруппировал файлы по префиксу имени — и получил **шесть**
событий с разбросом, три из них ложные (`phantom` 10,0 дБ, `purifier` 3,5,
`zone_stinger` 3,1). Причина: префикс склеивает разные события
(`phantom_whisper` и `phantom_cry` — разные события `sounds.json`).
**Разброс считается только по карте событий из `sounds.json`, не по именам
файлов.** Если этот счёт когда-нибудь попадёт в гейт — считать так же.

## 3. Про общее правило, которое Звук предложил утвердить

Формулировка Звука: `разброс ≤ 3 дБ → ok; иначе объявлено в спеке → ok; иначе
находка`. **В таком виде это fail-open**: «объявил в спеке» становится
постоянным пропуском, а не проверкой. Ровно так `detail_flow` и жил — с
`1.0` в пакете при разбросе 7,7 дБ.

Рабочая формулировка должна быть проверяемой:

```
разброс <= 3 дБ                          -> ok
иначе: в спеке есть targets_by_sample
       И после применения этих множителей остаточный разброс <= 1 дБ  -> ok
иначе                                    -> находка
```

Второе условие машинно проверяемо и уже один раз сработало: моё решение по
`detail_flow` (множитель `2.437`) даёт остаток **0,00 дБ** — объявление было
**подтверждено**, а не принято на слово. Без этого условия правило бесполезно:
декларация есть, компенсации нет.

## 4. Наблюдение, которое может оказаться важнее разброса

Три самых тихих файла банка — почти одно и то же число:

| файл | RMS | у события есть пара? |
|---|---:|---|
| `detail_flow_01` | **−29,57** | да, разрыв 7,7 дБ |
| `hive_spawn_idle_01` | **−29,09** | да, разрыв 7,1 дБ |
| `phantom_whisper` | **−29,06** | **нет — событие из одного сэмпла** |

Похоже не на два независимых дефекта, а на **одну партию файлов**, сведённую по
более тихой норме: все три — `_01`/одиночка из ранней серии. У `phantom_whisper`
пары нет, поэтому правило «разброс внутри события» его **не поймает никогда**, а
слушатель получит тихое событие рядом с громкими: медиана банка −18,6 dBFS,
разброс по банку 16,1 дБ.

**Вопрос Архитектору (не моё решение):** баланс **между** событиями — это
норма или дефект? Если норма, правило Звука закрывает вопрос. Если нет, нужен
второй порог — по событиям, а не внутри пар, и тогда находок станет больше трёх.
