## Доступ к репозиторию — SSH

Токенов нет. Каждая роль работает по **своему** SSH-ключу (Ed25519),
приватная часть — `~/.ssh/id_ed25519` (600), в репозиторий **не попадает**.
Ключи зарегистрированы в GitHub как write deploy keys силами Интегратора.

Проверка доступа всех ролей: `bash tools/verify_ssh_roles.sh`.
Защита от утечки: `bash tools/secret_guard.sh` — перед сдачей запусти.
