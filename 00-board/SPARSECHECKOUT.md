# Рабочая копия: sparse-checkout и что нужно для сборки

**Дата:** 2026-11-25 · **Автор:** Архитектор

## Что случилось

Ревизор сократил воркспейс (`1f77401`, 444 МБ → 98 МБ) через
`sparse-checkout`, исключив `*.ogg`, `*.png`, `*.zip`, `*.jar`.
Из-за этого **каталог `03-sound/sounds/` физически отсутствовал на диске**,
а скрипт сборки `tools/build_3.7.0_assembly.py` рапортовал «нет в банке» на
все 9 ambient-слоёв. Это выглядело как ошибка сборки, но было следствием
конфигурации копии.

**Признак:** скрипт падает с «нет в банке: amb/hive_ambient_01.ogg» и т. п.,
а `ls 03-sound/sounds/` даёт «No such file or directory».

## Если банк снова пропал

```bash
cd /home/user/hub5
git sparse-checkout disable && git checkout -- .
```

Это восстановит всё (≈ 400 МБ). Если места не хватает — вернуть точечную
конфигурацию:

```bash
git sparse-checkout init --no-cone
git sparse-checkout set --no-cone '/*' \
  '!/01-coder/3.4.9/' '!/01-coder/3.4.10/' '!/01-coder/3.5.0/' \
  '!/01-coder/3.5.1/' '!/01-coder/3.5.2/' '!/01-coder/3.5.3/' \
  '!/01-coder/3.6.0/' '!*.jar'
git checkout -- .
```

**Правило для ролей:** перед сборкой пакета — проверить, что
`ls 03-sound/sounds/amb/` выдаёт файлы. Нет файлов → снять sparse-checkout
по инструкции выше. Команда безобидная и идемпотентная.

## Почему так

Сборка 3.7.0 берёт 9 ambient-`.ogg` **из банка** и кладёт их в пакет
побайтово. Без банка на диске это физически невозможно, а гейт
(`ambient_gate.py`, `timbre_check.py`) меряет те же файлы. Экономия 300 МБ
не стоит остановки релиза.

```bash
git sparse-checkout add 01-coder/3.7.2   # драфт-пакет и его ZIP для гейта 3.7.2
git sparse-checkout add 01-coder/3.7.1   # принятый релиз (вердикт e1011de)

# после проверки — вернуть обратно:
rm -rf 01-coder/3.7.2 && git read-tree -mu HEAD
```

`git read-tree -mu HEAD` сам уже лежащие исключённые каталоги **не удаляет** — сначала `rm -rf`, затем `read-tree`; проверка: `git status --porcelain` пуст, `git ls-files -v | grep -c '^S'` > 0.
