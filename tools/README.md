# `tools/` — инструменты приёмки Carnis

**Владелец зоны:** Интегратор. Отчёт по кодам возврата — `00-board/reports/integrator_gate_codes.md` (T-3125).

---

## 1. Главное: два РАЗНЫХ словаря кодов

В проекте два вида инструментов, и у них **разные** значения кодов возврата.
Скрипт, который читает код, обязан знать, с каким инструментом говорит.

### 1.1. Гейты приёмки — `accept_<версия>.py`

| Код | Значение | Что делать скрипту-читателю |
|---|---|---|
| **0** | **ПРИНЯТО** — все проверки пройдены | можно релизить (после вердикта Ревизора) |
| **1** | **ЕСТЬ РАСХОЖДЕНИЯ** — пакет проверен и не прошёл | приговор **пакету**, не запуску |
| **2** | **ПАКЕТА НЕТ / ОШИБКА ЗАПУСКА** | виноват запуск, не пакет |

Правило: **код 1 никогда не означает «сломался инструмент»**. Если гейт не
смог работать (нет файла, дали каталог, битый ZIP, нет Pillow) — это всегда 2.

### 1.2. Чекеры — всё остальное

`ambient_gate.py`, `timbre_check.py`, `sound_orphans.py`, `glow_check.py`,
`tendril_flesh_match.py`, `delta_360.py`, `shade_density.py` (у Художника).

| Код | Значение |
|---|---|
| **0** | **СХОДИТСЯ** |
| **2** | **ЕСТЬ ЗАМЕЧАНИЯ** |
| **1** | **ОШИБКА ЗАПУСКА** |

### 1.3. Почему так, а не наоборот

Исторически: чекеры появились раньше и взяли 2 = «замечания» (так у Ревизора в
`ambient_gate.py` и `timbre_check.py`). Гейты писались позже и взяли
1 = «расхождения» (диалектика «1 — не 0, но пакет существует»).

**Ломать существующее нельзя:** на коды чекеров завязаны отчёты ролей и
скрипты Ревизора. Поэтому словари **разведены и задокументированы**, а не
унифицированы. Различать инструменты надо **по имени**: `accept_*` — гейт,
всё остальное — чекер.

⚠️ Не пишите `if code == 2: print("есть замечания")` и не проверяйте
`accept_*.py` этим условием: у гейта 2 значит «пакета нет».

## 2. Гейты приёмки

| Файл | Версия | Блоков | Что проверяет |
|---|---|:--:|---|
| `accept_3.7.0.py` | 3.7.0 | 10 | манифест, JSON, версия, overlay, A4-p7-**R**, A3R1, K8-S, ambient, принятые слои, Д1–Д7 |
| `accept_3.7.1.py` | 3.7.1 | 12 | то же + **тембр** (`timbre_check`) |
| `accept_3.7.2.py` | 3.7.2 | 15 | то же + **существа**, **блоки**, **банк** |

Запуск:

```bash
python3 tools/accept_3.7.2.py                       # пакет по умолчанию
python3 tools/accept_3.7.2.py <zip> [<манифест>]    # явно
```

Аргумент — **только ZIP**. Каталог, несуществующий путь и битый архив дают
код 2 с объяснением, без трейсбека (З-6, T-3125).

### Окружение
Блоки, которым нужны библиотеки, сами ищут подходящий интерпретатор
(`_python_with`):

| Библиотека | Кому нужна |
|---|---|
| Pillow | `glow_check`, `tendril_flesh_match`, блоки 11–14 |
| numpy + scipy + av | `timbre_check`, блок 15 (клиппинг) |

Если библиотеки нет — соответствующий блок даёт **код 1 с явной причиной**,
а не тихий пропуск. Установка:

```bash
python3 -m venv /tmp/vv3 && /tmp/vv3/bin/pip install Pillow numpy scipy av
```

## 4. Инструменты сборки (не приёмка)

| Файл | Что делает |
|---|---|
| `build_3.7.0_assembly.py` | шаги 1–6 ТЗ T-3103 (ambient-фикс, звуки, ZIP). `--dry-run`, `--repo=` |
| `secret_guard.sh` | проверка, что приватные ключи и токены не попали в git |
| `agent_push.sh` | пуш с выбором транспорта (SSH, иначе токен) |

`build_3.7.0_assembly.py` определяет корень по **целевому** каталогу
(`01-coder/` + `03-sound/sounds/`), а не по месту скрипта: иначе запуск из
копии дерева правил бы настоящий репозиторий.

## 5. Постоянные величины порогов

| Порог | Значение | Где |
|---|---|---|
| доля самой частой краски | ≤ **35 %** | З-1, блоки 11 и 14 |
| доля энергии < 80 Гц | ≤ **25 %** | блок 9 |
| спектральный центр | ≥ **400 Гц** | блок 9 |
| PULSE_INTERVAL_TICKS | **420–480** (эталон 450) | блок 8 |
| суммарная громкость слоёв | ≤ **0,70** | блок 8 |
| Δ средних цвета щупалец | ≤ **12** | блок 6 |
| длина петлевого слоя | **120,000 с** | блоки 8, 9 |
