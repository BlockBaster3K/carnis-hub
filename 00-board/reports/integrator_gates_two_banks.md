## Проверка предсказания Архитектора

Пока Звук не развёл банки, гейт 3.7.3 **падал** — и я это видел своими
глазами до переноса:

```
· банк хранилища: 276 .ogg | пакет: 144
✗ банк: 132 файлов есть в хранилище, но НЕ в пакете
```

Это ровно тот сценарий, который З-27 назвал «выигрыш одной версии
обесценивает принятую». После переноса (`729335d`, канон 144 + `sounds_380`
132):

```
· банк хранилища: 144 .ogg | пакет: 144
✓ пакет == банк по составу (144 из 144 …)
```

## Отдельно: З-Г6 (третий исход `sound_orphans`)

`FLESH_AMALGAM_AMBIENT` не вызывается как константа, но его файл играется
живым событием `hive.amalgam_breath`. Теперь это **третий исход** —
печатается строкой `~ играется через "hive.amalgam_breath"` и не валит.

Критерий строгий: **все** файлы события должны быть покрыты живыми
событиями. Проверил негативом: событие из двух файлов, где живым покрыт
один, — по-прежнему валит.

Счёт на 3.7.3: было 11 валящих → стало **9** (1 задел + 1 слышен через
другое событие).
