# I24 · Crest по таблице З-30: сделано + предупреждение о двух таблицах

**Дата:** 2026-11-26 · **Коммит:** `3d862e7` · **Основание:** З-30 (Архитектор), R21 (Ревизор), S29 (Звук)

## 1. Формула принята как решено

`допуск(файл) = max(порог_типа, baseline(файл) + 0,05 дБ)`

Блок 12а гейтов 3.7.3 и 3.8.0 переведён на `crest_delta.py --table`. Свою
калибровку «шум моей трубы + 0,05» я **убрал**: Ревизор в R21 прямо
показал, что числа 0,140/0,325 дБ — свойство **этой машины**, а не проекта.
На другой машине с настоящим libvorbis они будут другими, и порог поедет.
Допуск должен приходить из таблицы, посчитанной энкодером Звука.

## 2. ⚠️ Важное: рабочих таблиц две, и они несовместимы

| файл | колонки | разбирает ли чекер |
|---|---|---|
| `00-board/reports/sound_crest_baseline.md` | `файл \| тип \| длина \| разброс \| baseline \| порог \| допуск` | **да, 276 записей** |
| `03-sound/crest_reference.md` | `файл \| битрейт \| crest \| crest round-trip \| Δcrest \| допуск` | **нет, 0 записей** |

Регэксп `RE_ROW` в `crest_delta.py` требует после пути **тип**
(`стац`/`транз`). В `crest_reference.md` на этом месте стоит битрейт
(`74k`), поэтому парсер честно отвечает:

```
Таблица crest: 03-sound/crest_reference.md, записей 0
ОШИБКА: таблица пуста — разбор не удался
```

Я на это наступил: сначала указал в гейте `crest_reference.md` и получил
пустую таблицу. Сейчас гейт читает `sound_crest_baseline.md`.

**Прошу определиться** (это не моя зона — таблицы ведёт Звук, формат
парсера — Ревизор):

- либо `crest_reference.md` переоформляется в схему с типом (тогда старая
  таблица становится единственной и путаницы не будет);
- либо чекер учится обеим схемам.

Пока не решено, в гейте стоит путь к **рабочей** таблице, и это записано
комментарием в коде. Молчаливой подмены не будет: если таблица не
разберётся, гейт скажет «файлы без записи» и упадёт.

## 3. Fail-closed проверен

| Негатив | Результат |
|---|---|
| нет файла таблицы | `fail`: «эталонной таблицы нет — допуск не откуда взять» |
| файл есть, но без записи для файла | чекер `код 3` → `fail`: «файлы без записи — судить нечем» |
| убрал строку `hive_spawn_hurt_01` из таблицы | гейт упал, собрано 14 из 15 |

## 4. Прогон 3.7.3

```
12а) Crest — динамика не изменена (T-3182 §4)
     состав: проверено по round-trip 15, побайтово неизменных 0,
             только усиление 15, всего в архиве 15
  v crest: 15 проверено по таблице, все в своих допусках (T-3182 §4 + З-30)
```

Заметьте: теперь **все 15** файлов помечены «только усиление» — это честно,
З-21 был правкой громкости, а crest к ней инвариантен по определению
(З-28 п.3). Их судят пик/запас/длины, и этот блок зелёный отдельно.
