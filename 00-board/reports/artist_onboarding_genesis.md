- Свечение существ: **ровно `(255,92,57)`**, α ∈ {0,255} (Р-3). Сенсорные узлы/глаза/синапсы — да; кости и кожа хозяина — нет.

- Рецепт перекраски: `score = lum + det_noise(x,y) + vertical_gradient(y)` → сортировка → 7 квантилей (`idx*7//N`) → топ ~14.3–15.5 %, запас >2× до порога. Альфа строго {0,255}, маска `α>0` побитово сохраняется.
- Directional Muscle Bundling: волокна кластерами 3×2/4×2 вдоль оси мышцы, не шахматный дизеринг; кость — микропоры + трещины + градиент минерализации основание→остриё.

### 4.1. Замечания по инструментам (чужая зона — только фиксирую, не правлю)

1. **Баг `tools/creature_shade_audit.py` (зона Интегратора):** в каталожном режиме строка `Image.open(io.BytesIO(blob) if is_zip else name)` открывает голое имя файла вместо полного пути → любой каталог падает с «No such file or directory». ZIP-режим работает (проверено, п.4 таблицы). Обход: упаковать каталог в ZIP с путями `src/main/resources/…`. Предлагаю Интегратору правку `else name` → `else str(ent / name)`.
2. **Д5 на legado-моделях Фонда:** `geo_pairs_d5.py` даёт exit 2 на `infected_zombie` (11 видимых пар), `infected_skeleton` (62), `infected_spider` (25), `infected_creeper` (2). Методика Д5 калибрована на `cerebral_nexus` и применялась к новым сдачам; Фонд принят до Д5. Вопрос Помощнику: распространяется ли Д5 ретроактивно на Фонд, или только на новые модели? Для новых моделей принимаю Д5 = 0/0 как обязательный гейт.
3. **Pillow 13:** `Image.getdata()` deprecated (удаление в Pillow 14). Действующие чекеры проекта используют его — работают, но при будущем апгрейде потребуется миграция на `get_flattened_data()`. Мой новый инструмент уже совместим с обоими API.
