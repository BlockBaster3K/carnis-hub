## 2. A4-p7 — единая палитра существ

### 2.1. Что это

Сейчас заражённые мобы нарисованы в расширенной палитре: `infected_skeleton.png`
— **115 цветов**, `infected_spider.png` — 81, `infected_zombie.png` — 66. Весь
остальной мод принят по единой палитре `BASELINE_PALETTE` (**7 непрозрачных
цветов + прозрачный**): блоки Д6, флора Д7, щупальца A3/A6.

**A4-p7 — не новые существа.** Это **перекраска существующих**: геометрия и
силуэт не меняются, меняются только цвета. Задача — сделать существа частью
общего визуального языка мода.

### 2.2. Файлы (8 штук)

| Файл | Размер | Что сделать |
|---|---|---|
| `entity/infected_creeper.png` | 64×32 | перекрасить |

`src/main/resources/assets/carnis/textures/entity/<имя>.png`

### 2.3. Критерии приёмки (измеримые, без трактовок)

1. **Размеры не изменились**: ровно 64×32 / 64×64 как в таблице.
2. **Альфа только 0 и 255.** Никаких промежуточных значений (сейчас у
   `infected_skeleton_glowmask` есть 200 и 210 — это дефект).
3. **Ровно 7 непрозрачных цветов**, и все семь — из `BASELINE_PALETTE`
   (`tools/tendrils/tendrils_check.py`, константа `BASELINE_PALETTE`:
   7 непрозрачных + `(0,0,0,0)`). Плюс прозрачный — итого 8 значений RGBA.
4. **Маска (пиксели с альфа > 0) побитово идентична текущей.** Ни один
   непрозрачный пиксель не добавляется и не исчезает; перекраска идёт
   **по пикселям на своих местах**. Это главный критерий: силуэт не трогаем.
5. **Glowmask-ы — один цвет свечения.** Ориентир — уже принятые:
   `hive_sentinel_glowmask.png` и `cerebral_nexus_glowmask.png` используют
   **RGB (255, 92, 57)**. Допускается этот цвет и его ближайшие оттенки из
   `BASELINE_PALETTE`; других цветов — нет.
6. **Непротиворечие с уже принятым.** Мобы читаются как плоть: тело из
   `BASELINE_PALETTE`, свечение — отдельным слоем. Если после перекраски
   силуэт перестал читаться — это провал, а не успех.

### 2.4. Проверка

Ревизор оформляет эти критерии как чекер `tools/glow_check.py`
(по образцу `tools/flesh_spread.py` и `tools/tendrils/tendrils_check.py`):
печатает числа (размер, число цветов, совпадение маски с эталоном) и
`ИТОГ: СХОДИТСЯ` / `ИТОГ: ЕСТЬ ЗАМЕЧАНИЯ`, код возврата 0 / 2.

Сдавать можно **только** с `ИТОГ: СХОДИТСЯ` и кодом 0.

## 3. K8-S — сиротские звуки

В JAR лежат `sounds/combat/flesh_amalgam_death.ogg` и
`sounds/combat/flesh_amalgam_hurt.ogg` — на них не ссылается ни один файл
пакета. Варианты: (а) объявить события в `sounds.json` и использовать,
(б) удалить файлы.

**Решение принимает Кодер, обоснование пишет в отчёт**; Звук даёт аудит.
Критерий приёмки: либо 0 файлов-сирот в JAR, либо оба подключены и слышны.

## 4. Чего делать нельзя

- Не трогать геометрию существ (силуэт, размеры, позы).
- Не рисовать новых существ в этой версии — A4-p7 только перекраска.
- Не менять `BASELINE_PALETTE` — палитра проекта фиксирована.
- Не трогать принятые партии D6, D7, A3/A6.
- Не переделывать `creeping_tendrils`.
- Не запускать локальный Gradle build.
