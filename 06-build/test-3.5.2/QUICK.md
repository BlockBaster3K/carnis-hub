# Быстрая проверка — 6 пунктов, ~1 минута

Полный бланк (`REPORT.md`) и форма по звуку не обязательны: **всё, что видно в
логе, Интегратор проверит сам**. Здесь только то, чего в логе нет — как это
*звучит* и *выглядит* в игре.

Ответь в одну строку под каждым пунктом. Можно голосом в чат — перепишу сам.

```
1. Игра запустилась и дошла до главного меню без краша?        ДА / НЕТ
2. Мод Carnis 3.5.2 виден в списке модов?                        ДА / НЕТ
3. «Око разума» ставится и не роняет игру?                      ДА / НЕТ
4. Удар сердца слышен у Flesh Bulb (мясная луковица)?           ДА / НЕТ
5. Звук удара чистый — или слышны щелчки / «двойной удар»?     ЧИСТО / ЩЕЛЧКИ
6. Косы звучат при взмахе и ударе?                               ДА / НЕТ
```

## Как сдать лог (одна команда, если лог весит больше пары мегабайт)

Windows (cmd), в папке с логом:

```
tar -czf latest.log.gz latest.log
```

`tar` есть в Windows 10+ из коробки. Получится файл в несколько сотен килобайт —
его можно приложить к сообщению, и я разберу его сам.

Или целиком одной командой (скрипт сам зальёт лог в репозиторий и построит
разбор — отвечать в формы тогда вообще не нужно):

```
curl -sL -o submit_log.py https://raw.githubusercontent.com/BlockBaster3K/carnis-hub/arena/d474d740-carnis-hub/tools/submit_log.py
python submit_log.py "C:\путь\к\logs\latest.log"
```

Скрипт спросит fine-grained PAT (репозиторий `BlockBaster3K/carnis-hub`, право
**Contents: Read and write**). Токен в репозиторий не попадает и на диск не
сохраняется.

> **Почему лог такой большой.** Нормальный `latest.log` — 1–5 МБ. 32 МБ означает,
> что какое-то сообщение повторяется десятки тысяч раз. Это **не поломка игры**,
> а находка: источник найдётся в разборе, и я починю его.
