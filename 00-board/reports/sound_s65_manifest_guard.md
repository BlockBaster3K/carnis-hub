## 1. Что было не так

В S60 я создал `MANIFEST_canon_144.txt` и написал в его README:

> «При любой правке канона манифест **обязан** пересчитываться в том же коммите.
> Незакрытый путь «манифест устарел молча» остаётся: сверку никто не запускает
> автоматически. Сказано прямо, чтобы не выглядело гарантией.»

То есть я **сам** назвал дыру и оставил её. Это ровно то, что я закрывал в S50
(страж для `baseline_master`) и в чём упрекал других: документ обещает, код не
проверяет.

## 2. Что сделал

`tools/manifest_canon_test.py` — сверяет манифест с фактическим каноном:

| проверка | нарушение |
|---|---|
| количество записей в манифесте | не 144 → **код 3** (это не манифест канона) |
| файл из манифеста отсутствует | «удалён» → **код 2** |
| SHA256 не сходится | «изменён» → **код 2** |
| файл в банке без записи | «добавлен без записи» → **код 2** |
| манифест не читается | **код 3** |

## 3. Негативы прогнаны

| сценарий | код | что напечатал |
|---|---:|---|
| как есть | **0** | 144 файла, все SHA256 сходятся |
| порча 1 байта в `.ogg` | **2** | «файл изменён: 1» |
| удаление файла | **2** | «файл удалён: 1» |
| добавление файла | **2** | «добавлен без записи: 2» |
| битый манифест | **3** | «покрывает 0 файлов, ожидалось 144» |

Третий негатив важен отдельно: без проверки «файл в банке **без записи**» новый
файл канона прошёл бы мимо и манифеста, и приёмки. `check_baseline_master.py`
такой случай уже ловит, теперь и здесь.

## 4. Границы, которые называю прямо

- Тест **не** встроен в гейт. Он вызывается вручную или из CI; `tools/` — не моя
  зона, встраивание решает Интегратор.
- Тест **не** пересчитывает манифест — только говорит «устарел». Пересчёт делает
  человек и коммитит вместе с правкой файла. Так же, как со стражем baseline:
  пересчёт на машине приёмки вернул бы машинозависимость.
- Проверяется **только канон 144**. `sounds_380` (132) и `masters` (147) — своими
  манифестами.

## 5. Что прошу

Одну строку в гейт приёмки, рядом с проверкой звукового банка:

```python
rc = subprocess.run([sys.executable, "tools/manifest_canon_test.py",
                     "--quiet"]).returncode
if rc != 0:
    fail.append("манифест канона устарел (код %d) — сверка банк==пакет "
                "пойдёт по неверному эталону (S60/S65)" % rc)
```
