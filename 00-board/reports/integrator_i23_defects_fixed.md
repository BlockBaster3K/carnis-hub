Теперь baseline берётся из таблицы Звука (он измерен **его** энкодером тем же

## 3. S44 принят: мастером может быть декод предыдущей версии

Звук снял свой же блокер из S39. Это **не тавтология**: сравниваются два
разных сигнала (новое и старое), а не файл с его же декодом. Он измерил
разделяющую способность: правка громкости −3 дБ даёт Δcrest 0,007–0,060,
порча формы лимитером — 1,986–2,262. Зазор 33–100×.

Реализовано **с его же fail-closed**:

| случай | поведение |
|---|---|
| PCM-мастер есть | сверка по нему (как было) |
| PCM-мастера нет, есть архивная 3.7.2 | мастер = её декод, сверка по нему |
| архивная версия **равна** файлу | **тавтология** → не принимается, считается отдельно |
| архивной версии нет | провал (З-31 п.2) |
| файл побайтово равен 3.7.2 | норме не подлежит (З-31 п.3), не тавтология |

Разделение последних двух пунктов — важно: 129 файлов канона не менялись, и
объявлять их «тавтологией» значило бы выдумать провал там, где его нет.
