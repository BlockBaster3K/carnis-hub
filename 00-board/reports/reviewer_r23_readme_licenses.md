## Что это значит по существу (не формальность)

**1. GeckoLib уже сейчас — жёсткая зависимость, и о ней нигде не сказано.**

```
[[dependencies.carnis]]
modId="geckolib"
mandatory=true
versionRange="[4.4.4,)"
side="BOTH"
```

`mandatory=true` + `side="BOTH"` = **без GeckoLib на сервере мод не запустится**.
По правилу Директора №3 («зависимость = требование к серверу, иначе игроки получат
краш») это ровно тот случай, а README, где это написано, не существует. GeckoLib не
входит в список пяти новых, поэтому `mandatory=true` для него законен — но
**задокументирован он быть обязан**.

**2. Двойное лицензирование не заявлено.** Код — MIT (`mods.toml`), а лор и
иллюстрации журнала (Patchouli, 3.8.0/3.8.1) — CC-BY-NC-SA-3.0 по решению Директора.
Это **две разные лицензии на один продукт**: без явного разделения в README и в
разделе лицензий пакета пользователь не знает, что иллюстрации нельзя использовать
коммерчески, а код можно. Одного `license="MIT"` в `mods.toml` для этого мало: в
метаданных мода есть **одно** поле лицензии и оно про код.

**3. Для 3.8.0/3.9.0 требования ещё не выполнены даже в метаданных.** Пакета 3.8.0
в репозитории пока нет (`01-coder/` заканчивается на `3.7.3`), то есть проверить
`mandatory=false` для пяти новых пока не на чем. Фиксирую это как **предусловие
приёмки 3.8.0**, а не как находку.

## Критерии приёмки R23 (машинно проверяемые)

1. `README.md` присутствует **внутри** пакета (`01-coder/<версия>/*.zip`), а не только в хабе.
2. В README есть все **шесть** имён: `GeckoLib`, `Curios`, `Patchouli`, `SmartBrainLib`, `Lodestone`, `Sound Physics`.
3. В README есть строка `CC-BY-NC-SA-3.0` и отдельное указание, что она — про лор/иллюстрации, а MIT — про код.
4. В README есть фраза о том, что мод работает без необязательных зависимостей (проверка: рядом с каждым из пяти стоит «нет» или «необязательно»).
5. В `mods.toml` **ни одна** из пяти не имеет `mandatory=true`; GeckoLib — имеет (он обязателен).
6. Файл `LICENSE` (MIT) присутствует в пакете.

Пункты 1–6 проверяются grep'ом по распакованному zip — приложу к приёмке 3.8.0
как автоматический блок.
