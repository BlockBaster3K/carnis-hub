## Как накатить

1. Распаковать `.ogg` в `src/main/resources/assets/carnis/sounds/entity/`.
2. В `sounds.json` добавить 27 событий из `sounds_381_additions.json` (ключи `entity.<моб>_<роль>.<действие>`).
3. В `lang/en_us.json` и `lang/ru_ru.json` добавить по 27 строк из `lang_381_additions.json`.
4. Собрать пакет и отдать на приёмку.

Файлы `sounds.json` / `lang_*.json` в этой папке — **уже накатанные** версии из каталога
3.8.1 Звука, их можно просто скопировать целиком вместо ручного слияния
(`sounds.json` 241 событие, `lang_*` 370 ключей).

## Воспроизводимость (важно для приёмки)

Сборка **побайтово воспроизводима**. Без флага `-fflags +bitexact` libvorbis вставляет в
заголовок Ogg случайный serial, и два прогона генератора давали 0 совпадений из 27 —
при этом PCM после декодирования совпадал побитово, различались 31 байт из 27685 (0,1 %).
Флаг обнуляет serial (`00000000`); проверка: два прогона подряд → **27/27** совпадений SHA-256.
Поэтому SHA-256 в `variants_381_table.md` означает «этот звук», а не «этот прогон».
