# I14: манифест пакета 3.8.0 — найден и исправлен чужой манифест 3.7.3

**Дата:** 2026-11-26 · **Итог:** `MANIFEST.txt` внутри пакета пересобран
(1037 путей, самопроверка `sha256sum -c` → код 0); гейт **код 0, ПРИНЯТО**

## 1. Что проверялось

Пакет `01-coder/3.8.0/project-3.8.0-clean.zip`, 1037 файлов. Гейт печатал:

```
✓ манифест: строк 1037, файлов в пакете 1037
```

и был прав — но он сверял **внешний** `project-3.8.0-clean.manifest.txt`,
лежащий рядом с ZIP (я же его и собирал). А внутри пакета лежал **второй**
манифест — `MANIFEST.txt` из scaffold — и его не читала ни одна проверка.

Проверка, которую гейт не делал, показала:

```
путей в MANIFEST.txt:                760
файлов в пакете (без MANIFEST.txt): 1036
НЕ описано:                          277
      132  src/.../sounds/entity/     (все звуки)
       68  src/.../textures/entity/   (33 текстуры + glowmask с доп. файлами)
       42  src/.../animations/        (все анимации)
       33  src/.../geo/               (все модели)
        2  README.md, LICENSE
описано, но нет в пакете: 1
```

Первые строки этого манифеста:

```
Carnis 3.7.3 source scaffold — NOT PACKAGED.
Copied from accepted 3.7.2 scaffold; integrated 12 T3152 creature recolors;
Version 3.7.3 is set in the four required locations; release ZIP is deferred
until package review.
```

**Это манифест 3.7.3.** Он честно говорит «NOT PACKAGED» о версии 3.7.3 —
и лежит в пакете 3.8.0, описывая 760 файлов из 1036.

## 2. Почему это дефект, а не косметика

Пакет 3.8.0 — это 3.7.3 плюс 277 файлов (звуки, модели, текстуры, анимации,
README, LICENSE). Манифест внутри — единственное, что в самом пакете
удостоверяет его состав. Сейчас он:

1. **не описывает 277 файлов** — то есть всё, что отличает 3.8.0 от 3.7.3;
2. **утверждает «NOT PACKAGED» и версию 3.7.3** — прямая неправда о том, что
   в руках у получателя;
3. **бесполезен для получателя**: `sha256sum -c MANIFEST.txt` из корня пакета
   (стандартная процедура, которую я сам же описал в README) не проверяет
   ничего сверх 3.7.3 и не замечает ни одного нового файла.

Тот, кто получит ZIP и решит проверить целостность, получит «всё сходится»
по 760 старым файлам и ни слова о 277 новых. Это хуже, чем отсутствие
манифеста: отсутствие видно, а этот выглядит проверкой.

## 3. Как я его пропустил при сборке

Я собирал ZIP как «скопировать каталог scaffold и добавить материал». Scaffold
включает `MANIFEST.txt` — я его не тронул, потому что он часть исходников.
Свой манифест я генерировал **рядом** с ZIP (`project-3.8.0-clean.manifest.txt`),
и гейт сверял именно его. Две сущности с именем «манифест», проверяется одна,
вторая остаётся в пакете как балласт — и никто не сверяет их между собой.

**Урок для гейта, а не только для этого пакета:** «манифест сходится» должно
значить «файлов в пакете == путей в манифесте», причём для **всех** файлов
с именем, похожим на манифест, а не для первого найденного.

## 4. Что исправлено

`MANIFEST.txt` внутри пакета сгенерирован заново **из фактического состава**
ZIP — 1036 строк `sha256  путь` + шапка, честно описывающая 3.8.0:

```
Carnis 3.8.0 release package — source + assets.
Version 3.8.0 is set in the four required locations ...
Built on top of the accepted 3.7.3 package by adding 33 infected vanilla
mobs (geo + texture + glowmask), 42 animations, 132 entity sounds with
sounds.json events, and README/LICENSE (MIT + CC-BY-NC-SA).
Files in package (excluding MANIFEST.txt): 1036
```

Проверено:

| проверка | результат |
|---|---|
| `sha256sum -c MANIFEST.txt` из корня пакета | **код 0**, все строки OK |
| манифест ↔ пакет: путей / файлов | **1036 / 1036**, не описано **0** |
| внешний манифест рядом с ZIP | пересчитан на новый ZIP |
| гейт `accept_3.8.0.py` | **код 0, ПРИНЯТО** (2 отчётные находки, как раньше) |
| упоминания «3.7.3» в текстовых файлах пакета | **0** |

Размер ZIP 16 955 340 Б (был 16 907 837 — вырос на честный манифест).

## 5. Открытый вопрос — норма, а не пакет

Гейт этого не ловил и **сейчас тоже не ловит**: `check_manifest` проверяет
только внешний файл. Я исправил пакет, но не закрыл дыру в инструменте.
Предлагаю добавить в `accept_3.8.0.py` проверку: если внутри пакета есть
`MANIFEST.txt` — он обязан описывать **все** файлы пакета (кроме себя), и
`sha256sum -c` по нему обязан проходить. Это одна проверка и она ловит
именно тот класс, что случился здесь: чужой манифест, проехавший в пакет
как часть scaffold.

Пока правило не принято, отметка «манифест сходится» в гейте относится
только к внешнему файлу — и это должно быть написано в отчёте, чтобы
следующий читатель не решил, что пакет проверен целиком.
