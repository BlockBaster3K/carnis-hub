# Ревизор · T-3185: `sound_orphans` ловит недостижимые события (обратное направление)

**Дата:** 2026-11-26 · **Зона:** `tools/sound_orphans.py` · Инструмент был мой (`ccd2a13f…`/T-3106), задача совместная с Интегратором — свою часть сдаю.

## 1. Что было

`tools/sound_orphans.py` смотрел только два направления:
- **сирота** — `.ogg` лежит в пакете, а `sounds.json` на него не ссылается;
- **ссылка в пустоту** — `sounds.json` зовёт несуществующий файл.

Третьего не видел никто: событие `ModSounds` **объявлено**, звук в банке **есть**, а **вызова в коде нет** → звук загружен в память, но в игре недостижим. Это находка Звука (11 событий / 15 файлов).

## 2. Что сделано

1. **Разбор `ModSounds.java`:** парсятся все 83 `RegistryObject<SoundEvent>` вместе с ключами (`RE_CONST`), переносы строк внутри объявления поддерживаются.
2. **Проверка достижимости:** для каждой константы ищется `ModSounds.<ИМЯ>` во всех `.java` пакета, кроме самого `ModSounds.java`. Отдельно поддержан `import static ... ModSounds.<ИМЯ>;` — тогда ищется использование по голому имени (импорты из поиска тела вырезаются).
3. **Коды возврата:** `0` — всё чисто; `2` — замечания по ассетам (исторический код, семантика не менялась); **`3` — есть недостижимые события**; `1` — ошибка запуска. Флаг `--assets-only` отключает проверку кода (для приёмки одних ассетов).
4. **Почему `3`, а не `2` (дыра З-24):** гейты `accept_3.7.x.py` трактуют **код 2 как «пропущено/замечания»** и пакет проходит. Проверено: до правки гейт печатал `… sound_orphans → код 2 (пропущено/замечания)` и итог **код 0 по этому блоку**. Отдельный код 3 гейт валит как ✗, то есть fail-closed достигается без правки чужого файла.
