## Коротко

При приёмке 3.7.2 гейт `tools/accept_3.7.2.py` даёт **код 1** из-за **3 ложных ✗**
в блоке 12 — «перекраски: нет архива `Carnis_3.7.2_T3115_block_recolor.zip`».
Пакет при этом **корректен**: все 144 `.ogg` == банк побайтово, манифест
сходится, клиппинг 0, перекраски == сдаче Художника 3 из 3.

Причина: блок 12 читает архив **из рабочего дерева**
(`os.path.join(REPO, "04-artist", "deliverables", arch)`, стр. 552).
У проверяющего с sparse-checkout этого каталога нет — файл не открывается,
и гейт рапортует расхождение, которого нет.

**Это З-17, не закрытый для текстур.** З-17 (`tools/baseline.py`) починил
эталон 3.6.0-R, но блок 12 остался на прямом `os.path.exists`.

## Решение готово и проверено

`tools/baseline.py` уже умеет ровно то, что нужно, и **не привязан** к
3.6.0-R: `resolve(path, rev)` принимает любой путь.

Проверка на архиве перекрасок:

```
файла на диске: False
  · эталон: git-объект HEAD:04-artist/deliverables/Carnis_3.7.2_T3115_block_recolor.zip (17937 Б)
resolve → статус=ok, откуда=git:HEAD
   путь: /tmp/baseline-51nm8n3j.zip
   читается как ZIP: 24 записей
   ✓ archive_spore_sprout sha = c50c3b2e8dd5e5aa…
```

**Правка одной строки-двух:** в `check_recolor_allowlist` заменить

```python
zp = os.path.join(REPO, "04-artist", "deliverables", arch)
archives[zp] = zipfile.ZipFile(zp) if os.path.exists(zp) else None
```

на `baseline.resolve(zp, rev="HEAD")`, а ветку `z is None` перевести из
`fail.append(...)` в **пропуск с явной пометкой** — как требует сам
`baseline.py`: «не смог проверить» ≠ «проверил, не сходится».
