## 3. Правила приёмки — сводно

**Общее для всех ролей.** Принимается **по файлам, не по отчёту**. Отчёт без
хешей и без путей — не отчёт.

| Что | Чем | Что считается дефектом |
|---|---|---|
| Пакет Кодера | `sha256sum -c` → 0 FAILED; число файлов = число строк манифеста; `mod_version` = имя папки; все JSON разбираются | любое расхождение |
| Совместимость 1.20.1 | каждый новый вызов — по официальным маппингам Mojang 1.20.1 / Forge 47.4.28 | метода нет в маппингах |
| Д1 | паузы посчитаны по коду на всём цикле, показан нижний предел | пауза ≤ 12 тиков где-либо на цикле |
| Д2 | фактический диапазон `soundDelay` | диапазон пересекает ≤ 28 тиков |
| Д3 | `HEARTBEAT_MAX_SAMPLE_SECONDS` отсутствует либо реально применяется | константа жива и не используется |
| Д4, Д7 | хеши в манифесте совпадают с таблицами выше | хоть один хеш не тот |
| Д5 | геометрия изменилась байтами; компланарных пар и мёртвых кубов нет | осталась хоть одна пара |
| Д6 | разброс доведён до порога 12 | разброс > 12 |
| Палитра флоры | **пересчёт L и S по пикселям** | L вне 60 ± 5 % или S > 15 % |
| A3/A6 | шесть критериев — §4 | любой из шести не сходится |
| Звук | манифест совпадает с диском; файлы декодируются | расхождение с диском |

**Грабли проекта, на которые уже наступали:**

- `Level#getGameEventDispatcher(BlockPos)` **не существует** в 1.20.1 — ручную
  регистрацию `GameEventListener` делать не нужно, vanilla `LevelChunk`
  регистрирует listener через `GameEventListener.Holder#getListener()`;
- в production-сборке ForgeGradle переименовывает методы Minecraft в SRG-имена
  (`getListener` → `m_280052_`) — **ищи по SRG-имени**, иначе вывод о наличии
  переопределения будет ложным;
- имена — **только Mojmap**, никаких Yarn-имён (`getListenerRegistry`, `addListener`);
- `LadderBlock` уже объявляет `FACING` — **не объявляй `facing` заново**.

## 4. Переформулированные критерии A3/A6

Прежние критерии — «совпадение кромок» + «содержимое не прижато к краю» —
**противоречили друг другу**: вместе они требовали пустого кольца по краю
плитки, а такое кольцо на стене образует **прозрачную решётку**. Отсюда четыре
неудачные пробы. Теперь критериев **шесть**:

1. попарный **seam** (стыки вариантов без щели);
2. сетка **3×3** и **5×5** со смешением — шов и периодичность;
3. **совпадение кромок** (побайтово, и у всех вариантов кромка одна);
4. **читаемость в 16 px**;
5. **торцы и углы**: кромка заполнена **≥ 45 %** непрозрачных в полосе 3 px; вдоль
   кромки нет прямой полосы длиннее **24 px**; углы **≤ 10 из 16 px**;
6. **нет решётки**: средняя альфа у границы плитки в проекции 16 px — не ниже
   **35 %** от альфы внутри плитки.

**Стенд проверки** (общий для Художника и Ревизора, лежит в репозитории):
`tools/tendrils/tendrils_check.py <каталог> <out.json>` →
`ИТОГ: ВСЁ СХОДИТСЯ` / `ИТОГ: ЕСТЬ ЗАМЕЧАНИЯ`.
