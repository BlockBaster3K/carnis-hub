# Интегратор: гейт 3.8.0 покраснел бы на ПРАВИЛЬНОМ пакете — доказано двумя подлогами

**Дата:** 2026-11-26 · **Как нашёл:** сравнил две общие функции двух гейтов
(`check_delta_372`) · **Правка:** `tools/accept_3.8.0.py`, константа `GROWN_380`

## 1. Что показало сравнение

Прогнал AST-сравнение общих функций `accept_3.7.3.py` и `accept_3.8.0.py`.
Из 20 общих расходятся 4. Одно расхождение — по существу:

```
3.7.3:  cmd += ["--allow", "src/main/resources/assets/carnis/sounds.json"]
3.8.0:  (такой строки нет)
```

В 3.8.0 дельта разрешала **только** `src/main/java/` и одну маску
`flesh_amalgam_glowmask.png`.

## 2. Почему это дефект, а не «3.8.0 строже»

По смыслу 3.8.0 обязан принести **33 новых существа** (geo + текстура +
glowmask) и **132 новых звука** плюс события для них в `sounds.json`. Всё это —
**добавление** файлов в каталоги `textures/entity/`, `geo/`, `sounds/` и правка
`sounds.json`.

А гейт 3.8.0 валил любое из этого как «не разрешено». То есть **на сдаче,
собранной ровно по заданию, приёмка дала бы красный**, и интегратор пошёл бы
искать дефект в пакете Кодера, которого нет.

Это худший вид ложной тревоги: не «пропустил дефект», а **обвинил правильную
работу**. Стоимость — часы Кодера на поиск несуществующей ошибки.

## 3. Доказательство (два подлога, оба прогоном)

Собрал пакет 3.7.3 + добавленные файлы, которые 3.8.0 обязан принести.

**Подлог А — рост.** Добавлены 2 `.ogg`, 1 `.geo.json`, 1 PNG (настоящий
64×64, 8 цветов), и `sounds.json` получил новое событие.

| прогон | вердикт |
|---|---|
| без роста-разрешений (как было) | ✗ «добавлено 6 файлов, не разрешено: geo/…, sounds/…, textures/…» — **код 2** |
| с роста-разрешениями | ✓ «ИТОГ: СХОДИТСЯ» |

Отдельно проверил `sounds.json`: без разрешения — «✗ неожиданные изменения
содержимого: sounds.json», код 2. Разрешение на **два каталога звуков**
проблему не снимало — нужен был именно файл.

**Подлог Б — удаление (проверка, что я не ослабил норму).** Удалил
существующий `sounds/amb/hive_ambient_01.ogg`, оставив все разрешения:

```
✗ пропали файлы: 1
ИТОГ: ЕСТЬ РАСХОЖДЕНИЯ
```

Удаление по-прежнему ловится. Разрешения касаются только добавления.

## 4. Что исправлено

Новая константа с объяснением, почему каталоги именно эти:

```python
GROWN_380 = (
    "src/main/resources/assets/carnis/textures/entity/",
    "src/main/resources/assets/carnis/geo/",
    "src/main/resources/assets/carnis/sounds/",
    "src/main/resources/assets/carnis/sounds.json",
)
```

Применяется вместе с `EXPECTED_CHANGED_PNG`. В 3.7.3 этот блок не тронут:
там рост не ожидается, и `sounds.json` разрешён точечно по своей причине
(S17, смысловая проверка следом).

## 5. Почему это не «разрешить всё»

Разрешение узкое по трём осям:

1. **только добавление** — удаление и изменение существующих файлов падают
   (подлог Б);
2. **только четыре пути**, где 3.8.0 обязан вырасти;
3. **состав проверяется отдельно** — блок 16 требует у каждого нового
   существа geo + текстуру + glowmask (и размер маски, З-Г5(B)), блок 9д
   требует 132 файла ↔ 132 события, блок 7 валит сирот.

То есть проверка не отменена, а переехала туда, где она содержательнее:
«файл появился» — слабое утверждение, «у существа полный комплект» — сильное.

Первый негатив (удаление) я сделал на файле `infected_skeleton_hurt_01.ogg`,

это тест, который не может провалиться.
