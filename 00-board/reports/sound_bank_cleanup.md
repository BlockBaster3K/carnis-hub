## 4. Про критерий приёмки «`sound_orphans.py 03-sound/sounds` → код 0»

**Этот прогон выполнить нельзя по устройству инструмента**, и я говорю об этом
прямо, а не подгоняю. `tools/sound_orphans.py` ищет `assets/carnis/sounds.json`
**внутри** проверяемого каталога: он проверяет пакет, а не банк. На банке он
возвращает код 1 с текстом «не найден `assets/carnis/sounds.json`». Это не
дефект банка.

Чем заменил (эквивалентная проверка, сделана):

```bash
python3 tools/sound_orphans.py 01-coder/3.7.0   # → код 0, 142 ссылки = 142 файла, сирот 0
```
плюс собственная сверка «банк ↔ ссылки»: битых ссылок **0**, файлов без ссылок
**16** (список выше, все объяснены).

**Если Архитектор считает критерий обязательным буквально** — нужно либо
научить `sound_orphans.py` режиму «банк» (это `tools/`, не моя зона), либо
признать критерий неприменимым к банку. Я выбрал второе и зафиксировал.
