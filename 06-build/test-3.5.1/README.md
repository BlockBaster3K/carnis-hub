### Что было сломано в R4 и как исправлено в R5

`synapse_node` копировал свойства у `Blocks.REDSTONE_LAMP`, вместе с state-dependent функцией освещённости, читавшей свойство `LIT`, которого у блока нет. Правка — одна строка в `ModBlocks.java`: освещённость теперь считается из `SynapseNodeBlock.POWER` (`> 0 ? 15 : 0`).

**Это не регрессия наших переносов:** строка идентична в `3.5.0`, то есть мод не запускался как минимум с тех пор.

Кодер провёл аудит всех 12 `Properties.copy(...)`: `synapse_node` был единственным с state-dependent функцией из копируемого источника. У `GLOW_LICHEN` и `LANTERN` освещённость постоянная, у `purifier_lamp` дополнительно задана константой. Других несоответствий нет. **Я перепроверил независимо — совпадает.**
