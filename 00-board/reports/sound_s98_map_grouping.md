## 4. Поправка: правило перестало быть fail-open

Было (моё, негодное): `разброс > 3 дБ → «объявлено в спеке» → ok`.
Стало:

```
разброс <= 3 дБ                                    -> ok
иначе: в спеке есть цель для КАЖДОГО сэмпла события
       И остаток после применения множителей <= 1 дБ -> объявление ПОДТВЕРЖДЕНО
иначе                                              -> находка
```

Остаток считается как `RMS + 20·lg(target)` по каждому сэмплу и разброс между ними.
Без `--spec` событие **не засчитывается** как решённое — прямо об этом пишется в итоге.
