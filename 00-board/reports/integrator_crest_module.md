# Интегратор: блок 12б вынесен в модуль — одна норма на оба гейта

**Дата:** 2026-11-26 · **Коммит:** `2449290`

## 1. Почему не скопировал

Раньше я писал: «перенесу 12б в 3.8.0, когда появится пакет». Причина была
честная (нечего прогонять), но вывод неправильный: я собирался **скопировать**
268 строк. Копия — это второе определение нормы, и оно разойдётся с первым
ровно так же, как уже разошлось (Ревизор I23 §9: старый `rescue` в 3.8.0
против таблицы в 3.7.3).

При этом я сам же писал Ревизору: «пока определений два, они расходятся — это
не случайность, а структурная причина». И в том же отчёте просил Звука не
заводить второе определение. Копирование противоречило обоим.

## 2. Что сделано

`tools/crest_master.py` — 500 строк, весь блок целиком:

| часть | что внутри |
|---|---|
| `_decode` / `_crest` / `_attack` / `_dsp` | измерение (PCM16 → [-1,1]) |
| `_table_types` | таблица З-30 (тип, порог, baseline, допуск) |
| `_baseline_master` | `baseline_master.json` схема v2 + fail-closed |
| `_prev_version_bytes` / `_write_temp_decodable` | S44: мастер = декод 3.7.2 |
| `_unchanged_vs_prev` | З-31 п.3: побайтово равен → норме не подлежит |
| `check_crest_attack(extract_dir)` | возвращает **список провалов** |

Модуль **не** завершает процесс и **не** пишет в чужой `fail`: он возвращает
список, гейт решает код. Иначе «модуль» был бы гейтом внутри гейта.

Оба гейта — тонкие адаптеры:

```python
_cm = _load_crest_master()
if _cm is None:
    fail.append("crest/атака: модуль проверки отсутствует")   # fail-closed
else:
    for msg in _cm.check_crest_attack(tmp):
        fail.append(msg)
```

## 3. Проверки

| что | результат |
|---|---|
| модуль автономно, пакет 3.7.3 | 15 от мастеров, 129 не подлежат, **0 провалов** |
| `accept_3.7.3.py` через модуль | вывод **побайтово тот же**; код **1** только `sound_orphans` |
| `accept_3.8.0.py` через модуль, популяция 132 | 132/132, **0 провалов** |
| модуль отсутствует | **fail** («проверка не выполнена»), не «ок» |

Ключевое: поведение 3.7.3 **не изменилось**. Если бы изменилось — значит при
выносе я что-то потерял, а не просто переставил.

## 4. Чего пока не сделал

**12а в 3.8.0 не удалил.** Там остался старый `rescue` (шум + допуск) —
тот самый, который Ревизор назвал consistency debt. Удалять его вслепую, без
пакета, я не буду: 12а умеет то, чего 12б не умеет (сверка с round-trip по
архиву, когда мастера нет). Заменю/оставлю — по результату прогона на
настоящем пакете: если 12б покрывает всё, что покрывало 12а, — уберу, чтобы
не держать два механизма.

## 5. Что это даёт приёмке

Теперь норма crest для 3.8.0 — **та же**, что для 3.7.3, и её нельзя
разъехать незаметно: файл один. Любая правка нормы (например, решение
Архитектора по стационарным) немедленно действует в обоих гейтах, и это
видно по одному diff, а не по двум.
