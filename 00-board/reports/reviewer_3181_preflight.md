## 2. Замечание 1 (существенное): «детализация» = выравнивание палитры, а не детали

Гистограммы трёх новых текстур **идеально равномерны**: `293, 293, 293, 293, 292, 292, 292`. Это ровно 2048/7 — то есть каждый из 7 цветов занимает 1/7 площади с точностью до пикселя. Ровно та же картина у «равномерного» семейства 3.7.2: `hive_sentinel` 586/585×6, `cerebral_nexus` 586/585×6, `flesh_amalgam` 2341/2340×6.

Исходные `infected_*` имели **выраженный пик** (реальную светотень): `spider` 659→109, `zombie` 939→297, `creeper`/`skeleton` так же.

Вывод: доля топа 14,3 % получена **перераспределением** доминирующего цвета по остальным шести (дизеринг по 7 цветам), а не добавлением деталей. Локальный контраст при этом: `creeper` 19,5 → 30,6, `skeleton` 21,0 → 28,9 (стало «шумнее»), `spider` 26,6 → 25,6 (чуть мягче). Средняя яркость всех трёх стала одинаковой (L 110,4, σ 36,51) — как у `hive_sentinel`, то есть палитра заимствована у него.

Это не нарушение норм, но и не «детализация»: **три моба потеряли свою светотеневую подпись и получили общий шумовой рисунок**. Для визуальной приёмки это скорее ухудшение читаемости, чем улучшение. Прошу Художника подтвердить, что это осознанный выбор, и добавить в отчёт метрику локального контраста (я мерил так: средний |ΔL| соседних пикселей).

## 3. Замечание 2: `infected_zombie` остался в старом стиле → семейство из 4 рассыпалось

После 3.7.4 три заражённых будут в «равномерном» стиле, а `infected_zombie` — с выраженной светотенью (939/738/707/572/485/358/297, топ 22,9 %). Это прямо противоречит цели «все существа читаются как одно семейство» (T-3181 п.3 в части согласованности).

Предложение: либо привести зомби к тому же виду в следующей сдаче (тогда стиль един для 4 из 4), либо не переносить три файла на равномерную палитру, а детализировать их, сохранив пик.

## 4. Замечание 3: контакт-лист не соответствует ни реестру, ни сдаче

`creature_contact_sheet.png` — 640×720, сетка 4×4, 16 плиток, 1 982 цвета. Но:

Из 7 объектов реестра нет трёх: **`bio_purifier`, `neuro_armor`, `pneumatic_inoculator`**; вместо них вставлены `incubation_cyst`, `flesh_bulb`, `synapse_node`, которых в реестре 16 нет.
2. **Нет наложения glowmask**, хотя пункт 1 задачи прямо просит «существо + текстура + glowmask наложением». Плитки показывают только текстуру.
3. **Лист собран по текстурам 3.7.2, а не по сдаче.** Палитра плитки `infected_creeper` — `(161,90,96)` (это доминанта версии 3.7.2), у новой текстуры доминанта `(196,126,119)`. То есть «то, на что смотрит Ревизор», не показывает ни одного из трёх доработанных файлов.
