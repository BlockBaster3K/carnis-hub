# S118 · Шаг S12: тембровая норма не выполняется на 85 файлах из 144 — и это вывод о НОРМЕ

**Кто:** Звук · **Шаг:** S118 (план S12) · **База:** `c75ca49`
**Норма из:** `00-board/ROADMAP_sound.md` → S12
**Кому:** Архитектору (решение), Ревизору, Интегратору

---

## 1. Что измерено

`tools/timbre_base_check.py` — три метрики по всем 144 файлам канона, без
нормализации (тембр, не громкость): спектральный центр (взвешенное среднее по
спектру мощности), доля энергии ниже 80 Гц, шов петли (разрыв RMS первых и
последних 10 мс).

| норма S12 | файлов вне нормы |
|---|---:|
| спектральный центр ≥ 400 Гц | **51 из 144** |
| энергия < 80 Гц ≤ 25 % | **25 из 144** |
| шов петли ≤ 1 дБ | **9 из 13 петель** |

Пересечения дают **85 файлов** вне хотя бы одной нормы — **59 % банка**.

## 2. Проверил, не артефакт ли это методики

Взял худший случай, `zone_stinger_deep`, и разложил по полосам:

| полоса | доля энергии |
|---|---:|
| 0–40 Гц | **64,8 %** |
| 40–80 Гц | 20,0 % |
| 80–160 Гц | 7,6 % |
| 160–400 Гц | 3,1 % |
| 400 Гц–4 кГц | 4,5 % |

Центр **114 Гц**. Автокорреляция пиков > 0,5 не даёт — это **не тон**, а
настоящий инфранизкий гул. Расчёт корректен: файл действительно почти целиком
лежит ниже 80 Гц.

## 3. Вывод, который я обязан назвать прямо

**Норма S12 не описывает этот банк.** Это не «59 % брака» — это норма, взятая
из другого контекста.

Причина видна по данным: **весь худший класс — это то, что по замыслу низкое.**

| файл | энергия < 80 Гц | что это |
|---|---:|---|
| `zone_stinger_deep` | 84,8 % | «глубокий» стингер зоны |
| `zone_stinger_release` | 81,4 % | снятие зоны |
| `hive_heartbeat` | 79,5 % | **сердцебиение** |
| `hive_spawn_death_01/02/04` | 73,7–77,5 % | смерть существа |
| `hive_spawn_idle_04/01` | 73,0–80,3 % | дыхание улья |

Сердцебиение с центром выше 400 Гц — это уже не сердцебиение. Требование
«центр ≥ 400 Гц» для `hive_heartbeat` противоречит самому звуку.

## 4. Что при этом НЕ является предметом спора

**Шов петель — настоящая находка, и она серьёзная.** Здесь норма применима
всегда: если файл играется по кругу, разрыв на стыке слышен как щелчок.

| файл | шов | длина |
|---|---:|---|
| `hive_pulse_02` | **30,2 дБ** | 13,4 с |
| `hive_pulse_01` | **29,3 дБ** | 13,4 с |
| `hive_pulse_03` | **27,5 дБ** | 13,4 с |
| `hive_ambient_tonal_stinger` | 7,4 дБ | 10 с |
| `hive_ambient_02` | 3,0 дБ | 120 с |
| `amb_surface` / `amb_deep` | 1,8 / 1,6 дБ | 120 с |
| `hive_ambient_close_02`, `hive_ambient_01` | 1,4 / 1,3 дБ | 120 с |

**30 дБ на стыке — это не «шов», это обрыв.** Три файла `hive_pulse` играются
фоном постоянно; разрыв в 30 дБ означает, что каждый цикл заканчивается
хлопком.

Это укладывается в уже существующий шаг **S22** роадмапа («швы 1 с → 100 мс»),
где материала на 9 нарушений. **Мой замер даёт те же 9 файлов** — то есть
независимо подтверждает S22 с другой стороны.

## 5. Что предлагаю

| норма | предложение |
|---|---|
| шов петли ≤ 1 дБ | **принять как норму немедленно** — она верна, и 9 файлов чинятся |
| центр ≥ 400 Гц | **не применять ко всему банку.** Либо по классам (речь/удар — да; гул/сердцебиение/стингеры — нет), либо отменить |
| энергия < 80 Гц ≤ 25 % | то же: для `zone_stinger_*`, `hive_heartbeat`, `hive_spawn_death` это **замысел** |

**Порог я не подгоняю.** Мог бы «найти» 400 Гц медианой или применить норму
только к 131 короткому файлу — получил бы «зелено» и не сказал бы ничего. Вместо
этого пишу: норма из роадмапа не соответствует банку, решение — за Архитектором.

## 6. Шаг S13 (решения по отклонениям) — готов как материал

| класс | файлов | предлагаемое решение |
|---|---:|---|
| шов > 1 дБ | **9** | **чинить** (S22 уже это планирует) |
| низкий центр + много низа, файл по замыслу низкий | ~40 | **принять с обоснованием** («глубокий гул/сердцебиение») |
| низкий центр, замысел не очевиден | ~11 | **разобрать поштучно** — нужен список от Архитектора |
| пограничные (центр 380–400 Гц) | 6 | принять: разница с нормой < 5 % |

## 7. Инструмент

`tools/timbre_base_check.py --bank 03-sound/sounds [--all] [--json]`
Коды: 0 — в норме; 2 — отклонения; 3 — не проверено.
Шов считается **только у петель** (13 файлов): у одноразового удара шва нет по
определению, и включать его в счёт было бы завышением.
