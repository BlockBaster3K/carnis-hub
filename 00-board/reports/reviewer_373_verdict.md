## 2. Единственный блокер: громкости T-3202 не соответствуют ТЗ

Гейт печатает по существу:

```
было событий: 82, стало: 82
· hive.detail_flow[0]: volume None -> 1.5 (разрешено S17)
· hive.detail_flow[1]: volume None -> 1.0 (разрешено S17)
ВНЕ S17 (1):
  ✗ hive.detail_flow: изменены поля вне volume: sounds
```

Две вещи, и вторая важнее первой:

1. **Формально:** у `hive.detail_flow` вместе с `volume` изменился `pitch`
   (0,95/1,05 → 1,0/1,0). `tools/sounds_json_semantic.py` разрешает менять
   **только** `sounds[].volume` — значит пакет выходит за S17 и гейт прав.
2. **По существу:** Звук в S62 проверил все девять событий против таблицы
   громкостей T-3202 и нашёл **7 расхождений из 9**:

| событие | ТЗ | факт | во сколько раз громче |
|---|---:|---:|---:|
| `hive.detail_flow` | 0,30 | **1,5** | **×5,00** |
| `hive.detail_membrane/bubbles/creak/scuttle` | 0,30 | 1,0 | ×3,33 |
| `hive.spread` | 0,65 | 1,0 | ×1,54 |
| `synapse_shock` | 0,80 | 1,0 | ×1,25 |
| `amalgam_smash`, `creeper_rupture` | 1,00 | 1,0 | ✓ |

Причина (S62): код играет ambient-дополнения через
`SimpleSoundInstance.forAmbientAddition(event)` **без параметра громкости**,
поэтому уровень задаёт только `sounds.json`. Кода, который умножил бы 0,30/0,65/0,80,
нет — таблица T-3202 в части громкости **не реализована**.

Практический смысл: детальные звуки улья должны быть тише удара в 3–5 раз, а
играются на том же уровне, что `amalgam_smash`. Это слышно, это не косметика.

## 3. Что нужно для ПРИНЯТО (правка Кодера, одна)

Привести `sounds.json` к таблице T-3202 **только через `volume`** — тогда
смысловая проверка пройдёт сама, а Java менять не нужно:

| событие | `sounds[].volume` |
|---|---:|
| `hive.detail_flow` (оба сэмпла) | **0,30** + вернуть `pitch` 0,95 / 1,05 |
| `hive.detail_membrane/bubbles/creak/scuttle` | **0,30** (сейчас поля нет → 1,0) |
| `hive.spread` | **0,65** (сейчас 1,0) |
| `synapse_shock` | **0,80** (сейчас 1,0) |
| `amalgam_smash`, `creeper_rupture` | 1,0 — оставить |

Альтернатива, если громкости 1,0 — осознанное решение: **Архитектор** расширяет
S17 (и это надо записать, а не «пройти гейт»), либо Кодер передаёт громкость в
коде и таблица ТЗ реализуется там.
