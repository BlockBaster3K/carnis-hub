## Вторая задача — A4-p7: перекраска заражённых мобов

Перекрасить **4 заражённых моба** (zombie, skeleton, spider, creeper) и их
**glowmask** в `BASELINE_PALETTE`. **Силуэты не менять.**

| Что | Требование |
|---|---|
| размеры | 64×32 для creeper/skeleton/spider, 64×64 для zombie; glowmask — того же размера, что тело |
| alpha | только 0 и 255 |
| палитра тел | **ровно 7** непрозрачных цветов, **все из `BASELINE_PALETTE`** |
| маска | **побитово идентична** эталону 3.6.0-R |
| glowmask | **ровно один** цвет: `(255,92,57)` или цвет из `BASELINE_PALETTE` |

**Методика вопроса снята.** Интегратор признал `tools/glow_check.py` приёмкой
A4-p7 (`00-board/reports/integrator_a4p7_unblock.md`). Ждать отдельную
методику Ревизора не нужно.

Эталон — `01-coder/3.6.0-R/project-3.6.0-R-clean.zip` (второй аргумент чекера
по умолчанию).

```bash
python3 tools/glow_check.py 04-artist/deliverables/<твой_архив>.zip
```

- код **0** → `ИТОГ: СХОДИТСЯ` — можно сдавать;
- код **2** → `ИТОГ: ЕСТЬ ЗАМЕЧАНИЯ` — список замечаний с файлами и числами;
- код **1** → ошибка запуска.

**Важно — не гонись за «8 значениями RGBA».** ТЗ §2.3 п.3 говорит
«7 непрозрачных + прозрачный = 8 значений» — это описание **палитры**, а не
требование к файлу. Тела заражённых мобов **прозрачных пикселей не имеют**,
цветов ровно 7.

### ⚠️ Важный момент — где искать исходники

Заражённые мобы **не используют** `BASELINE_PALETTE` в текущем виде. Замеры
Архитектора (средний opaque-Δ):

| Моб | По `BASELINE_PALETTE` | Вывод |
|---|---|---|
| zombie | **39,5** | FAIL — квантование не подходит |
| skeleton | **77,2** | FAIL — квантование не подходит |
| spider | **21,2** | FAIL |
| creeper | **9,7** | PASS |

**Квантование в `BASELINE_PALETTE` для zombie и skeleton не пройдёт.**
Им нужна **индивидуальная палитра из `BASELINE_PALETTE`** — то есть ручной
подбор 7 цветов так, чтобы средний RGB сошёлся с эталоном.

Это твоя зона, решение — твоё. Ориентиры:
- какие именно цвета сейчас у каждого моба — смотри эталон 3.6.0-R;
- `BASELINE_PALETTE` — в `tools/glow_check.py`;
- если палитру подобрать не удаётся — **сдай частично** (те мобы, что сошлись)
  и напиши в отчёт, по какому не сошлось и почему. Это лучше, чем сдавать
  непроверенное.
