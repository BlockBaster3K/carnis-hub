## 3. Поправка к моему §11.3: «воспроизводимость 0,033 дБ» — это был outlier

В §11.3 я взял 0,033 дБ с одного файла (`breeze`) и подал как свойство
конвейера. По всем 147:

| | медиана | макс | > 0,05 |
|---|---:|---:|---:|
| `repro_delta` (Звук) | **0,0020** | 0,282 | **11 из 147** |

То есть **типичная** воспроизводимость — 0,002 дБ, запас 0,05 больше неё в
**25 раз**, и моё предложение «поднять запас до 0,10» **не нужно**. Хвост из 11
файлов — отдельная история: там собственный разброс кодека больше запаса.
Смотреть на них надо не запасом на всех, а индивидуально.

Проверил и самосогласованность нормы: у 147 файлов `|Δ − baseline| ≤ repro +
0,05` выполняется **всё**, а `|Δ − baseline| ≤ repro` — только у 69 (78
нарушений, худшее превышение **0,001**). Значит фактический файл отличается от
свежего перекодирования своего мастера ровно на величину шума кодирования, и
запас 0,05 — это и есть допуск на этот шум. Норма непротиворечива.

## 4. Чего не хватает для внедрения (Интегратору)

1. **`baseline_master.json` не читает ни один гейт**: `grep baseline_master`
   по `tools/accept_3.7.3.py` и `tools/accept_3.8.0.py` — **0 вхождений**.
   Артефакт измерен, но приёмка по-прежнему берёт **табличный** baseline,
   который для сравнения с мастером неверен (§11.2). Это последний шаг I23.
2. **В JSON нет типа сигнала** (`стац/транз`) и порога — придётся джойнить с
   `sound_crest_baseline.md` (276 строк с типом). Как показал §2 выше, ошибка в
   типе меняет число провалов, поэтому лучше положить `type` и `threshold`
   прямо в запись, чтобы гейт читал **один** артефакт.
3. `kbps_actual` в JSON — 151…296 кбит/с на `sounds_380` (медиана 182).
   Это нормально для VBR при номинальном пресете 160k (Звук сам поправил
   контракт в S48), но формулировку нормы стоит так и записать:
   «номинальный пресет 160k (VBR)», иначе приёмка однажды потребует «ровно 160».

## 5. Итог

S48 — **принято**: `baseline(M)` измерен, машиночитаем, воспроизводим и
совпадает с моей независимой трубой на 12/12 файлах. Осталось **внедрить**:
гейт должен читать этот файл (с типом сигнала внутри) вместо табличного
baseline. Мой §11.1 (запас 0,10) **снимаю** — измеренная вариативность 0,002 дБ.
