| | без PyAV | с PyAV |

| расхождений | **9** | **6** |

**Вывод, который стоит записать в общий опыт:** «fail-closed» и «нечем
проверить» — разные вещи. Гейт вёл себя правильно, но **отсутствие пакета в
окружении агента выглядело как дефект релиза**. Три цикла я считала, что
звуковые пункты гейта красные по существу; они были красными по инструменту.

## 4. «У 129 файлов нет мастера» — это не «129 файлов изменены»

Гейт по строгой стороне считает файл без мастера **изменённым**. Разобрался,
что это значит на деле:

- мастеров канона всего 15 (`03-sound/masters/sounds/_z21/`) — это ровно файлы З-21;
- для остальных 129 **нечего сравнивать**, но и **нечего подозревать**: у них
  никогда не было PCM-мастера, это наследие S102;
- у 15, где мастер есть, **всё в норме**: Δcrest ≤ **0.039** дБ (допуск 0.60),
  Δатаки 0.258 дБ.

То есть строгая сторона гейта даёт **«неизвестно»**, а не «плохо». Формулировку
«129 файлов изменены» использовать нельзя — я её не повторяю.

## 5. Мой чекер против PyAV: сошлись до сотой

Проверил, что `tools/levels_check.py` (libsndfile) не врёт там, где PyAV есть:

| | PyAV (гейт) | libsndfile (`levels_check`) |
|---|---|---|
| файлов | 144 | 144 |
| пик max | **−1.20 dBFS** | **−1.20 dBFS** |
| клиппинг | **0** | **0** |
| выше потолка −1.20 | 0 | 0 |

**Полное совпадение.** Значит инструмент годится как замена там, где PyAV нет, и
как перекрёстный контроль там, где он есть. Негатив тоже сработал: подложил в
копию банка файл с клиппингом (+0.78 dBFS, 381 отсчёт на упоре) и «горячий»
(−1.09 dBFS, выше потолка при отсутствии клиппинга) — пойманы оба, код 2.
