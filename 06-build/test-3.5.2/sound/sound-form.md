# Форма по звуку — Carnis 3.5.2

Заполните после проверки из чек-листа (часть 5.5). По одной строке на звук.

> **Сначала — что где звучит.** Это разные звуки в разных местах:
>
> | Звук | Источник | Когда слышен |
> |---|---|---|
> | `heart_pulse` (одиночный удар) | блок **Flesh Bulb** (`flesh_bulb`) | рядом с луковицей, пока она зреет |
> | `heartbeat_loop` (луп) | клиентский «галлюцинационный» пульс игрока | когда у игрока **накопилась инфекция** (стадия ≥ 1); при высокой — чаще |
>
> «Сердце биома» (Pulsing Heart) — **не источник** этих ударов: он пульсирует
> раз в 5 секунд, и удар сердца у него звучит только в момент превращения.

## Проверяем звук

| Звук | Где слышен | Ожидается | Ок | Комментарий |
|---|---|---|---|---|
| Удар сердца (`heart_pulse`) | рядом с блоком **Flesh Bulb** | периодический удар, без щелчков | ☐ | |
| Фоновый гул (`heartbeat_loop`) | при накопленной инфекции, у себя рядом с игроком | ровное зацикливание, без щелчка на стыке | ☐ | |
| Взмах костяной косой | взмах по воздуху | короткий взмах | ☐ | |
| Удар костяной косой | попадание по мобу | звук попадания | ☐ | |
| Взмах окостеневшей косой | взмах по воздуху | другой тембр, чем у костяной | ☐ | |
| Удар окостеневшей косой | попадание по мобу | звук попадания | ☐ | |
| Звук блока «Око разума» | установка / разрушение блока | органический звук мода | ☐ | |

## Частота ударов Flesh Bulb

Меряйте **в одном месте**, не отходя: частота зависит от **возраста луковицы**,
а не от расстояния.

| Момент | Ударов за 30 секунд | Интервал (примерно) |
|---|---|---|
| сразу после установки | ______ | ______ с |
| через ~30 секунд | ______ | ______ с |
| через ~60 секунд | ______ | ______ с |

**Ожидание:** интервал **сокращается** от примерно **2,0 с** (40 тиков) в начале
цикла до примерно **0,5 с** (10 тиков) к концу. Это **не** постоянные 1,7–2,3 с.

### Контроль: зависит ли частота от расстояния?

| Расстояние до Flesh Bulb | Ударов за 30 секунд | Комментарий |
|---|---|---|
| вплотную (1–2 блока) | ______ | |
| 5 блоков | ______ | |
| 15 блоков | ______ | |
| 25+ блоков | ______ | |

**Ожидание:** число ударов примерно **одинаково** во всех строках — дальше звук
просто **тише** (в Minecraft блоковый звук слышен в пределах ~16 блоков).
Если на большом расстоянии ударов **заметно меньше** — отметьте это отдельно:
в коде зависимости частоты от расстояния нет, это может быть дефект.

### Контроль: наложение в конце цикла

| Что слышно | Ок |
|---|---|
| В начале цикла — ровные отдельные удары | ☐ |
| К концу цикла — удары **накладываются**: щелчок или «двойной удар» | ☐ |
| Через сколько секунд от появления луковицы это началось | ______ с |

> ⚠️ Наложение в конце — **известный дефект 3.5.2**: интервал (10 тиков)
> становится короче самого звука (12 тиков). Правка готовится в 3.5.3.
> Отметьте, слышно это или нет.
