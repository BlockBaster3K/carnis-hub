# K8-S · Два `amalgam_breath`: решение — подключены и слышны

## 1. Решение

**`amalgam_breath_01.ogg` и `amalgam_breath_02.ogg` — ПОДКЛЮЧИТЬ (уже подключены),
не удалять.** Удалять нечего: в текущем пакете 3.7.2 они **уже являются
вариантами события** `hive.amalgam_breath`.

Вот это событие в `01-coder/3.7.2/src/main/resources/assets/carnis/sounds.json`:
```
"hive.amalgam_breath": {
  "sounds": [
    {"name": "carnis:entity/flesh_amalgam_ambient", "volume": 0.25, "weight": 1},
    {"name": "carnis:hive/amalgam_breath_01",      "volume": 0.35, "weight": 1},
    {"name": "carnis:hive/amalgam_breath_02",      "volume": 0.35, "weight": 1}
  ]
}
```
То есть событие **трёхвариантное**: тихая подложка (0.25) плюс два вздоха
по 0.35 с равным весом. Оба файла **слышны** — громкость не нулевая.

## 2. Проверка официальным инструментом

Прогнал `tools/sound_orphans.py` на **фактическом ZIP 3.7.2**:
```
Аудит сирот .ogg (K8-S, ТЗ 3.7.0 §3)
Пакет:     project-3.7.2-clean.zip
Событий в sounds.json: 82, ссылок на файлы: 144, файлов .ogg: 144

Сирот нет: 0

ИТОГ: СХОДИТСЯ — сирот 0, ссылок в пустоту 0
```
**Код возврата 0.** Критерий ТЗ §3 выполнен: «либо 0 файлов-сирот в JAR,
либо оба подключены и слышны» — выполнены **оба** условия сразу.

## 3. Что было в отчёте Интегратора и почему расхождение

`integrator_k8s_gap.md` утверждал: событие `hive.amalgam_breath` ссылается
только на `carnis:entity/flesh_amalgam_ambient`, а `amalgam_breath_0*.ogg`
не подключены. **В 3.7.2 это уже не так** — оба варианта добавлены в список
`sounds`. Две строки по 0.35 в событии есть, они реальные.

Вероятная причина расхождения: отчёт писался по заготовке **3.7.0**, а
проверка сейчас идёт по **3.7.2**. Подключение сделали позже — задача
Кодеру (#5) свою часть закрыла.
