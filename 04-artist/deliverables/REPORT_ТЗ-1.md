## 2. Пути

```

```

Генераторы (если нужно перегенерировать или поправить):

```
deliverables/scripts/<имя>.py     — самодостаточные, Pillow, каждая карта — явные hex
```

Запуск генератора:
```bash
python3 deliverables/scripts/flesh_block.py                 # → flesh_block.png
python3 deliverables/scripts/flesh_block.py path/to/out.png # → в указанный путь
```

Скрипты прогнаны: 14/14 без ошибок, результат пиксель-в-пиксель совпадает с PNG в дереве ассетов.

## 3. Что видно на каждой текстуре

**flesh_block** — влажная мышечная масса: крупные спокойные зоны, короткие жилки-штрихи, поры-ямки, блики влаги. Не камень, не фарш.

**flesh_veins_t1** — начало заражения: одна тонкая жилка с двумя ответвлениями, чуть светлее плоти.

**flesh_veins_t2** — жилы толще: двойной ствол с ответвлениями вверх и вниз, влажные блики в узлах, розовые точки пульса.

**flesh_veins_t3** — сеть: широкие (2 px) протоки с обрывами, ветвления, аневризмы (2×2 ярких узла), тени в развилках, влага на стыках.

**flesh_veins_t4** — полное заражение: вся поверхность — живая ткань (наплывы светлой жилы на тёмной основе), борозды-швы, пульсовые точки. Тиры отличаются **морфологией**, не тинтом.

**bone_flesh** — крупные бледно-серые костные плато с бликами, тень вокруг, хрящевые мягкие пятна, глубокие поры. Кость не белая — серая с тёплым подтоном.

**charred_flesh** — обугленные массивы, длинные Y-трещины, на дне трещин — живая светлая ткань. Не лава, не огонь: просто мёртвый участок.

**refractory_flesh** — гладкая серо-пурпурная кожа/рог: четыре больших плато с роговыми швами, редкие блики, две поры. Самый «спокойный» блок.

**stomach_pool_top** — вязкая поверхность: две плавные ступенчатые волны, кольцевые пузыри, тёмные впадины, желчные жёлтые точки.

**stomach_pool_side** — вертикальные складки с волновым дрейфом, тёмная кромка сверху (стык с поверхностью), потёки жидкости, поперечные перепонки.

**stomach_pool_bottom** — тёмное дно: светлые пятна осадка, тёмные хлопья, зелёные кислотные остатки, блеск влаги.

**nerve_pillar** — три волнистых нервных волокна (толщина 1→3 px), синапсы-утолщения, розовые акценты, у оснований тени, внизу волокна расширяются в корни.

**nerve_pillar_top** — срез: концентрические кольца (бледно-голубые / розовые), яркий центр, разрывы колец, чтобы не читалось «мишенью».

**sinew_spikes** — мясистая основа, 5 светлых рёбер с дрейфом, бледные кончики сверху, поперечные насечки, влага.

## 5. Метрики

`seam h/v` — перепад яркости через стык относительно среднего внутри тайла (1.0 = стык неотличим). `lum` — диапазон воспринимаемой яркости.

| Файл | seam h / v | lum | тонов |
|---|---|---|---|
| `flesh_block` | 0.76 / 0.89 | 31–90 | 8 |
| `flesh_veins_t1` | 0.71 / 0.83 | 31–90 | 8 |
| `flesh_veins_t2` | 0.89 / 0.83 | 31–90 | 8 |
| `flesh_veins_t3` | 1.45 / 0.78 | 31–105 | 9 |
| `flesh_veins_t4` | 0.86 / 1.96 | 31–105 | 8 |
| `bone_flesh` | 1.50 / 1.24 | 51–132 | 7 |
| `charred_flesh` | 0.69 / 0.85 | 30–97 | 6 |
| `refractory_flesh` | 1.35 / 1.58 | 51–120 | 7 |
| `stomach_pool_top` | 0.37 / 0.20 | 63–145 | 8 |
| `stomach_pool_side` | 0.77 / 0.89 | 63–145 | 7 |
| `stomach_pool_bottom` | 1.40 / 0.82 | 47–145 | 7 |
| `nerve_pillar` | 0.04 / 1.30 | 64–163 | 6 |
| `nerve_pillar_top` | 0.29 / 0.37 | 64–163 | 6 |

Значения у `t4`, `bone`, `refractory`, `bottom` выше 1.2 — это осознанно: у них есть направленные детали (наплывы, плато, кромки). Визуально стык не читается, проверено развёрткой 3×3 (см. превью).

## 6. Отклонения от ТЗ и решения

1. **Палитра ТЗ соблюдена, но расширена.** В ТЗ указаны 3–5 ключевых цветов на блок. Я добавил по 2–4 промежуточных тона (подъём/гребень/блик) — без них на 16×16 не получить «плавные переходы» из стиль-гайда. Базовые hex-коды ТЗ сохранены и лежат в основе каждой рампы.
2. **`flesh_veins_t4` — не «сплошная жила».** Первые итерации давали «горох»/«мишень». Финально это ткань из наплывов (светлая жила) на тёмной основе с бороздами. Тиры t1→t4 отличаются морфологией, как и просил Арх.
3. **`stomach_pool_side`**: верхняя кромка — 2 строки тёмного тона (стык с поверхностью жидкости). Если борт в модели не соприкасается с top-текстурой сверху, это допустимо; если соприкасается — кромка даёт естественную тень под поверхностью.
4. **`nerve_pillar`**: направленность вниз достигнута расширением волокон (корни) в нижней трети и синапсами; сверху волокна тоньше. Требование «волокна читаются в обе стороны, но взгляд тянет вниз» выполнено морфологией, без контурных стрелок.
5. **`nerve_pillar_top`** намеренно не бесшовный — торец виден целиком; края уведены в тёмную рампу, чтобы на стыке с боковой текстурой не было светлой каймы.
6. **`sinew_spikes`** — текстура для геометрии шипов, силуэт не заложен (по ТЗ). Рёбра идут вертикально, бледные кончики сверху — чтобы на модели, где шипы торчат вверх, работала подсветка.

- [ ] `sinew_spikes` на модели шипов: рёбра не «плывут» при повороте
