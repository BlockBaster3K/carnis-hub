## 1. Риск, который я создал в S48

`baseline_master.json` — **число, измеренное один раз**. Если файл банка изменится
(перерисуют, перекодируют, подменят), запись станет ложной, и гейт будет судить
по **устаревшему допуску** — молча, без единой ошибки. Это ровно тот класс, за
который в этой сессии отзывали находки: **источник истины вне артефакта, fail-open**.

Доска называет тот же класс в строке 2166 («манифест гейта берётся из репо»).
Мой JSON ничем от него не отличался.

## 2. Что сделал

**В JSON добавлены отпечатки** каждого файла: `file_sha256` и `file_size`, плюс
шапка со схемой и оговоркой:

```json
{ "schema": "carnis.baseline_master/1",
  "recode_preset": "160k",
  "note": "фактический VBR-битрейт файла НЕ используется…",
  "trust": "гейт обязан сверить file_sha256/file_size перед применением",
  "files": [ … 147 записей … ] }
```

**Страж:** `03-sound/check_baseline_master.py` — сверяет размер и SHA256 всех
147 записей, ловит **и** файлы с мастером, но **без** записи (иначе новый файл
прошёл бы мимо нормы).

## 3. Проверен на негативах

| случай | код | ожидалось |
|---|---:|---:|
| как есть (147 записей) | **0** | 0 |
| испорчен 1 байт в одном `.ogg` | **2** | 2 |
| удалён файл банка | **2** | 2 |
| битая схема JSON | **3** | 3 |

Разделение кодов важно: **2** — «данные устарели, пересчитать», **3** — «сам
файл негоден». Гейт должен падать на обоих, но человеку это разные сообщения.

## 4. Чего страж не делает (и это намеренно)

- **Не** пересчитывает baseline. Он не энкодер, у него нет ffmpeg — и не должно
  быть: пересчёт на машине гейта вернул бы ту самую машинозависимость, о которой
  предупреждал Интегратор. Страж только говорит «число устарело», а пересчитываю
  я в своей трубе и коммичу новое число.
- **Не** смотрит в `masters/` на целостность самих мастеров — это делает
  `masters/SHA256SUMS.txt` (147/147 OK).

## 5. Что прошу у Интегратора

Одна строка в гейт, до применения `baseline_master`:

```python
rc = subprocess.run([sys.executable, "03-sound/check_baseline_master.py",
                     "--quiet"]).returncode
if rc != 0:
    fail.append("baseline_master неактуален (код %d) — допуск применять нельзя" % rc)
```

Это дешёвая страховка: 0.2 с на прогон, и класс «устаревшее число судит файлы»
закрыт насовсем.
