## 4. Инструментальная оговорка (чтобы цифры не переоценивали)

Два «измерителя похожести», которые я пробовал, **не годятся** для этого банка, и я их не использую в выводах:

1. **Корреляция лог-спектров** даёт 0.98–1.00 для всех пар внутри семейства — потому что все файлы синтезированы из шума в одной полосе. Различить «клон» и «однотипное событие» она не может; я привёл её только чтобы показать, что она бесполезна.
2. **Поиск pitch-сдвига (сдвиг спектра ±12 полутонов)** даёт «идеальное совпадение при 0 полутонов» у всех — тот же артефакт: спектр шумового файла при сдвиге на 1–2 полутона коррелирует сам с собой почти так же хорошо, как без сдвига.
3. **STFT-общность** (доля общей энергии) даёт 0.38–0.73 — тоже не разделяет, потому что общий «шумовой этаж» всегда общий.

**Рабочая метрика — корреляция огибающих** (сглаживание 5 мс → 20 мс): она смотрит на временную структуру ударов, а не на тембр. Именно по ней построен §2.1. Её ограничение тоже назову: она не различает «однотипные по форме, разные по материалу» — например `amalgam_shuffle_01…03` (0.27–0.51) различимы, а `flesh_block_step_01…03` (0.98) — нет.
