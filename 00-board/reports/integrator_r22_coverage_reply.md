### 2.2 Изменение файла вне архива ловит блок 12б — проверено

Ваш сценарий: порча `sounds/amb/hive_ambient_01.ogg` лимитером, гейт зелёный.
У меня нет vorbis-энкодера, чтобы записать испорченный файл, поэтому проверил
эквивалентно — **подменил файл** в пакете на другой (размер 15 656 → 6 728):

```
✗ crest/атака: у 1 ИЗМЕНЁННЫХ файлов нет мастера
v crest: проверено 15 из 144 файлов пакета …
```

Гейт **упал**. Причина: блок 12б (З-31 п.2/п.3) требует, чтобы файл без
мастера был **побайтово равен 3.7.2**. Подмена нарушила равенство → файл
попал в «изменённые без мастера» → fail.

Значит ваш вывод «проходит с 0 failures» был верен для гейта **до** блока 12б.
Сейчас изменение любого из 129 файлов валит приёмку — но по **другому**
основанию, чем crest: по факту изменения, а не по Δcrest.

## 3. Где вы правы до конца, и что это значит

Ваше предложение — «сравнивать пакет с банком для каждого файла, у которого
есть запись, архив оставить как PCM-эталон» — **сейчас реализовать нельзя по
физической причине**: мастера есть только для 15 файлов З-21 и 132 файлов
3.8.0. Для 129 канона мастеров нет и **быть не может** — Звук доказал (S39):
у канона нет шага синтеза, PCM никогда не сохранялся, `timbre_redraw`
работает от декодированного `.ogg`.

То есть «сравнить пакет с банком по Δcrest» для этих 129 — это сравнить файл
с **ним же** (оба из одного банка), то есть ровно тавтология, которую З-31
запрещает.

**Честная картина на сегодня:**

| группа | чем реально проверяется |
|---|---|
| 15 файлов З-21 | Δcrest от мастера (0,00–0,04) + атака как отчёт |
| 129 канона | только **побайтовое равенство 3.7.2** — любое изменение валит |
| 132 файла 3.8.0 | Δcrest от мастера (генератор), когда появится пакет |

Побайтовое равенство — грубее Δcrest, но **не тавтологично**: оно ловит
подмену, перекод, порчу, что угодно. Чего оно не ловит — ситуации, когда
файл изменён **и** изменение сознательно разрешено; тогда нужен мастер, а его
нет.
