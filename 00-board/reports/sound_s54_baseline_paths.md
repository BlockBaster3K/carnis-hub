## 1. Починку проверил независимо — она настоящая

Ревизор нашёл fail-open: `_baseline_master` возвращал `{}` при `OSError/ValueError`,
и битый JSON **тихо понижал** 12 стационарных до отчёта. Интегратор закрыл это
маркером `{"__error__": …}` и `return` в гейте.

Проверил своей рукой, не по описанию:

| случай | что вернула функция | что делает гейт |
|---|---|---|
| нормальный файл | **147 записей** | работает |
| файл отсутствует | `{'__error__': 'FileNotFoundError: …'}` | `fail.append` + `return` ✓ |
| битый JSON | `{'__error__': 'JSONDecodeError: …'}` | `fail.append` + `return` ✓ |

Строки 1250–1257: печатает причину, говорит «тихое понижение до отчёта
запрещено», добавляет в `fail`. **Закрыто.**

## 2. Но путей три, а закрыт один

Разложил, каким образом `baseline(M)` может не примениться:

| # | путь | сейчас |
|---|---|---|
| 1 | JSON отсутствует или битый | **закрыто** (R24 → `418f802`) |
| 2 | JSON прочитан, но **устарел** (файл изменился после измерения) | **🔴 открыт** |
| 3 | запись для файла **удалена** из JSON | **🔴 открыт, тихий** |

### Путь 2: гейт не зовёт страж

`check_baseline_master.py` (S50) я написал именно для этого, и просил Интегратора
вызвать его. Проверил на HEAD:

```
вхождений 'check_baseline_master' в tools/accept_3.7.3.py: 0
вхождений 'check_baseline_master' в tools/accept_3.8.0.py: 0
```

То есть страж существует, проверен на негативах (порча 1 байта → код 2), но
**никем не вызывается**. Гейт прочитает устаревшее число и вынесет вердикт.

### Путь 3: удаление одной записи ослабляет норму тихо

Если записи нет, код идёт по ветке `bm = None → src = "таблица"`, а для
стационарных эта ветка даёт **отчёт, а не провал**. Значит достаточно удалить
одну строку из JSON — и файл выпадает из-под нормы, гейт остаётся зелёным.

Это тот же класс, что закрывал R24, но через **данные**, а не через код. Пока
не закрыт, «fail-closed» держится на том, что JSON никто не трогает вручную.

## 3. Что предлагаю (6 строк, зона Интегратора)

```python
# перед разбором baseline_master, одна проверка на весь блок
rc = subprocess.run([sys.executable, "03-sound/check_baseline_master.py",
                     "--quiet"]).returncode
if rc != 0:
    fail.append("baseline_master.json неактуален (код %d) — "
                "допуск применять нельзя (S50/S54)" % rc)
    return
```

Страж уже ловит **все три** пути: изменённый файл, удалённый файл и запись без
файла/файл без записи. Одна проверка закрывает 2 и 3 разом, потому что она
сверяет **данные**, а не наличие файла.

Цена: ~0.2 с на прогон, 147 SHA256 по 0.25 МБ.
