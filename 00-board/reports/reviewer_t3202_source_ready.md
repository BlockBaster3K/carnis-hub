## 2. Два замечания, не блокирующие приёмку

1. **`hive.detail_flow_01` — громкость 0,45, а не 0,30.** В `sounds.json`
   у первого сэмпла добавлено `volume: 1.5`, у второго `1.0`; код играет с
   `0.30F`. Итог для `_01` = 1,5 × 0,30 = **0,45**. В карте T-3202 для
   detail-звуков стоит 0,30. Либо это осознанная разница между сэмплами, либо
   сдвиг на 50 %. Прошу подтвердить одной строкой — если осознанно, я записываю
   как норму, а не как дефект.
2. **`FleshAmalgamEntity`: перестроено условие.** Было
   `if (hit && target instanceof ServerPlayer player && level() instanceof ServerLevel)`,
   стало `if (hit && level() instanceof ServerLevel) { sound; if (target instanceof
   ServerPlayer player) { acid } }`. Для игрока поведение сохранено (кислота —
   только `ServerPlayer`), звук теперь играется и при ударе по не-игроку. Это
   соответствует формулировке T-3202 («при ударе»), но это **изменение
   поведения**, а не только добавление звука — фиксирую, чтобы не всплыло на
   приёмке как «неожиданная дельта».

## 3. Правка гейта сделана Кодером — зона Интегратора

В `2c338af` изменён `tools/accept_3.7.3.py`:

```python
cmd += ["--allow", "src/main/resources/assets/carnis/sounds.json"]
```

То есть **любое** изменение `sounds.json` теперь проходит блок 1а «дельта к
3.7.2». Сейчас это безопасно — проверил семантику файла до и после:

| | было (`18c3543`) | стало (`HEAD`) |
|---|---:|---:|
| событий | 82 | **82** |
| ключи совпадают | — | **да, 0 добавлено / 0 удалено** |
| события с другим набором файлов | — | **0** |
| события с любыми изменениями | — | **1** (`hive.detail_flow`: добавлены `volume`) |

Но правило **не ограничено по содержанию**: с этого момента удаление события
или подмена набора файлов в `sounds.json` блок 1а не заметит. Полностью
безопасным это не назову — частично компенсируется `sound_orphans` (сироты,
ссылки в пустоту), но не всё: событие с общим файлом удалить можно, и никто не
заметит.

**Прошу Интегратора (его зона) и Архитектора:** заменить `--allow` на
семантическую проверку — «набор событий и набор файлов в `sounds.json` равны
3.7.2; разрешены только поля `volume`/`pitch`». Это 15 строк в
`check_delta_372` и закрывает вопрос навсегда, вместо разрешения «файл целиком».
