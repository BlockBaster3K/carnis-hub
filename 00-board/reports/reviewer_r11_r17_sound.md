### 2.1. З-Г6 · `FLESH_AMALGAM_AMBIENT` считается недостижимым, хотя его звук слышен

Проверил по байтам пакета 3.7.3:

```
sounds.json, событие flesh_amalgam_ambient → [carnis:entity/flesh_amalgam_ambient]
sounds.json, событие hive.amalgam_breath  → [carnis:entity/flesh_amalgam_ambient,
                                              carnis:hive/amalgam_breath_01,
                                              carnis:hive/amalgam_breath_02]
FleshAmalgamEntity.java:614 → return ModSounds.HIVE_AMALGAM_BREATH.get();
```

То есть **файл играется** живым событием `hive.amalgam_breath` (вызов есть), а константа `FLESH_AMALGAM_AMBIENT` не используется. Чекер смотрит только на имя константы и потому ставит событие в «недостижимые».

Проверил остальные 10 — **ни одно не покрыто живым событием**:

| Событие | Файлов | Покрыт живым событием |
|---|---:|---|
| `FLAMETHROWER_FIRE` | 1 | — (задел, allowlist) |
| `AMALGAM_SMASH` / `HIVE_SPREAD` | 2 / 3 | — |
| `SYNAPSE_SHOCK`, `CREEPER_RUPTURE` | 1 / 1 | — |
| `HIVE_DETAIL_FLOW/MEMBRANE/BUBBLES/CREAK/SCUTTLE` | 2/1/1/1/1 | — |
| **`FLESH_AMALGAM_AMBIENT`** | 1 | **`hive.amalgam_breath`** |

**Предложение (Интегратору, `tools/`):** третий исход вместо двух — «файл слышен, константа мертва». Такое событие печатать отдельной строкой (`~ FLESH_AMALGAM_AMBIENT — играется через hive.amalgam_breath, константа не вызывается`) и **не считать** в валящем числе, как и требует R17. Критерий — покрытие **всех** файлов события живыми событиями; если хотя бы один файл не покрыт, это недостижимо по ошибке и валит кодом 3 (негатив `HIVE_DETAIL_PROBE` это уже подтверждает).

**Почему не «удалить константу»:** по T-3190 удаление — только по согласованному списку Звука, а Звук помечает это событие как «уже жив». Правильный финал — после привязки T-3190 либо вызов по имени, либо слияние ключа в `hive.amalgam_breath`; решение за Архитектором, я фиксирую расхождение.
