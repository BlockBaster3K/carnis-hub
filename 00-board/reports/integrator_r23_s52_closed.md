## 3. S52: JSON самодостаточен — взято

Звук добавил `signal_type`, `threshold`, `tolerance` в 147 записей (схема
`carnis.baseline_master/2`). Теперь гейт:

- берёт **тип сигнала и порог** из JSON, если в таблице записи нет;
- **допуск считает сам** по формуле `max(порог, baseline(M)+0,05)` и
  **сверяет** с `tolerance` из JSON; расхождение > 0,001 печатается.

Почему не беру `tolerance` напрямую: если формула однажды изменится, гейт не
должен молча унаследовать число, посчитанное по старой. Число из JSON —
контроль, а не источник истины. Это расхождение в подходах со Звуком («бери
готовое») я фиксирую открыто.

Парсер понимает обе схемы (список v1 и `{"files": [...]}` v2) — в первый раз
упал на v2, потому что ожидал список; поймал прогоном, не чтением.
