## 1. Зачем версия

3.7.0 закрывает три жалобы заказчика на уровне кода: цвет щупалец (A3R1),
палитра существ (A4-p7), гул и громкость ambient (ambient-фикс, K8-S).
Замер тембра показал, что **громкость — не главный носитель «раздражения»**:
энергия лежит ниже 80 Гц.

3.7.1 — версия **полировки**: убрать низкочастотную «подложку» из самого звука,
почистить банк от мёртвых файлов и закрыть три инструмента, чтобы
следующие партии не спорили о палитре и не ломали звук по мелочи.

## 2. Тембр ambient — T-3104

**Диагноз (замер Звука, `sound_ambient_metrics.md`):** доля энергии < 80 Гц
> 25 % у **8 из 13** файлов, максимум **84,8 %**. Спектральные центры
127–277 Гц — это почти чистый инфразвук. Crest 13,8–15,7 при пике −5…−8 дБFS:
файл читается как ровная низкочастотная подложка с редкими всплесками.

**Что перерисовать и до какого числа:**

|---|---:|---:|---|
| `amb/hive_ambient_01` | 84,3 % | 127 Гц | ≤ 25 %, ≥ 400 Гц |
| `amb/hive_ambient_02` | 82,9 % | 136 Гц | ≤ 25 %, ≥ 400 Гц |
| `amb/hive_ambient_03` | 84,8 % | 130 Гц | ≤ 25 %, ≥ 400 Гц |
| `amb/hive_ambient_close_01` | 78,3 % | 188 Гц | ≤ 25 %, ≥ 400 Гц |
| `amb/hive_ambient_close_02` | 80,0 % | 204 Гц | ≤ 25 %, ≥ 400 Гц |

## 4. Художник — T-3105, T-3109

### T-3105. З-1: `infected_creeper`

1 724 из 2 048 пикселей (84,2 %) — один цвет (104,47,64). Внутренняя светотень
исчезла, моб читается плоской фишкой. У остальных тел доля самой частой краски
22,9–32,2 %.

**Цель:** доля самой частой непрозрачной краски **≤ 35 %**, светотень вернулась.
**Не менять:** маску, 64×64, RGBA, набор 7 цветов `BASELINE_PALETTE`, силуэт,
свечение glowmask `(255,92,57)`. Сдача — **новой партией `-R`**.

### T-3109. Палитра-шпаргалка и чекер плотности светотени

**Проблема, которую это закрывает:** критерий «читается как плоть» был
**без числового порога** — З-1 всплыл только на вердикте. Следующая партия
должна ловиться чекером, а не глазом.

1. `04-artist/PALETTE.md` — **один источник правды по палитре проекта**: для
   каждой перекрашенной текстуры — файл, точные значения 7 цветов, средний RGB,
   доля самой частой краски. Заполняется по факту из принятых сдач.
2. `04-artist/tools/shade_density.py` — измеряет долю самой частой непрозрачной
   краски и число непрозрачных цветов по PNG или ZIP. Коды 0/2/1.
3. **Проверить в обе стороны:** текущий `infected_creeper.png` → код 2
   (84,2 %); синтетика с 30 % → код 0.

**Зачем:** с этим чекером следующий заказчик палитры проверяется **до** сдачи,
а не после.

- **Д1–Д7, K4, K5, K6-S, A1, A5, A7, Д6, Д7, A3/A6, K8-S** — закрыто,
