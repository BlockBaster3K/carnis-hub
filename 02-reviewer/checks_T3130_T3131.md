Замер (декодер и метрики — из моего же чекера `tools/timbre_check.py`, чтобы числа были сопоставимы с приёмкой тембра):

```bash
python3 - <<'EOF'
import sys, numpy as np
sys.path.insert(0, 'tools')
import timbre_check as T

PAIRS = [('/tmp/cmp/block_hive_block_break_03_crunch.old.ogg', '03-sound/sounds/block/hive_block_break_03_crunch.ogg'),
         ('/tmp/cmp/hive_hive_spawn_attack_04.old.ogg',          '03-sound/sounds/hive/hive_spawn_attack_04.ogg')]

for old_path, new_path in PAIRS:
    o = T.decode(open(old_path, 'rb').read()).astype(np.float64)
    n = T.decode(open(new_path, 'rb').read()).astype(np.float64)
    po, fo, co = T.metrics(o.astype(np.float32))
    pn, fn, cn = T.metrics(n.astype(np.float32))
    m = min(len(o), len(n))
    print(old_path.split('/')[-1],
          'peak %.2f -> %.2f' % (po, pn),
          'samples %d / %d' % (len(o), len(n)),
          'low80 %.1f -> %.1f %%' % (fo, fn),
          'centroid %.1f -> %.1f' % (co, cn),
          'corr %.4f' % np.corrcoef(o[:m], n[:m])[0, 1])
EOF
```

Полный набор из семи файлов — тот же цикл; существенное:

- декодер — `T.decode()` (PyAV → PCM 44,1 кГц, моно), метрики — `T.metrics()` (Welch, `nperseg=8192`);
- длина в сэмплах = `len(decode())`, сравнивается **точным равенством**, не «±1 мс»;
- **корреляция формы** = `np.corrcoef(old[:n], new[:n])` на общей длине `n = min(len)`: показывает, что правка была чистым усилением, а не пересинтезом;
- клиппинг = число сэмплов `|x| ≥ 0,999`;
- «12/12 не тронуты» — `sha256sum` текущих файлов против `git show f21620a^:<файл> | sha256sum`.

Порог центра: ТЗ говорит 1 %, фактические 1,14 % и 1,75 % — замечание З-11.
