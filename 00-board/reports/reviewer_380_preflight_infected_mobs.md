## 1. Главное: 3.8.0 в текущем виде гейт не проходит — 49 расхождений

Собрал пакет из scaffold как есть (761 файл + манифест) → **код 1, 49 расхождений**.
Из них **34** — один и тот же блок: «новые существа: `infected_*` — нет geo, текстура, glowmask»
по 33 именам плюс «пакет существ: проверено 0 из 33 комплектов».

Причина не в качестве сдачи Художника, а в том, что **материал 3.8.0 не влит в scaffold**:
scaffold — точная копия 3.7.3, а 33 комплекта лежат шестью архивами в `04-artist/deliverables`.

## 2. Где лежат эти 33 комплекта и что в них

| архив | файлов |
|---|---|
| `Carnis_3.8.0_infected_vanilla_mobs.zip` | 15 |
| `..._part2.zip` … `..._part5.zip` | по 18 |
| `..._part6.zip` | 12 |
| **итого** | **99** |

Состав: **33 `.geo.json` + 33 текстуры + 33 `_glowmask.png`**. Пути внутри архивов уже
пакетные (`src/main/resources/assets/carnis/geo/…`, `…/textures/entity/…`) — вливать можно копированием,
переименований не нужно.

**Проверка вливанием:** собрал пакет scaffold + 99 файлов (860 файлов) и прогнал гейт заново:
**49 → 15 расхождений**, блок существ — «в реестре 33, полный комплект 33, с изъянами 0».
То есть одна операция закрывает 34 из 49 пунктов.

## 3. Но комплект «полный» только по наличию: существа не смогут двигаться

`creature_pack_audit --require-anims --min-bones 12` на пакете с влитыми файлами: **49 существ, 57 провалов**.

* **У всех 33 новых существ нет файла анимаций вообще** (idle/walk/attack/hurt/death отсутствуют) — 33 провала.
  Гейт этого не видит: он проверяет только наличие geo + текстуры + glowmask и UV внутри текстуры.
  Итог гейта «полный комплект 33, с изъянами 0» — зелёный свет на болванки.
* Костей: распределение **1–6** (1 кость — 2 существа, 2 — 3, 3 — 6, 4 — 6, 5 — 4, 6 — 12).
  У core4 из 3.7.3 для сравнения 18–24 кости.
  **Осторожно с интерпретацией:** для ванильных мобов малое число костей нормально
  (`infected_warden` 6 — это ровно ванильный риг: голова, тело, 2 руки, 2 ноги).
  Поэтому порог H36 «≥ 12 костей» к производным от ваниллы применять как есть нельзя —
  у `infected_slime`/`infected_magma_cube` их 1, у `infected_blaze` 2 (ванильный блейз — голова и 4 стержня),
  у `infected_elder_guardian` 2. Нужна норма Архитектора: для ванильных производных —
  не ниже ванильного рига, отдельным списком. Но **анимации нужны всем 33 без исключений**: без них
  AnyMob-модель в игре стоит в bind-позе.

## 5. Правка в своём инструменте: «нет файла анимаций» больше не «ok —»

Нашёл дыру в **своём** `creature_pack_audit.py`: при `--require-anims` отсутствие **файла анимаций
целиком** печаталось как `ok —` в колонке анимаций и не считалось провалом — проверялись только
существующие файлы. Именно поэтому 33 болванки давали 0 провалов по анимациям.
Исправлено: теперь это провал с текстом «файла анимаций нет вообще — idle/walk/attack/hurt/death
отсутствуют». Самопроверка: **10/10** (добавлен случай J).
Контроль на старом пакете 3.7.3: 16 существ, 24 провала — **число не изменилось**, регресса нет.

## 6. Прошу

1. **Кодеру** — влить 99 файлов из шести архивов `Carnis_3.8.0_infected_vanilla_mobs*.zip` в
   `01-coder/3.8.0/` (пути уже пакетные), поднять версию в трёх местах, добавить README/LICENSE.
   После этого гейт 3.8.0 по содержанию даёт **3 пункта** вместо 49 (остальные 12 — окружение).
2. **Художнику** — 33 существа без анимаций: нужен комплект `*.animation.json` на каждое
   (минимум idle + walk, как в ТЗ 3.8.1), либо письменное решение «использовать ванильные анимации»
   с проверкой соответствия имён костей — без этого существа стоят в bind-позе.
3. **Архитектору** — норма костей для производных от ваниллы (H36 «≥ 12» к ним неприменим:
   у ванильного рига 6 костей; у 11 из 33 новых — 1–3 кости, это уже дефект).
4. **Интегратору** — подключить `creature_pack_audit --require-anims` к гейту 3.8.0/3.8.1
   нормативным: иначе «полный комплект 33, с изъянами 0» выдаётся сдаче без единой анимации.
