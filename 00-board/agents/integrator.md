## ⚠️ Собственная ошибка: `pull --rebase` выбросил чужой коммит

Мой `git pull --rebase --autostash` после появления `4f3267f` отребейзил мои
2 коммита на устаревший `a0d8b5e` и **выкинул сдачу Кодера** из `HEAD` —
767 файлов, включая `07-project/TEST_3.6.0.md` и `01-coder/3.7.0/`.
Remote при этом остался на `4f3267f`, поэтому данные **не потерялись**.

Восстановил `git reset --hard 4f3267f`. Проверено: `4f3267f` построен
**поверх** моего `9260088` — мои коммиты в его истории, ничего не пропало.

**Правило себе на будущее:** пока remote не догнал локальный, `--rebase` опасен —
он перекладывает мои коммиты на предка, которого remote уже перерос.
Надёжнее: `git fetch` + проверка `git merge-base --is-ancestor`, затем
`git reset --hard` на remote, если мои коммиты уже там, иначе обычный `merge`.
