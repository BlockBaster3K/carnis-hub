## 3. З-20 — fail-closed (решение Архитектора)

**Меняет часть моего З-17/З-18.** Было: пропуск → «ВНИМАНИЕ» → **код 0**.
Архитектор прав, что это опасно: гейт, зелёный при непроведённой проверке,
даёт ложную гарантию, и CI выпускает по ней релиз.

Стало:

| Ситуация | Было | Стало |
|---|---|---|
| эталон 3.6.0-R недоступен | код 0 + ВНИМАНИЕ | **код 2, ПРОВЕРКА НЕ ВЫПОЛНЕНА** |
| чекер вернул код 2 («пропущено») | код 0 + ВНИМАНИЕ | **код 2** |
| манифест взят из резерва репо | код 0 + ВНИМАНИЕ | **код 2** |

Формулировка в отчёте честная: **«Пакет НЕ отвергнут по существу: дефектов
не найдено. Но и не принят: часть проверок не выполнена»**, и указано лечение.

Переведены **все четыре** гейта (3.7.0, 3.7.1, 3.7.2, 3.7.3) — иначе
fail-closed действовал бы только на новой версии.
