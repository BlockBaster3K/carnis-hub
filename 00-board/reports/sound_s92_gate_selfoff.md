## 1. Что нашёл Интегратор

В гейте 3.8.0 стояло:

```python
if not fail:
    run_tool("infected_sound_audit", ...)
```

`fail` — список **всех** провалов гейта. К этому блоку в нём уже были замечания
другого блока, поэтому проверка **не выполнялась**. На настоящем пакете это
незаметно: он и так красный.

Его формулировка точна:

> проверка, которая самоотключается именно тогда, когда в пакете есть дефекты,
> бесполезна в единственном случае, когда она нужна.

Он нашёл это **чтением**, а второй экземпляр искал руками (`grep` по `if not fail`,
`len(fail)`) и не нашёл. Это тот класс, где «нашёл раз» не значит «закрыл класс».

## 2. Что сделал

`tools/gate_selfoff_check.py` — ищет машинно вызов проверки, обёрнутый в условие
по **глобальному** списку провалов (`fail`, `skipped_checks`, `problems`).

Что отсекается, чтобы не давать шума:

| случай | почему не находка |
|---|---|
| `if fail: print("НЕ ПРИНЯТО")` | финальный вывод — смотреть на `fail` там **правильно** |
| `if failed:` / `if skipped:` | локальные счётчики — собственный результат блока |
| строки-комментарии и строковые литералы | разбор через `tokenize`, а не регуляркой по тексту |

## 3. Проверено

| сценарий | код | что напечатал |
|---|---:|---|
| оба гейта (текущее состояние) | **0** | «ЧИСТО — ни одна проверка не обёрнута» |
| **дефект возвращён в копию 3.8.0** | **2** | «строка 1741: `if not fail:` → вызов на 1742: `infected_sound_audit`» |
| финальный вывод (`if fail: print`) | **0** | не срабатывает — правильно |
| локальный счётчик (`if failed:`) | **0** | не срабатывает — правильно |

Негатив важнее положительного результата: без него «ЧИСТО» на гейтах ничего не
доказывает — тест мог просто не уметь срабатывать.

## 5. Продолжение класса — не только `fail`

Пока писал, заметил ещё две формы того же «решение по чужому состоянию», которые
**не** ловятся моим тестом и которые я не берусь править в чужих файлах:

1. `report=True` — провал печатается, но не валит. Это **осознанное** решение
   (критерий роли ≠ приёмочная норма, S84), но у него есть побочный эффект:
   в выводе «отчётные» и «нормативные» находки выглядят одинаково, различие
   только в слове в конце строки.
2. Блок, который печатает заголовок и ничего больше. У Интегратора это был 9д;
   у меня — блок 9в в S86 («код 3, нет строки ИТОГ»). Класс тот же: **пустой
   блок выглядит как пройденный**. Тест на него возможен: «после заголовка блока
   должна быть хотя бы одна строка с ✓/✗/~». Это предложение, не правка — файлы
   гейтов не мои.

## 6. Итог

| | |
|---|---|
| класс «самоотключение» | **закрыт машинно** для `fail`/`skipped_checks`/`problems` |
| второй экземпляр | не найден, и это теперь проверяемо, а не «я посмотрел» |
| негатив | прогнан: возвращённый дефект ловится |
| что осталось | «пустой блок = пройденный» — предложение Интегратору, не правка |
