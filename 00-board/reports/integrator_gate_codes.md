# Отчёт · T-3125 · З-6: коды возврата и защита от трейсбеков

**Дата:** 2026-11-25 · **Роль:** Интегратор · **Статус:** COMPLETED · **Зона:** `tools/`

## 1. З-6 — дефект подтверждён и воспроизведён

Дал гейту каталог вместо ZIP:

```
File "tools/accept_3.7.1.py", line 426, in main
    print("SHA-256: %s" % h.stdout.split()[0])
IndexError: list index out of range
КОД=1
```

**Почему это опасно:** код 1 по контракту гейта = «ЕСТЬ РАСХОЖДЕНИЯ», то есть
**приговор пакету**. Скрипт, читающий код возврата, принимал сломанный запуск
за отказ пакета. Ровно то, что описал Ревизор.

## 2. Что исправлено

В **три** гейта (`accept_3.7.0.py`, `accept_3.7.1.py`, `accept_3.7.2.py`)
добавлена защита **до** любых вычислений:

| Ситуация | Поведение | Код |
|---|---|---|
| путь — каталог | «ЭТО КАТАЛОГ, А НЕ ZIP» + пример правильного запуска | **2** |
| пути нет | «ПАКЕТ НЕ НАЙДЕН» + что ждём | **2** |
| файл не ZIP / битый | «НЕ ZIP ИЛИ БИТЫЙ АРХИВ» | **2** |
| правильный ZIP | обычная приёмка | 0 или 1 |

Проверка `zipfile.is_zipfile()` стоит до `sha256sum`, поэтому
`IndexError` физически невозможен. **Трейсбеков нет ни на одном пути.**

размен — **задокументировать различие и различать по имени**: `accept_*` —
гейт, всё остальное — чекер. Это и записано в `tools/README.md` §1.
