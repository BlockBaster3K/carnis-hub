# ЧАСТЬ I. ИССЛЕДОВАНИЕ

## 1. «Как реагирует на повреждение тело без нервной системы?»

Ключевое различение из биологии: **ноцицепция ≠ боль**. Ноцицепция — детекция повреждающего стимула и рефлекс (убрать ногу от горячего, не дожидаясь, пока сигнал дойдёт до мозга). Боль — субъективное переживание, требующее интегрирующей сети.

| Факт | Источник | Следствие для звука |
|---|---|---|
| У насекомых **есть** ноцицепторы, ноцицептивные пути и ноцифенсивное поведение (выпрямление, побег, «замирание») | обзор Gibbons et al. 2022 (8 критериев боли), работы по *Drosophila* | реакция на повреждение **есть** — и она **мгновенная и стереотипная**, а не «выразительная» |
| Реакция — **рефлекс, а не сообщение**: она не адресована никому | там же | HURT **не должен быть коммуникацией** (в отличие от ALERT, который есть сигнал) |
| «Descending modulation» (способность приглушать ноцицепцию) возможна у отдельных таксонов; у многих — низкая вероятность субъективного переживания | Gibbons 2022 / Adamo 2019 | нельзя опираться на «эмоцию боли»; опираемся на **механику** |
| Даже при сильном повреждении насекомое может **продолжать начатое действие** (есть, спариваться) | наблюдения Adamo | HURT — **не «конец» и не «паника»**: система работает, событие зафиксировано |

**Вывод №1.** У тела без «боли» реакция на урон — это **механический сбой с немедленной компенсацией**. Не «ай», не «рык», не «крик». Три звуковых факта:

1. **мгновенный** (рефлекс быстрее сознания — атака 0–2 мс, иначе звук «опаздывает» за ударом);
2. **короткий** (рефлекс не длится — 0.25–0.45 с);
3. **с завершением** (сбой найден, зафиксирован, система вернулась в работу).

## 2. Есть ли у насекомых аналог болевого ответа? — Да, и он звучит как «поломка»

| Механизм | Что происходит | Что слышно |
|---|---|---|
| **Разрыв кутикулы** | интегумент рвётся в слабых точках; сила разрыва отличается у видов **на порядок** | короткий сухой **треск** + микроклик |
| **Гидростатическое давление** | мышцы сжимают тело → давление растёт → мембрана/слабый участок **выдавливает гемолимфу** (reflex bleeding) | короткий **срыв** через сужение + «сочение» |
| **Дыхальца** | клапан открывается/закрывается мышцей; при сбое — **срывается поток** | **вскрик через дыхальца**: воздух через сужение, резонанс ползёт вверх |
| **Возврат к работе** | давление восстанавливается, клапан закрывается | тихий **подъём давления** — «оно ещё держится» |

**Вывод №2.** «Боль» не-млекопитающего = **сбой + компенсация**. Именно компенсация (последняя треть файла) отличает HURT от DEATH: DEATH — это «системы отключаются по одной», HURT — «одна подсистема сбоит, остальные работают».

## 3. Как отличить «мне больно» от «меня сломали»? — по трём осям

| Ось | HURT | DEATH | Как сделано в файлах |
|---|---|---|---|
| **Длительность** | 0.27–0.42 с | 1.97–3.02 с | в 7–10 раз короче |
| **Траектория низа** | постоянная f0, затем **ползёт ВВЕРХ** на компенсации | **свип ВНИЗ** (давление уходит) | `sub_hit` (f0 const) + `pressure_return` (+13…+16 Гц) |
| **Финал** | энергия падает в ноль за 40–60 мс при сохранённой середине | распад → мокрое вытекание → длинный хвост IR | последний сегмент −29…−36 дБ, но **без «мокрой» фазы** |
| **Что слышит игрок** | «я попал, он это заметил» | «он кончился» | |

## 4. Как отличить HURT от COMBAT_FLESH_HIT (волна 2) — и главное отличие от ALERT

**COMBAT_FLESH_HIT** — это звук **удара по мясу** (результат действия игрока). **HURT** — это **реакция тела** (следствие). В миксе они играют почти одновременно, поэтому различие должно быть в разных полосах и разной длине хвоста, а не «в громкости».

| Параметр | `combat_flesh_hit` (волна 2) | `hive_spawn_hurt` (волна 5) |
|---|---|---|
| Длительность | 517–777 мс | **267–417 мс** |
| Центр тяжести (баланс) | низ −3.0…−3.6 дБ (у `_03` верх — −10.7) | **низ −5.3…−6.4 дБ**, верх −14.5…−15.6 |
| Полоса события | 160–640 Гц (мясистость) | **160–1280 Гц (ткань, трещина, клапан)** |
| Хвост | IR 0.5 с, «мокрый» | IR 0.13–0.18 с — **почти сухо** |
| Что сообщает | «удар попал» | «тело на это отреагировало» |

Приоритет микса: `combat_flesh_hit` играет **всегда** (это фидбэк игрока), `hive_spawn_hurt` — накладывается сверху, в другой полосе и с более коротким хвостом. Игрок слышит «шлёпок + срыв» = «я попал, и оно дёрнулось».

**Отличие от ALERT (жёсткое требование волны):** в HURT **нет устойчивой roughness 30–150 Гц на ВЧ-несущей**.

Мы ввели метрику **roughness sustain** — доля времени файла, где AM-энергия в 40–130 Гц лежит в пределах 6 дБ от пика (то есть модуляция *держится*, а не мелькает один раз):

| Файл | sustain (−6 дБ) | sustain (−12 дБ) | Чтение |
|---|---|---|---|
| ALERT `_01` / `_03` | **0.45 / 0.47** | 0.82 / 0.71 | модуляция держится половину файла → «тревога» |
| ATTACK `_01` / `_03` | 0.35 / 0.07 | 0.53 / 0.47 | держится меньше, но всё ещё есть |
| HURT `_01` / `_03` | **0.21 / 0.27** | 0.71 / 0.73 | **один короткий срыв**, затем тело: не читается как тревога |
| HURT `_02` / `_04` | 0.50 / 0.33 | 0.83 / 0.89 | см. ниже |
| DEATH / IDLE | 0.10 / 0.11 | 0.36 / 0.35 | нет модуляции |
| `combat_flesh_hit` | 0.04 / 0.11 | 0.22 / 0.21 | нет модуляции |

**Важный честный вывод:** у `_02` и `_04` модуляция держится долго — потому что там **трещины идут серией** (4 и 2 щелчка), и каждый щелчок даёт широкополосную AM. Это физически «треск стены клеток», а не «шероховатый голос»: у ALERT модуляция сидит на **тональной несущей**, здесь — на **шумовом транзиенте**. Чтобы это различие было измеримым, а не декларативным, в документе зафиксированы два порога (ниже): sustain ≤0.55 **и** salience ≤+10 дБ. ALERT проходит первый порог (0.45–0.47), но уходит по второму (+15…+17).

## 5. Что делает звук «болью», а не «тревогой» (по литературе о боли у людей)

| Находка | Источник | Что взято |
|---|---|---|
| В криках боли (младенцы, роды) растёт **roughness/нелинейность**, но у людей это читается как «боль» потому, что есть **голосовой источник** | Corvin et al. 2025; Koutseff 2018; роды — нелинейные явления | мы **забираем нелинейность**, но **убираем голосовой источник** → остаётся «механический сбой» |
| Боль кодируется **степенью нестабильности источника**, а не высотой | Anikin / Corvin | у нас нестабильность = **трещина + срыв клапана**, а не f0 |
| Опытные слушатели **теряют чувствительность** к «универсальным» признакам боли при привыкании | Current Biology 2022 («adults learn to identify pain») | нельзя строить HURT на одном признаке: 4 файла различаются **механизмом**, а не питчем |

**Вывод №3.** HURT должен различаться **типом сбоя** — как разные травмы, а не как разные громкости. Отсюда 4 файла = 4 механизма:
1. `_01` — **сорвало клапан** (давление вышло через сужение);
2. `_02` — **микротрещина** (стена клеток рвётся, воздуха почти нет);
3. `_03` — **мембрана прорвалась** (сначала натяжение 40 мс, потом прорыв);
4. `_04` — **внутренний сдвиг** (части тела сместились, жидкость перелилась, клапан заедает).

## 6. Ответы на ваши четыре решения

| Кандидат | Вердикт | Почему |
|---|---|---|
| 1. «Хрупкое сопротивление» (мембрана сопротивляется, потом прорывается) | ✅ **файл `_03`** | единственный вариант, где слышен **процесс** (натяжение → срыв за 40 мс). Но как единственный ответ — плохо: он длиннее и «медленнее» остальных, для частых ударов не годится |
| 2. «Вскрик через дыхальца» | ✅ **файл `_01`, частично `_02`** | это самый «болевой» элемент, но если он один → получается «писк существа» = коммуникация, а HURT коммуникацией быть не должен. Поэтому срыв клапана **всегда короткий (50–95 мс)** и **всегда с трещиной** |
| 3. «Внутренний сдвиг» | ✅ **файл `_04`** | даёт «тяжесть» без агрессии: толчок + жидкость. Без него банк звучит «сухо и мелко» |
| 4. **Комбинация** | ✅ **ответ** | но не «всё во всех файлах»: **обязательная триада** в каждом файле — (а) толчок низа (удар), (б) разрыв/трещина (урон), (в) компенсация (давление вернулось). Четвёртый элемент (срыв клапана / жидкость / натяжение) — **переменный**, он и делает файлы разными |

**Итоговая формула HURT:**
**толчок (постоянная f0, не свип) → разрыв мембраны (резонанс вниз) → микротрещины (сухие щелчки с растущими интервалами) → [переменный элемент: срыв клапана / жидкость / натяжение] → короткое сочение → давление возвращается (f0 ползёт ВВЕРХ) → разрыв в ноль 40–60 мс.**

# ЧАСТЬ II. СПЕЦИФИКАЦИЯ

## 7. `HIVE_SPAWN_HURT`

**\[HIVE_SPAWN_HURT\]**

— **Название:** Сбой тела (повреждение, не крик)
— **Контекст:** моб получил урон (`LivingEntity#hurt`). Играет **в позиции моба**, в момент попадания, **сразу после** `combat_flesh_hit` (не вместо него): сначала «удар попал», затем «тело отреагировало». При уроне от огня/взрыва — тот же звук, но pitch ниже (см. §11).
— **Тип:** SFX (реакция на урон)
— **Длительность:** 0.27 / 0.34 / 0.40 / 0.42 с (4 файла)
— **Громкость в игре:** **0.85** · RMS **−13.0…−14.5** · пик **−2.6…−1.6 dBFS**
— **Питч-вариация:** **0.90–1.10** (по требованию; в файле уже 4 разных механизма, поэтому питч не должен уходить дальше)
— **Эмоция:** «система получила повреждение и **продолжает работать**». Не страх (ALERT), не ярость (ATTACK), не конец (DEATH).
— **Слои:**
  1. **Impact body (40–160 Гц):** толчок с f0 **постоянной** (55–78 Гц), tanh 2.0–2.6, спад 0.38–0.50 длительности. **Не свип вниз** — это признак атаки и смерти.
  2. **Rupture (200–1200 Гц):** ядро урона — экспоненциальный шум с резонансом, который **съезжает вниз** (760→450 Гц и т.д.), спад 30 % длительности. Плюс микроклик 1.8–5.2 кГц (2 мс) — «стена клеток лопнула».
  3. **Cracks (850–2800 Гц):** 1–4 сухих щелчка **с растущими интервалами** (стена рвётся, потом держит). Каждый следующий тише на 18 %.
  4. **Переменный элемент** (один на файл): `_01` срыв клапана 700→1180 Гц; `_02` почти без воздуха, максимально «сухой»; `_03` натяжение 380→1000 Гц (40 мс) + прорыв 880 Гц; `_04` сдвиг жидкости (`wet_slosh` 200–700 Гц) + заедающий клапан (два щелчка с интервалом 32 мс, второй тише).
  5. **Seep (140–175 Гц база):** 1–3 коротких пузыря с ростом тона, 26–46 % уровня микса. «Сочение» — не «вытекание» (в DEATH их 8–10 и они длиннее).
  6. **Compensation (52–80 Гц):** f0 **ползёт ВВЕРХ** на 11–16 Гц за 70–130 мс — единственный файл в проекте, где низ идёт вверх. Это и есть «ещё можно починить».
  7. **Air / Reverb:** IR **0.13–0.18 с**, LP 4.6–5.4 кГц, send 15–20 %. Короче, чем у HIT и DEATH: тело реагирует в «своём» пространстве, а не отдаёт помещению.
  8. **Огибающая:** атака 0.8–4 мс, энергия падает ступенями (толчок → срыв → трещины → сочение → компенсация), финал — спад 40–60 мс + **20 мс истинного нуля**.
  9. **Чего нет:** нет roughness на ВЧ-несущей (sustain ≤0.55, salience ≤+10 дБ), нет свипа вниз, нет хвоста длиннее 0.2 с, нет «крика».
— **Референсы:** *Dead Space* — реакции Slasher'а на попадание (короткие, механические); *Half-Life 2* — хедкраб получает урон (сбой, а не голос); *SOMA* — повреждённая техника «дёргается»; энтомология: reflex bleeding, разрыв интегумента, срыв клапана дыхальца.
— **Foley-запись:**

| Слой | Что взять | Как записывать |
|---|---|---|
| Толчок | кулак/ладонь по набитому мешку; нога в мокрую землю; сжатие боксёрской груши | Микрофон 20–30 см + **контактный микрофон** на мешке (структурный низ). 10 дублей: нужен «толчок», а не «хлопок» |
| Разрыв | воздушный шарик, проткнутый иглой (3 слоя); презерватив/латекс на банке; пластиковый стакан, сжимаемый до трещины; влажная бумага, разрываемая | 10–15 см, сбоку. Нужна **атака без щелчка капсюля**. По 8 дублей разной силы |
| Трещины | сухая яичная скорлупа; сухие макароны; керамическая плитка, надламываемая; хитиновый панцирь креветки | По 20–30 одиночных тресков. Важно: **не «хруст костей»** (это `COMBAT_DISMEMBER`), а «сухая керамика» |
| Срыв клапана | соломинка в воде, выдув воздуха через неё; пипетка; край воздушного шарика, натянутый и отпущенный; сжатие бутылки с узким горлом | 5–10 см. Нужны 40–100 мс, чтобы «вскрик» был **событием**, а не голосом |
| Жидкость (только `_04`) | резиновая грелка с водой; шланг с воздухом в воде; мёд через узкое горло | 10–15 см, короткие дубли по 60–80 мс |
| Компенсация | тот же мешок/груша, но **очень тихо и коротко**; дыхание через нос с закрытым ртом (для формы) | Записывать отдельно: это самый тихий слой (−24…−30 дБ), он не должен читаться как отдельное событие |

— **Пошаговая обработка:**
1. Чистка: HP 30 Гц, DC, де-эссер 5–8 кГц (искры разрыва режут ухо).
2. Толчок: tanh 2.0–2.6, f0 **фиксированная**; проверить, что это не свип (иначе файл начнёт читаться как ATTACK).
3. Разрыв: `fb_sweep` (фильтрбанк с плавными весами, 9 полос, сглаживание 8 мс), резонанс вниз 30–45 %, спад 30 % длительности, **атака не короче 2 мс** (при 0.8 мс появляется «щелчок стекла» — этот артефакт был найден и устранён).
4. Трещины: интервалы **растут** (0.55–1.45× базового), каждый следующий −18 %; полоса 850–2800 Гц.
5. Переменный элемент: строго по файлу (см. §7 слои).
6. Сочение: 1–3 пузыря, рост тона ×1.7–2.6, длительность 45–75 мс.
7. Компенсация: синус с f0, ползущей вверх на 11–16 Гц, спад по smoothstep.
8. IR 0.13–0.18 с, LP 4.6–5.4 кГц, send 15–20 %; **не** накладывать длинный хвост — иначе HURT сольётся с HIT в «один мокрый звук».
9. 9-полосная окраска к цели `TARGET_HURT` (FFT-маски, 2 прохода, ход ≤6/8 дБ), затем RMS-якорь −12.4…−13.4 и пик −1.6…−2.6 dBFS.
10. Контроль: sustain roughness ≤0.55; salience ≤+10 дБ; спектральный центр в 1-м сегменте **выше**, чем в 4-м (идёт «вниз», а не «вверх»); финал ноль.

## 11. Java: банк + реакция на тип урона

```java
package com.carnis.sound;

import net.minecraft.sounds.SoundEvent;
import net.minecraft.world.damagesource.DamageSource;
import net.minecraft.world.entity.LivingEntity;
import net.minecraft.util.RandomSource;

/**
 * HURT играет ПОСЛЕ combat_flesh_hit и не заменяет его:
 *   hit  = «удар попал» (фидбэк игрока, волна 2),
 *   hurt = «тело отреагировало» (реакция цели, волна 5).
 *
 * Правила:
 *   - cooldown 50 мс, чтобы серия быстрых ударов не превращалась в стрёкот;
 *   - cap 3 одновременных на игрока;
 *   - тип урона меняет ТОЛЬКО питч и выбор файла, а не громкость:
 *       огонь/лазание по стене -> pitch 0.90..0.95, чаще «_03» (мембрана), длиннее тление
 *       взрыв                -> pitch 0.94..1.00, чаще «_04» (сдвиг), самый короткий и тяжёлый
 *       снаряд/стрела        -> pitch 1.00..1.10, чаще «_02» (микротрещина), самый сухой
 *       ближний бой          -> любой, равномерно
 */
public final class CarnisHurtSounds {
    private long lastPlay = 0L;

    public void onHurt(LivingEntity mob, DamageSource src, long now, RandomSource rnd, CarnisHiveVoices.PlaySound play) {
        if (now - lastPlay < 1L) return;                 // 50 мс = 1 тик
        lastPlay = now;

        int variant;
        float pitch;
        String type = src.getMsgId();
        if (type.contains("onFire") || type.contains("inFire") || type.contains("lava")) {
            variant = rnd.nextFloat() < 0.6f ? 2 : rnd.nextInt(4);
            pitch = 0.90f + rnd.nextFloat() * 0.05f;
        } else if (type.contains("explosion")) {
            variant = rnd.nextFloat() < 0.6f ? 3 : rnd.nextInt(4);
            pitch = 0.94f + rnd.nextFloat() * 0.06f;
        } else if (type.contains("arrow") || type.contains("trident") || type.contains("mob_projectile")) {
            variant = rnd.nextFloat() < 0.6f ? 1 : rnd.nextInt(4);
            pitch = 1.00f + rnd.nextFloat() * 0.10f;
        } else {
            variant = rnd.nextInt(4);
            pitch = 0.90f + rnd.nextFloat() * 0.20f;
        }
        play.accept("hive_spawn_hurt", variant, 0.85f, pitch, mob);
    }
}
```
