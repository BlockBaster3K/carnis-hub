## 2. Спор Кодера и Ревизора — разрешён фактом из кода

Ревизор (S62, затем вердикт `9967fef`) утверждал: «громкости T-3202 не
реализованы, нужно добавить multipliers в `sounds.json`». Кодер возразил:
call-site уже передают громкость, добавление в JSON умножит дважды.

**Проверил сам, вытащив исходники из ZIP, а не из отчётов:**

```
playLocalSound(…, detail, SoundSource.AMBIENT, 0.30F, 1.0F, false)
SynapseNodeBlock.java      … SoundSource.BLOCKS, 0.8F, 1.0F)
VeinMutationEngine.java    … SoundSource.BLOCKS, 0.65F, 1.0F)
```

**Кодер прав.** 0.30 / 0.65 / 0.80 стоят в коде на call-sites. S62 «не по ТЗ»
основан на чтении `sounds.json` без учёта аргументов вызова. Если бы Ревизор
настоял и Кодер добавил множители в JSON, эффект был бы двойным усилением —
0.45 стало бы 0.675 у `flow_01`.

Это ровно тот случай, где счётчики S62 (7 из 9 расходятся) верны как числа и
неверны как вывод: они измеряют один множитель из двух.
