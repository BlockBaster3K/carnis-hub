## 2. Приёмка 3.7.3: было 8 расхождений → стало 4, и все четыре не про звук

Два шага, которые дали результат:

**а) Поставил зависимости гейта.** После перезапуска окружения PyAV снова не
было, и звуковые проверки печатали «не проверен — нет декодера av+numpy».
`deps_gate_check.py` назвал это правильно: **отказ инструмента, а не дефект
пакета**. После `pip install -r tools/requirements-gate.txt` — 6 из 6 на месте.

**б) Достал эталон 3.7.2 из истории** (`git show … > /tmp`, без раздувания
sparse-набора). Без него гейт честно писал «эталона нет — сверять не с чем», и
это блокировало три проверки сразу.

| прогон | расхождений | звуковых |
|---|---:|---:|
| без PyAV и без эталона | **8** | 3 |
| с PyAV, без эталона | 6 | 2 |
| **с PyAV и эталоном** | **4** | **0** |

Что теперь измерено и сходится:

```
дельта против 3.7.2:      ✓ СХОДИТСЯ — события и наборы те же, менялись только громкости
клиппинг:                 ✓ измерено 144, peak max −1.20 dBFS, клип 0

sound_orphans:            ✓ сирот 0, ссылок в пустоту 0
ambient_gate:             ✓ код 0

```

**Главная строка — «без мастера 0».** В S126 было «у 129 файлов нет мастера,
изменение НЕ УСТАНОВЛЕНО». Сейчас мастеров 20 (15 старых + 6 моих новых, один
файл общий), и остальные 124 **побайтово равны 3.7.2**, то есть по З-31 п.3 они
норме не подлежат: их никто не менял. Дыра «неизвестно, менялись ли 129 файлов»
закрыта **сравнением с эталоном**, а не новыми мастерами.
