## 4. Три оставшихся сироты: измерение и предложение

Кодер удалил все пять во исполнение буквы критерия («0 сирот в JAR»), и формально
K8-S закрыт. Но по трём файлам остаётся содержательный вопрос, который ТЗ
оставляет за Звуком: **не выбрасываем ли мы рабочую запись, которую надо было
вернуть в слот?**

### 4.1. `hive/amalgam_breath_01` и `amalgam_breath_02` — вернуть в слот

Событие `hive.amalgam_breath` сейчас:

```json
"hive.amalgam_breath": {"subtitle":"carnis.subtitle.hive_amalgam_breath",
  "sounds":[{"name":"carnis:entity/flesh_amalgam_ambient","volume":0.25,"pitch":1.0,"weight":1}]}
```

То есть «дыхание улья» — это тот же файл, что и ambient существа, только тише в
4 раза. Оба сироты — ровно записи нужного типа, по имени и по звуку:

| файл | длит. | RMS | peak | crest | центр | < 120 Гц |
|---|---:|---:|---:|---:|---:|---:|
| `hive/amalgam_breath_01` | 2.00 с | −21.53 | −14.14 | 7.39 дБ | **1364 Гц** | 3.3 % |
| `hive/amalgam_breath_02` | 2.40 с | −22.01 | −14.64 | 7.37 дБ | **1369 Гц** | 3.7 % |
| `entity/flesh_amalgam_ambient` (сейчас) | 2.30 с | −20.01 | −9.77 | 10.24 дБ | **480 Гц** | 3.2 % |

Корреляция огибающих с текущим файлом — **+0.027** и **+0.147**, то есть это
**самостоятельные записи, а не варианты того же материала**. По спектру они
заметно выше (1364/1369 Гц против 480 Гц): это «дыхание/шорох», а не «гул».

По громкости: при `volume 0.25` новый файл даст ≈ −34 дБFS против нынешних
≈ −32 дБFS — тише на 2 дБ. Компенсация: `volume 0.4` (≈ −29.5 дБFS, на 2.5 дБ
громче нынешнего) или `0.35`.

**Предложение Звука:** вернуть оба файла в пакет и сделать событие 3-вариантным
(два новых + текущий ambient, всем `volume 0.35`). Это 86 014 Б, уже
закодированных в правильном формате (Vorbis, 44.1 кГц, моно). Критерий K8-S при
этом закрывается **вторым способом** из ТЗ — «подключены и слышны».
Если Кодер предпочтёт оставить как есть — это его право; тогда файлы остаются
только в банке `03-sound/sounds/hive/`, а в пакет не идут.

### 4.2. `block/nervous_twitch` — удалить, согласен с Кодером

| файл | длит. | RMS | peak | crest | центр |
|---|---:|---:|---:|---:|---:|
| `block/nervous_twitch` (сирота) | **0.137 с** | −20.09 | −8.09 | 12.01 дБ | 2126 Гц |
| `block/synapse_shock` (играется) | 0.551 с | −18.04 | −3.03 | 15.01 дБ | 1664 Гц |

Корреляция огибающих высокая (**+0.894**), но это артефакт: файл в 4 раза
короче, сравнивались первые 0.137 с нарастания. Выборочная корреляция по всему
`synapse_shock` — **0.09**, то есть **не фрагмент и не копия**. Практически это
0.137-секундный щелчок (−8 дБFS peak), самостоятельной ценности не имеет, а
событие `synapse_shock` с 3.5.x закрыто полноценной записью. Удаление — верно.

## 7. Инструмент: `03-sound/scripts/check_orphans.py`

Критерий K8-S должен проверяться командой, а не пересчётом 145 файлов руками.

```
python3 03-sound/scripts/check_orphans.py <jar | каталог пакета> [--verbose]
коды: 0 — 0 сирот и 0 висячих ссылок; 2 — критерий не выполнен; 1 — ошибка входа
```

Проверен в обе стороны, включая края:

| случай | ожидание | получено |
|---|---|---|
| пакет с 1 ссылкой и 1 файлом | код 0 | **0** |
| рядом лишний файл без ссылки | код 2 + имя | **2** |
| событие есть, файла нет | код 2, «ссылки в никуда» | **2** (1 ссылка) |
| нет `assets/carnis/sounds.json` | код 1 | **1** |
| битый архив | код 1 без трейсбека | **1** («File is not a zip file») |

Прогоны на реальных объектах: JAR 3.6.0 → 5 сирот (код 2); `3.6.0-R` → 5 (код 2);
`01-coder/3.7.0` → **0 (код 0)**; `tools/sound_orphans.py` Интегратора на той же
заготовке → **0, СХОДИТСЯ** (инструменты независимы, результат совпал).

## 8. Решения, принятые самому (Архитектор недоступен)

1. **Источник — `main`.** ТЗ говорило «jar из `06-build/jars/`», но в рабочей
   ветке 3.6.0 нет (только 3.5.1/3.5.2). Взял из `main` по коммиту `11ab02ed`,
   сверил sha256 с известным `280468e0…6ac7` — совпало, значит проверялся
   выпущенный артефакт, а не пересборка.
2. **Критерий «сирота» — отсутствие ссылок в `sounds.json` плюс проверка всех
   прочих файлов пакета.** Ссылок из кода мимо `sounds.json` в 1.20.1 быть не
   может; дополнительно проверил 60 констант `ModSounds` — 60/60 указывают на
   существующие события, «висячих» нет.
3. **`nervous_twitch` попал в сирот впервые** (ТЗ 3.7.0 знает только о двух).
   Без него критерий «0 сирот» после исправления пары `flesh_amalgam_*` не
   достигается — это дефект перечня в ТЗ, а не работы Кодера.
4. **Просил «подключить» только дыхание, а не все три.** `nervous_twitch` —
   щелчок 0.137 с без роли; дыхание — готовые записи под существующее событие,
   которое сегодня переиспользует чужой файл. Рекомендация не блокирует
   приёмку: K8-S закрыт и без неё.
5. **Файлы банка не удалял** — по конвенции `03-sound/` старые файлы уходят
   только с санкции. Все пять сирот остаются в банке, в пакет не идут.
6. **SSH-ключ роли не активирован в GitHub** (`Permission denied (publickey)`),
   поэтому сдача этого отчёта ждёт регистрации ключа Интегратором; подробности —
   `00-board/reports/sound_handshake.md` §2. Токен по HTTPS не использовал: по
   инструкции он не должен использоваться, и исторические токены GitHub уже
   отклонял.

## 10. Независимая проверка гейта приёмки (`tools/accept_3.7.0.py`)
