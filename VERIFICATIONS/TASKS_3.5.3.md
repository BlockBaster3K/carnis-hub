## Д1. ⛔ Накладка звука в `FleshBulbBlockEntity` — интервал короче самого звука

**Где:** `src/main/java/com/carnis/mod/block/entity/FleshBulbBlockEntity.java:53`

```java
int interval = 40 - (int)(30L * bulb.age / bulb.duration);
```

**Что происходит.** Интервал падает от 40 до **10 тиков** по мере старения луковицы
(`age/duration` → 1). Проигрываемый звук — `ModSounds.PULSING_HEART_BEAT` → файл
`block/heart_pulse.ogg`, измеренная длительность **0,600 с = 12 тиков**.

В последние ~7 % цикла интервал (10–12 тиков) **короче звука** → следующий удар
начинается, пока предыдущий ещё звучит → щелчок и наложение двух ударов.

> Ревизор зафиксировал «11–12 тиков»; по коду минимум **10** — дефект чуть серьёзнее.

**Требование:** интервал между ударами **всегда больше 12 тиков** (минимальный запас 13).
Не менять сам звук — он принят и утверждён.

**Приёмка:** в коде видно константу с запасом; в отчёте — строка, где взят нижний
предел интервала и чем он обоснован.

## Д2. ⛔ Накладка лупа в `PlayerHallucinationHandler` — перезапуск до конца файла

**Где:** `src/main/java/com/carnis/mod/client/PlayerHallucinationHandler.java:56`

```java
soundDelay = Math.max(8, 24 - agonyTicks / 7);
```

**Что происходит.** Задержка перезапуска — **10–24 тика** (0,5–1,2 с). Звук —
`ModSounds.HEARTBEAT_LOOP` → `block/heartbeat_loop.ogg`, измеренная длительность
**1,400 с = 28 тиков**. Вызов на строке 66 — `mc.level.playLocalSound(..., false)`:
последний аргумент `loop = false`, то есть это **повторный старт**, а не плавная
модуляция, даже при `"stream": true` в `sounds.json`. Значит луп каждый раз
начинается заново, не успев доиграть → обрыв на стыке.

**Требование:** задержка **больше 28 тиков** во всём диапазоне агонии, либо заменить
звук на короткий. Файл не менять.

**Приёмка:** в отчёте — фактический диапазон `soundDelay` после правки и сравнение
с 28 тиками.
