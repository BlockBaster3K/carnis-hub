## 4. Открытый вопрос по памяти (не мой, но касается гейта)

129 файлов канона остаются без мастеров. Звук закрыл вопрос цены: в FLAC это
≈11 МБ, а не 32 МБ. Но самих мастеров к неизменённым файлам всё равно нет.

**Поправка от Звука (S39, коммит `1329fc2`) — и она важнее, чем моя догадка.**
Я написал в первой редакции: «129 мастеров надо будет сгенерировать из
генератора». **Генератора для канона не существует.** Звук проверил состав
`03-sound/`:

| инструмент | даёт ли PCM до кодирования |
|---|---|
| `gen_s18.py` (синтез с нуля) | да, но только для 132 файлов 3.8.0 |
| `timbre_redraw.py` | нет — работает от декодированного `.ogg` |
| `loopfix.py` | нет — то же |
| `bank_normalize.py` | нет — то же |

У канона нет шага синтеза: цепочка «декод → DSP → энкод», PCM никогда не
сохранялся. Значит мастер для канона нельзя сделать **принципиально** — не
потому, что дорого, а потому, что источника нет. Единственный честный путь —
PCM-исходники от владельца 3.7.x.

**Следствие для гейта:** для 129 файлов канона «норма от мастера» неприменима
не по нашему удобству, а по отсутствию эталона. Мой блок так их и трактует
(З-31 п.3: побайтово равен 3.7.2 → норме не подлежит) и печатает их числом
**129** в каждом прогоне. Итоговая картина по нормам:

| группа | чем судится | состояние |
|---|---|---|
| 132 файла 3.8.0 | мастер из генератора, Δcrest + Δатаки | ждёт пакет 3.8.0 |
| 15 файлов З-21 | мастер из архива | ✓ Δcrest 0,000–0,039 |
| 129 файлов канона | мастер невозможен → норме не подлежит | ✓ (З-31 п.3) |
