# 1. `FLESH_BLOCK_STEP` — «Шаг по биомассе»

**\[FLESH_BLOCK_STEP\]**

— **Название:** Шаг по биомассе
— **Контекст:** игрок или моб идёт по блокам `living_flesh`, `biomass`, `ossified_flesh`. Триггерится стандартным `playStepSound` каждые ~0.4 блока пути (в Minecraft — на каждые 0.6–1.0 м). Это **самый часто звучащий звук мода**: за минуту ходьбы — 35–45 срабатываний.
— **Тип:** SFX (шаговый цикл)
— **Длительность:** 0.34–0.44 с
— **Громкость в игре:** 0.55 (`volume` в sounds.json); RMS −17 наш; фактический уровень добирается слайдером
— **Питч-вариация:** **0.90–1.10** (широко! для часто играющего звука это главный инструмент против усталости)
— **Эмоция:** физическое отвращение, «я наступаю на живое». Не «страшно» — именно телесно-неприятно, но с любопытством: игрок должен слышать, что материал *разный*.
— **Слои:**
  1. **Low body (30–200 Гц):** мягкое вдавливание массы — синус со спадом частоты 95→62 Гц (у засохшей плоти 150→95 Гц, короче). Спад 70–85 мс, LP 240 Гц. Не «бум», а «оно продавилось».
  2. **Mid texture (200–900 Гц):** влажный «чвак» — полосовой шум 220–900 Гц, атака 3 мс, спад 55–60 мс (это ядро узнаваемости шага).
  3. **High detail (0.8–4.8 кГц):** два события: (а) микро-хруст 800–2800 Гц, 13 мс — «ломкие волокна»; (б) **липкий отрыв** через 65–110 мс — 900–3800/4800 Гц, атака 20 мс (медленная!), спад 55 мс. Именно отрыв делает шаг «живым», а не «резиновым».
  4. **Air / Reverb:** короткое помещение зоны: IR 0.16 с (у засохшей 0.12 с), LP 5.2 кГц, send 22%. Мало реверба — шаги должны быть «под ногами», а не «в зале».
— **Референсы:** *Dead Space* — шаги по плоти на Ishimura (слоение + «двойной такт»); *Scorn* — влажная биомасса; *Alien: Isolation* — шаги героя по разным поверхностям (Kadoi/RE2: удар «собирается» из нескольких записей).
— **Foley-запись:**

| Слой | Что взять | Как записывать |
|---|---|---|
| Low | (1) кулак в мокрую глину; (2) хлопок ладонью по натянутой коже/барабану; (3) мякоть арбуза на доске | Близко (10–15 см), обутой ногой по мокрой глине — 6–8 дублей; голый звук «вдавливания» пишем без верхних деталей, они добавляются слоями |
| Mid | мокрая губка в кулаке; мокрая замша/тряпка | Сжимать **медленнее, чем хочется** (атака ≥3 мс) — иначе получается «капля». 8 дублей разной влажности |
| Хруст | пекинская капуста (один лист, ломать быстро); сельдерей | Микрофон 5–8 см, без ветрозащиты. Нужно 10–15 микро-дублей, из них отбираются «одиночные щелчки» |
| Отрыв | мокрая кожа/замша, оттянутая от стола и отпущенная; скотч от гладкой поверхности | Записывать с задержкой 65–110 мс после импакта — в DAW просто сдвинуть |
| Сухая корка | сухая корка хлеба, яичная скорлупа, сухие листья; «засохшая» — капуста, подсохшая за сутки | Для `_03 ossified`: ломать коротко, 4–6 событий, без влаги |

Для трёх вариантов **записывать нужно три разных набора**, а не один с разным питчем:
`_01 soft` — нормальная биомасса, `_02 wet` — затопленная/очень влажная, `_03 ossified` — засохшая корка + кость.

— **Пошаговая обработка:**
1. Чистка: HP 28 Гц, убрать DC, вырезать «дыхание» микрофона (RX).
2. Импакт: LP 240 Гц на низ, сатурация `tanh` drive 1.5 **только на низах**.
3. Мид: полоса 220–900 Гц, **не уже** (Q ≤ 1.2), иначе «бочка».
4. Хруст: HP 800, транзиент 13 мс — единственный слой с жёсткой атакой.
5. Отрыв: атака ≥20 мс (это принципиально: атака 1 мс превращает отрыв в «каплю»), HP 900.
6. Свести с весами 0.80 / 1.00 / 0.70 (низ/мид/хруст), отрыв +0.45 на 20 мс.
7. IR 0.16 с, send 22%; для `_03` — 0.12 с, send 15%.
8. Многополосный контроль: цель `[−30, −8, −2, −6, −10, −16, −24, −34, −44]` (±3 дБ). Провал 20–40 Гц (−30) — важно: шаг не должен «бить в живот», иначе 40 шагов в минуту = тошнота.
9. Нормализация пика −2 дБFS, обрезка pregap (атака в 0–3 мс).

— **Варианты:**
- `_01` **soft** — базовая биомасса, длина 0.40 с.
- `_02` **wet** — очень влажная/затопленная, 0.44 с (отрыв ярче и позже).
- `_03` **ossified** — засохшая корка/окостеневшая плоть, 0.34 с (сухой треск, почти нет низа).

Для полноценного банка нужно 8 файлов (по 3 + 5 дополнительных вариантов того же материала с другими дублями). Сейчас 3.

— **Priority:** **High** (самый частый звук; здесь экономить нельзя)

**Тех:** `BLOCKS` (или `PLAYERS` для игрока) · att 8 · stream false · **bank 8** · cooldown 0.20 с · subtitle отсутствует (шаги без сабтайтлов) · pitch 0.90–1.10 задавать в `sounds.json` попарно разными значениями.

**FFmpeg (сборка из foley-слоёв):**
```bash
# low.wav / mid.wav / crack.wav / peel.wav — ваши записи; ir_step.wav — IR помещения 0.16 с
ffmpeg -y -i peel.wav -i ir_step.wav -filter_complex "[0]highpass=f=900,adelay=80|80[p];[p][1]afir=dry=0.8:wet=0.2" peel_r.wav

ffmpeg -y -i low.wav -i mid.wav -i crack.wav -i peel_r.wav \
 -filter_complex "\
 [0]lowpass=f=240,volume=0.80[l];\
 [1]bandpass=f=500:width_type=h:w=700,volume=1.00[m];\
 [2]highpass=f=800,volume=0.70[c];\
 [3]volume=0.45[p];\
 [l][m][c][p]amix=inputs=4:normalize=0:duration=longest[mix];\
 [mix]highpass=f=28,alimiter=limit=0.79:attack=2:release=40[out]" \
 -map "[out]" -ac 1 -ar 44100 step_master.wav

ffmpeg -y -i step_master.wav -af "volume=-2dB,aresample=44100" \
  -ac 1 -ar 44100 -c:a libvorbis -q:a 5 assets/carnis/sounds/flesh/flesh_block_step_04.ogg

ffprobe -hide_banner assets/carnis/sounds/flesh/flesh_block_step_04.ogg   # channels=1, 44100
```

# 2. `COMBAT_FLESH_HIT` — «Попадание по плоти»

**\[COMBAT_FLESH_HIT\]**

— **Название:** Попадание по плоти
— **Контекст:** любое попадание по заражённому мобу или блоку плоти (меч, топор, стрела, кулак). Второй по частоте звук мода: в бою — до 3–5 срабатываний в секунду.
— **Тип:** SFX (боевой отклик)
— **Длительность:** 0.52–0.78 с
— **Громкость в игре:** 0.85 · RMS −17…−19 наш
— **Питч-вариация:** **0.88–1.14** (максимально широко: это ключ к тому, чтобы бой не превращался в метроном)
— **Эмоция:** тактильная отдача «это работает» + брезгливость. Звук должен *вознаграждать* игрока: плотный низ + сочный всплеск.
— **Слои:**
  1. **Low body (30–200 Гц):** «мясистый» импакт с падением частоты 110→58 Гц (у крита 120→58), спад 130 мс. Сатурация drive 1.9 — агрессия без грязи.
  2. **Mid texture (180–900 Гц):** «шлёпок» 180–800 Гц, спад 70 мс — тело удара.
  3. **High detail (0.7–6 кГц):** (а) хруст 300–1400 Гц 35 мс; (б) **всплеск** 700–6000 Гц через 12 мс, спад 60 мс — «брызги»; (в) «догоняющий» влажный шлепок через 100 мс — по правилу «два такта» (хруст → шлёпок даёт ощущение двух слоёв плоти).
  4. **Air / Reverb:** IR 0.22 с (крит 0.26 с), LP 6 кГц, send 28%. Больше реверба, чем у шагов: удар «в мир», а не «под ноги».
— **Референсы:** *Dead Space* — попадание по некроморфу (слоение + «wet tail»); *RE2 Remake* — hit feedback по зомби; *Bloodborne* — «мясистые» попадания; библиотеки: Gore Toolkit (cabbage/dismember), SoundBits Just Gore.
— **Foley-запись:**

| Слой | Что взять | Как |
|---|---|---|
| Low | сырое мясо (говяжья печень/куриная грудка) на разделочной доске; бить рукояткой ножа | 10–12 дублей, разная сила; микрофон 15 см |
| Шлёпок | мокрая губка, брошенная в мокрое полотенце; мокрая замша | Важно: **не** «шлепок ладонью» (слишком «человечно») |
| Хруст | сельдерей (пучок), капуста, грецкий орех | Короткие дубли, 10–15 |
| Всплеск | арбузная мякоть, раздавленная рукой; вода из бутылки с широким горлом, выдавленная в ткань | Записывать отдельно; в DAW ставить через 10–15 мс после импакта |
| Догоняющий шлепок | мокрая тряпка, брошенная на стол | Через 100 мс, тише на −8 дБ |

— **Пошаговая обработка:**
1. HP 30 Гц, DC-offset, чистка щелчков.
2. Низ: LP 200, сатурация 1.8–1.9; при этом **проверить 20–40 Гц** — не должно быть больше −26 дБ, иначе в бою «каша в животе».
3. Шлёпок: 180–800 Гц, атака 1 мс (здесь резкая атака нужна — это контакт).
4. Хруст: 300–1400 Гц, спад 35 мс.
5. Всплеск: 700–6000 Гц, задержка 10–15 мс, спад 60 мс; HP 700.
6. «Два такта»: догоняющий шлепок на +100 мс, −8 дБ.
7. IR 0.22 с, send 28%.
8. Многополосный контроль к цели `[−26, −8, −2, −3, −7, −13, −21, −31, −41]`.
9. Пик −1 дБFS.

— **Варианты:**
- `_01` **flesh** — обычное попадание, 0.62 с.
- `_02` **crit** — критический/расчленение: добавлены хруст кости (1200–5000 Гц) и тональный «перелом» 260→180 Гц; 0.78 с.
- `_03` **chitin** — попадание в хитин/панцирь: сухой, высокий, неприятный; центр тяжести в 500 Гц–6 кГц; 0.52 с.

Банк: **6 flesh + 3 crit + 3 chitin = 12 файлов** (по спецификации Док. 02). Сейчас 3.

— **Priority:** **High**

**Тех:** `HOSTILE` · att 16 · stream false · **bank 12** · cooldown 0.05 с (в бою), **cap 4 одновременных** (channel budget!) · subtitle отсутствует.

**FFmpeg (сборка из слоёв):**
```bash
ffmpeg -y -i hit_low.wav -i hit_slap.wav -i hit_crush.wav -i hit_splat.wav -i hit_late.wav -i ir_hit.wav \
 -filter_complex "\
 [0]lowpass=f=200,volume=0.85[l];\
 [1]bandpass=f=490:width_type=h:w=620,volume=0.95[s];\
 [2]bandpass=f=850:width_type=h:w=1100,volume=0.70[c];\
 [3]highpass=f=700,adelay=12|12,volume=0.70[p];\
 [4]adelay=100|100,volume=0.35[t];\
 [l][s][c][p][t]amix=inputs=5:normalize=0:duration=longest[m];\
 [m][5]afir=dry=0.72:wet=0.28[w];\
 [w]highpass=f=30,alimiter=limit=0.89:attack=1:release=40[out]" \
 -map "[out]" -ac 1 -ar 44100 hit_master.wav

ffmpeg -y -i hit_master.wav -af "volume=-1dB,aresample=44100" \
  -ac 1 -ar 44100 -c:a libvorbis -q:a 5 assets/carnis/sounds/combat/combat_flesh_hit_04.ogg
```

## 4.2 Java-триггеры (Forge 1.20.1)

```java
// Шаги: переопределяем звук шага для блоков плоти
@Override
public SoundType getSoundType(BlockState state) {
    return CarnisSoundTypes.FLESH;   // новый SoundType с нашим stepSound
}

// Попадание: в обработчике атаки игрока
if (target.getMobType() == MobType.UNDEFINED && target instanceof CarnisMob) {
    if (ChannelBudget.canPlay(CarnisSounds.COMBAT_FLESH_HIT.getId(), 4)) {
        level.playSound(null, target.blockPosition(),
            CarnisSounds.COMBAT_FLESH_HIT.get(), SoundSource.HOSTILE,
            0.85f, 0.88f + level.random.nextFloat() * 0.26f);   // 0.88–1.14
    }
}
```

## 4.3 Channel budget (обязательно для боя)

В бою 4 моба × 3 удара в секунду = 12 запросов/с. Правила:
- `combat.flesh.hit` — **cap 4 одновременных**, cooldown 50 мс (иначе «стена шлепков»);
- шаги — **cap 2** (игрок + один моб рядом), остальные отбрасываются до `playSound`;
- при переполнении приоритет: `combat.hit` > `step` (шаги дропаются первыми);
- общий бюджет «наших» источников — ≤16 (см. Док. 03, §5.3).
